## 已保留与已验证

- 原地图全部 749 个对象的名称、变换、模型、材质、碰撞、可见性、文件夹和标签未修改。
- 百盛主楼、天主教堂、青岛七中、码头、栈桥、所有墨绿色山石、地面和坡道均原样复制；普通街坊名称中的“百盛东侧”不属于百盛主楼。
- 新房屋按原 Facade 组件的有向三维边界适配，保留朝向、占地、整体高度和底部位置。屋檐及阳台计入总尺寸；89 栋均通过尺寸与中心点校验。
- 房屋内部的旧 VisibleBody 方块未重复显示，以免从新屋顶或立面中穿出；原地图的这些结构碰撞完全保留。
- 没有复制 LDMapAnchor、PlayerStart、LDLayoutPoint、LDRegionNavBounds、怪物逻辑、相机或全局灯光。
- 原全局海面已覆盖两片区域，未重复叠放海面。
- 对照区只有静态美术对象：无碰撞、不影响导航、不开启重叠事件，不携带 LDSceneVisual、LDSceneAnchor 等玩法或派生索引标签。
- 对照区可在当前 Game View 下显示，因此最终为普通可见美术对象，会随关卡进入运行与打包。它不构成新的可玩区域；正式打包交付前可移除整个对照文件夹以免保留对照美术开销。

## 使用与复用

UE 资产目录：`/Game/Lockdown/Art/QingdaoCityL1`，包含 Meshes / Materials / Textures。

Blender 源文件：`QD_City_L1_9Types.blend`。9 个模型在展示阵列中排开；展示用地面、相机和灯光不是游戏资产。导出的 FBX 已保持模型原点在底部附近的原始导出坐标，UE 资产尺寸为厘米。

允许按场景适度缩放复用。以后正式替换时按 Facade 的可视边界匹配，不要把整栋 Actor 的编辑器图标边界当作建筑体量，也不要把山石批量当作房屋。

这批 FBX 经 UE 5.8 传统 FBX 导入器以 Import Uniform Scale=100 导入并实测尺寸。Interchange 不读取 FbxImportUI 的相同选项；重导入时应沿用当前资产保存的导入设置，不要对其他来源 FBX 一概应用此比例。

## 校验与追溯

- `kit-manifest.json`：Blender 资产规格。
- `ue-import-report.json`：UE 中实际三角面、材质槽与模型尺寸。
- `placement-report.json` / `房屋替换对应表.csv`：每栋房屋的原对象、对照对象、使用资产和尺寸。
- `runtime-isolation-audit.json`：碰撞、导航、重叠与玩法对象隔离检查；最终可见性标记以 placement-report 为准。
- `previews/01-comparison-overview.png`：实际 UE 对照截图，左为原版，右为替换版。
- `previews/02-updated-city.png`：实际 UE 新城市局部。
- `backup-before-comparison/L_Demo.umap`：替换前的当前关卡备份，保存在外部交付目录，不自动覆盖回工程。

本批几何与材质为程序化制作，未下载外部模型或调用付费模型生成。
