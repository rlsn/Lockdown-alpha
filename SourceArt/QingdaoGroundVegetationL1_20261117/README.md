# 青岛城市地面与植被资产

本库包含分区地面和七类植被的可编辑 Blender 文件、FBX、PBR 贴图及尺寸清单。贴图已打包进 Blender 文件。作者单位为米；UE 使用 100 的导入比例。

地面按现有关卡支撑面并集制作，包含 10 个分区及 4 个铺装细节网格。覆盖教堂广场、马牙石坡街、七中校园、商业步行街、滨海步道、中央开放空间与三段山地。模型保留原高低层和坡道，合并重复的内部表面；导出坐标精度为 0.1 毫米。模型顶点相对作者原点制作，当前对照区域地面 Actor 的平移为 UE 厘米 `(0, 24000, 0)`。

- 教堂广场参考浙江路马牙石铺装，灰色小石块与连续深色边带。
- 大下坡共用一套 1K 贴图、一个材质，贴图按米制尺度重复。
- 商业街为暖灰花岗岩步行空间，以深灰嵌带衔接滨海石材铺装。
- 七中运动场在现有尺度内采用蓝色外场、红色跑道、青色缓冲区、浅绿色球场及白线；校园通行面为灰色铺地。
- 山区采用开发过的市区山头公园风格，石质园路与草地、种植土交替，保留通行带。

七类植被为黑松、雪松、悬铃木、刺槐、耐冬、大叶黄杨、麦冬草丛。每个模型少于 3000 三角面，共用一套 512 贴图。各模型原点设在植株基部；摆放时只旋转 Yaw，草木可适度缩放与复用。

UE 资产位于 `/Game/Lockdown/Art/QingdaoGroundVegetationL1`。当前场景实例位于 `L1_房屋替换对照_20261116/12_地面街道与植被`，每株植被为独立可编辑 Actor。实例位置由关卡拥有，无运行时自动重铺或重新生成。

这些实例沿用对照区域纯美术属性：NoCollision，不参与导航，不承担玩法身份。原正式区域的碰撞、导航与玩法布局未由本库更改。正式地面需要有效原生 WorldStatic 支撑和阻挡 Pawn，依项目关卡创作约束配置；不能通过模型名称、装饰数量或固定坐标驱动开局。
