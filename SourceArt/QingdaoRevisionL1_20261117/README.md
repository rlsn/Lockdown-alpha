# 青岛地标与场景资产

本库包含可编辑 Blender 源文件、FBX、材质贴图和资产尺寸清单。贴图已打包进 Blender 文件。FBX 使用米作为作者单位；UE 导入比例为 100。各资产的 `asset-manifest.json` 给出三角面、包围盒、材质槽和贴图尺寸。

- church：天主教堂，14,682 三角面，一套 2K 贴图，建筑和附属小礼拜堂。
- school：东翼与外围教学楼、临街历史建筑、校门、校名牌及独立立体中文字。立体字的网格已焊接，并校正封口法线。
- parkson：百盛，3,492 三角面，一套 1K 贴图。沿街长侧面为凹入玻璃门入口；整体沿用关卡中压缩后的体量。
- pier：主栈桥、回澜阁、栏杆、桥墩和灯具，2,868 三角面，共用一套 1K 贴图。灰色花岗岩铺装按 600×400mm 尺度排布，4.8m 重复单元保持桥面与平台一致的纹理密度。
- fence：四段适配既有教堂边界的石基铁艺围栏，单段少于 3,000 三角面。石基包含原地形高差处的挡墙高度。
- dock：独立码头地面白线网格及深色沥青材质；白线为装饰，不提供导航或碰撞。

场景资产位于 `/Game/Lockdown/Art/QingdaoRevisionL1`。关卡中的本批修改位于 `L1_房屋替换对照_20261116` 的对照区域。美术网格不参与碰撞、导航或游戏初始化。保留既有关卡的承托面、阻挡体与玩法定位点；不要将美术对象的名称、数量或位置作为玩法前提。

校名字样为“山东省青岛第七中学”，校训为“求真 尚善 致美”。字为独立网格，安装时应保持在墙面或底板外，避免穿插；不应沿高度轴压扁。校门开口沿用关卡已有约 4.41m 的净宽。
