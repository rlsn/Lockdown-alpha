Basketball animation source and license

Original recordings: CMU Graphics Lab Motion Capture Database.
https://mocap.cs.cmu.edu/
https://mocap.cs.cmu.edu/faqs.php

Selected captures: 06_03 (forward dribble), 06_13 (freestyle dribble,
used to establish an athletic stance), 06_15 (dribble and shoot).
The motion is from a recorded performer; it is not a recording of the depicted athlete.

Downloaded FBX conversion:
https://huggingface.co/datasets/gbionics/cmu-fbx
Conversion provenance: CMU ASF/AMC -> cgspeed BVH -> RancidMilk FBX.
The converted data has a reference T pose, body motion and no captured fingers.

The CMU terms permit copying, modifying and redistribution, including use
inside commercial products. Selling the motion data itself, including converted
data, is prohibited. These terms apply to the included source motion as well.

Attribution: The data used in this project was obtained from mocap.cs.cmu.edu.
The database was created with funding from NSF EIA-0196217.

Authoring:
BasketballMotion.json contains the retargeted, edited local bone tracks used
by AuthorPreviewAssets.py. Run that script in the Unreal Python environment
to rebuild the three animation assets and preview materials. Tripo's imported
root scale is retained, and local translations respect that root scale.

Mocap/retarget.py reproduces those tracks from Mocap/target.json and the three
FBX files; it requires Python with numpy, scipy and pillow. The target export
contains this character's reference transforms and the existing idle/run tracks.
The run uses the existing locomotion legs with captured basketball upper-body
motion. Standing dribble and throw use planted feet with an adjusted athletic
stance. Finger curl and palm alignment are authored corrections, not finger capture.
Output retargeted.json is consumed as BasketballMotion.json.

Preview runtime: 0.9 s idle dribble cycle, 0.8 s run gait cycle,
1.5 s throw with release at 1.047 s. The ball is gathered at the next contact,
then attached at the calibrated BasketballSocket until release. Returned balls
transition through the ready pose. Moving attacks retain the locomotion base
and aim the spine within a 70 degree arc.
