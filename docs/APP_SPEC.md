# Lockdown Demo App Spec

**目标版本：v0.10.0**

**平台：Windows PC，键盘与鼠标，Unreal Engine 5.8.4**

本文定义首个可玩 Demo 的产品规则和验收要求，不是当前代码的完成声明。
开发方式见 [开发指南](DEVELOPMENT.md)，AI 协作约束见 [AGENTS](../AGENTS.md)。

## 1. 产品目标与范围

Lockdown 是一款采用 MOBA 操作和俯视斜角镜头的自由混战游戏。每位参赛者通过争夺野怪、击杀对手、升级选择和购买装备建立战斗优势，再把优势转化为在唯一旗杆上喷上并守住自己的涂鸦。

**核心循环：探索与侦察 → 战斗获取经验和金币 → 选择成长、购买装备 → 判断继续发育还是去旗杆 → 喷上涂鸦并守住获胜。**

击杀、金币和等级都是获胜手段，不是独立胜利条件。策略同时来自构筑、资源争夺、局部视野、进退时机，以及喷漆、守护与围攻涂鸦主人之间的取舍，不以堆叠系统数量作为深度。

| 项目 | Demo 范围 |
| --- | --- |
| 对抗关系 | 所有参赛者各自为战；没有队伍或共享胜利 |
| 真人 | 最多 3 人，包含 Host 本人 |
| 对手 AI | 最多 3 个；与真人一样独立参赛，不是队友 |
| 总规模 | 最多 6 名参赛者；野怪不计入参赛人数 |
| 地图 | 一张地图，1 个占领点（旗杆及其喷漆区）、5 组野怪、2 档野怪难度、1 个商店、2 处躺平角、10 个预设出生点 |
| 角色 | 所有人使用相同的基础角色，开局只有近战单体普攻；身份通过名称、头像和可辨识外观区分 |
| 成长 | 从 1 级到最高 10 级；开局获得一次三选一，之后每次升级再获得一次，最多选择 10 次 |
| 角色技能 | 最多 2 个主动技能槽；被动技能没有独立槽位上限；每个角色技能最高 3 级 |
| 装备 | 最多 2 件，没有额外背包；装备可提供属性、被动效果或主动技能 |
| 联机 | Host 同时作为玩家和 Listen Server；其他真人通过 IP 直连 |
| 表现目标 | 功能 Demo，可使用占位资源，但游戏状态、攻击、技能、视野、喷漆、涂鸦与 UI 必须清晰可辨 |

本文只定义这个 Demo。不设置跨局战力成长、长期世界模拟或后续版本路线图。

### 1.1 雾港世界观与表现

对外标题为 **《谁是雾港最强淫人王》**，副标题为“脆皮大学生无差别大乱斗 · 旗杆上插谁的名，谁就是淫人王”；
技术项目名仍为 **Lockdown**。“淫”是雾港黑话，只指把人揍趴下，可以公开用于标题、菜单、击杀播报
（“X 把 Y 淫了”）与宣传文案。主菜单常驻一行小字：“雾港黑话：淫 = 把人揍趴下，跟色情没关系”。

舞台是雾港大学城后街的烂尾球场：白天有人跑步，晚上全是来“整活”的。沿用
[世界报告](demo/WORLD_CAMPS_AND_VISION.md)中已批准的单层地图布局。真人与对手 AI 都是已成年的
“脆皮大学生”（一碰就碎，但嘴很硬）；野怪也按成年人表现：低档野怪显示为已读不回的 HR（两只一组），
高档野怪显示为追着办卡的私教。它们仍是非参赛者，不因此增加席位或改变两档规则。

基调是简中互联网与贴吧式的整活：人人嘴硬、到处是梗，不中二、不严肃。伤害反馈围绕“精神状态”，
生命归零表现为“寄了”或“被淫了”，复活等待表现为“回出租屋 emo”。招牌阴招是扒裤子与掏蛋子。
名称、衣物和尴尬动作的表现不改变原有伤害类型、控制期限或动作权限。

内容边界：

- 扒裤子只露出夸张的大花裤衩或秋裤，不露身体；掏蛋子隔着衣服、卡通化表现。
- “淫”只指把人揍趴下。以上表现都不带性意味，不做裸露或色情。
- 不做血腥。
- 不美化毒品：世界观里的“禁药”只作背景，不做成技能、装备或其他条目。
- 不使用真实品牌名或商品名。

这次换皮（[#111](https://github.com/rlsn/Lockdown-alpha/issues/111)）只改玩家可见文字；美术、音效、数值、机制、
内容 ID、显示键、枚举与地图几何都不变。角色仍是现有的校园休闲装，野怪与场地外观也不变，
等正式美术（[#93](https://github.com/rlsn/Lockdown-alpha/issues/93)）按雾港世界观统一。
技能、装备目录及机制标签统一见
[内容与数值 §15](demo/CONTENT_AND_BALANCE.md#15-后续批次构筑扩展已批准方向未进入运行输入)，
不是新增另一套玩法模式，也不扩大当前完成门槛。

## 2. 对局流程与胜负

### 2.1 从菜单到结算

主菜单提供 **开始、设置、退出**。开始入口提供创建房间与通过 IP 加入房间。

房间展示参赛者名称、真人/AI 标识、Host 标识和准备状态。Host 设置 AI 数量；未使用的名额无需自动补满。所有已连接真人准备后，由 Host 开始。单人也可以创建房间进行练习，使用同一套玩法规则。

对局开始时，参赛者进入随机出生点，角色状态初始化，野怪生成，进入发育期。发育期内可以打野、战斗、升级和购物，但不能喷漆或获胜。发育期结束后，旗杆开放，并持续开放到本局结束。

守护成功后立即锁定唯一胜者，停止继续结算战斗、奖励、购物、喷漆和守护。结果页面展示胜者和本局基本结果；Host 可以带房间返回 Lobby 开始新局，玩家也可以离开房间返回主菜单。

结算展示所有参赛者的名称、击杀数、死亡数、助攻数和最终等级，并标出赢家，同时显示结束原因和本局用时。
离局不删除其本局结果记录；没有胜者时不从统计中另选赢家。统计只用于展示，不参与胜负判定。

### 2.2 唯一胜利条件：喷漆与守护

旗杆开放后，**一名有效参赛者在喷漆区内独自喷上自己的涂鸦，再让这幅涂鸦连续守护满规定时长，即获胜**。进入喷漆区自动开始判定，无需交互键、钥匙、门票或其他前置任务。
喷漆需要时间；喷上之后要守住，期间可以挨打，但挨打本身不打断守护，只计算涂鸦连续存在的时间。

表现为在旗杆上喷上涂鸦、守住后成为“淫人王”；喷漆、涂鸦与加冕反馈只跟随服务器已提交的状态与唯一胜者，
不能通过动画、称号或统计提前判胜。

- **开放**：发育期结束后旗杆开放，直到本局结束。
- **有效参赛者**：仍在本局、存活且不在复活保护中的真人或对手 AI。死亡角色、野怪、商店以及技能视觉效果不计入喷漆区人数。
- **喷漆区**：以旗杆为中心的圆形区域，按角色脚点的平面距离判定，边界算在内。半径与喷漆、守护时长写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

| 情形 | 规则 |
| --- | --- |
| 喷漆区内只有一名有效参赛者，且他不是当前涂鸦主人 | 他的喷漆进度累积；满规定时长即喷上涂鸦 |
| 喷漆区内有两名以上有效参赛者 | 所有人的喷漆进度暂停并保留 |
| 喷漆者受到普通伤害、减速或缴械 | 不影响喷漆 |
| 喷漆者离开喷漆区、死亡、离局，或受到定身、眩晕、嘲讽、击退 | 他的喷漆进度清零 |
| 喷上涂鸦 | 旗杆显示该参赛者的涂鸦，守护计时从 0 开始；原涂鸦被覆盖 |
| 守护期间 | 涂鸦主人可以离开喷漆区，自由移动和战斗；他受伤、受控、出圈都不影响守护计时 |
| 涂鸦主人以外的一名有效参赛者独自在喷漆区内累积喷漆进度 | 守护计时暂停；改漆失败（进度清零或暂停）时，守护计时从暂停处继续 |
| 涂鸦主人本人在喷漆区内 | 他不喷漆；只要不是有人独自在累积喷漆进度，守护计时就继续 |
| 涂鸦主人死亡或离局 | 涂鸦立即清除，旗杆回到无主状态 |
| 守护计时连续累积满规定时长 | 涂鸦主人获胜 |

定身、眩晕、嘲讽、击退只在施加的那一刻清零喷漆进度；之后即使仍被控制，只要他仍独自留在喷漆区内，就从 0 重新累积。
喷漆进度只属于本人，别人不能继承；暂停保留的进度在争夺结束、他重新独自在区内时从暂停值继续。
复活保护者不计入人数，既不能喷漆，也不能暂停别人的喷漆或守护，避免利用无敌状态争夺旗杆。

喷漆开始、争夺暂停、进度清零、喷上涂鸦、覆盖、守护暂停、涂鸦清除与获胜必须有清楚反馈。旗杆开放状态、喷漆进度、当前涂鸦主人和守护剩余时间属于全场公开信息，不受战争迷雾遮蔽。人数与边界判定以服务器上的真实位置为准，不依赖客户端画面或个人视野。

同一结算时刻先处理死亡、离局和控制，再处理喷漆和守护。达到完成时刻时，必须仍然满足对应条件；同一时刻已发生的争夺、离区、控制或死亡不能被跳过；服务器只能提交一次最终结果，结束原因为“守护成功”。

没有击杀数、财富、等级或超时积分胜利；无人守护成功时，对局继续，或由 Host 主动结束而不产生胜者。

## 3. 操作与战斗

### 3.1 MOBA 操作

操作参考 Dota / League of Legends 的通用交互，不照搬其英雄、技能、美术或音效内容。

| 输入 | 行为 |
| --- | --- |
| 右键地面 | 点击寻路移动，绕开不可行走区域；按住右键时按光标处地面持续更新目的地 |
| 右键可攻击目标 | 沿合法路径接近攻击距离并持续普攻；只锁定当前可见目标；失去视野后取消目标锁定，并停止这条追击订单。普攻前摇一旦在攻击距离内开始，出手时目标即使已离开攻击距离也照样命中，只要它仍可见且视线无遮挡（2026-11-06 用户决定） |
| 右键商店模型 | 与右键墙等障碍物完全一样：移动标记落在点击处，角色普通移动到模型旁最近的可走点（不与模型重叠；已经贴着时原地不动），不弹出页面、不减速（2026-11-05/06 用户决定） |
| 左键商店模型 | 原地打开商店页面，不移动；点击范围就是模型本身，不是模型周围的地面 |
| 左键 | 选择查看目标，或确认已准备的技能目标/地面位置 |
| A + 左键 | 攻击移动 |
| S | 停止移动、追击及可中断动作 |
| Q / W | 使用对应角色主动技能 |
| 1 / 2 | 使用对应装备的主动技能；没有主动效果时显示为不可用 |
| D | 通用冲刺（显示为“润”）：每名参赛者（含 AI）都有，按下即朝鼠标指针方向冲刺，不需要左键确认，与快速施法开关无关（2026-11-04 用户决定）；朝该方向快速冲出一小段，遇阻挡停在最远的合法位置；被定身时不能用；不消耗电量，有自己的冷却，不受整活频率影响；它是移动而不是进攻，不解除复活保护 |
| P | 打开或关闭自身属性面板 |
| 按住 Tab | 显示局内排行榜：每名参赛者的名字与击杀/死亡/助攻，击杀多的在前，相同时死亡少的在前；松开即收起（2026-11-05 用户决定：只列名字与 K/D/A） |
| 屏幕边缘、方向键 | 平移镜头 |
| 空格 | 镜头回到自身角色 |
| 镜头跟随开关、鼠标滚轮 | 切换跟随，或在允许范围内缩放 |
| Esc | 优先取消当前选定动作或关闭最上层面板，否则打开设置/退出菜单 |
| 对单位施放的 Q / W / 1 / 2 | 目标在施法距离外时，角色沿合法路径接近，进入施法距离后自动施放；在距离内则立即停下施放。施放后原地站立，不恢复之前的移动；技能本身无法施放（冷却、电量不足、受控制、空槽等）时立即拒绝，不开始走动；目标失去视野或死亡时取消（2026-11-06 用户决定） |
| 对地面点或方向投射的 Q / W / 1 / 2 | 指向的地面点在施法距离外时，角色朝该点走，直到该点进入施法距离再朝它施放；其余同上（立即停下施放、施放后站立、无法施放时立即拒绝）。冲刺类技能与 D 没有施法距离，仍按下即朝指针出手（2026-11-06 用户决定） |
| 按住 Shift + 右键 / A 左键 / Q W 1 2 D | 指令队列：把这条指令排在当前指令和已排指令之后，依次执行，而不是替换当前指令（2026-11-06 用户决定） |

使用固定俯视斜角镜头，不要求自由旋转镜头。输入绑定允许修改并保存；镜头速度、边缘平移与跟随偏好属于本地设置。

操作手感：保持 MOBA 点击操作，不改用方向键移动或朝鼠标方向攻击。右键地面在落点给出移动标记，路线不可达时给出红叉；右键目标在其身上给出攻击标记；光标悬停在可攻击的可见单位上时高亮该单位并换成攻击光标，悬停砍一刀小摊时换成交互光标。按住右键时角色持续朝光标移动（发令频率受限）。自身技能前摇尚未出手时按下的下一个技能键先暂存一个，前摇结束后作为普通请求发出；按 S、进入新生命或新对局、或暂存超过 1 秒时丢弃。可选的本地设置“快速施法”默认关闭；打开后，指针已指着合法单位或地面时按技能键直接施放，否则仍需左键确认。预输入与快速施法只改变客户端何时发出请求，服务器的准入与结算规则不变。

指令队列（2026-11-06 用户决定）：按住 Shift 下达的移动、攻击目标、攻击移动以及 Q/W/1/2/D 依次排在当前指令之后，由服务器保存，最多 8 条，再多时提示“指令队列已满”并拒绝。前一条结束后（到达、施放完成）才开始下一条；技能轮到时才由服务器按当时的规则判定，朝方向施放的技能（含 D）从角色当时的位置朝排队时指向的地面点出手。某一条失败或提前结束（路线不通、受阻、目标不可见或死亡、被掀飞、技能被拒绝）时跳过它继续下一条；按 S、下达任何不按 Shift 的指令或技能、死亡、新生命或新对局时清空整个队列；被嘲讽或被诱饵吸引时也清空，结束后不恢复。排队的进攻指令和技能在发出时就算作进攻意图，立即解除复活保护。每个排队的地面点显示一个小标记，并有一条虚线从角色经当前目的地连到各个排队点。Shift 固定用作队列键，不能改绑给其他操作。

技能可采用指向单位、指向地面、方向或自身释放等目标形式，由技能内容定义。释放前显示有效目标、范围或方向；无效输入不消耗资源，并反馈失败原因，但已通过身份/代次准入的进攻意图仍按 §7.1 解除复活保护。

点击 UI 不得同时向世界发送移动、攻击或施法命令。打开面板、选择升级奖励和修改设置都不暂停联机对局，也不赋予角色无敌。

### 3.2 属性模型

角色采用 MOBA 式战斗属性。下表固定属性含义，不包含数值和计算公式。

| 属性 | 作用 |
| --- | --- |
| 力大砖飞（物理攻击力） | 决定普攻及具有物理攻击加成的技能效果 |
| 阴阳怪气（法术强度） | 决定具有法术加成的技能效果；不默认让普攻变成魔法伤害 |
| 嘴硬（护甲） | 影响承受的物理伤害 |
| 心大（魔法抗性） | 影响承受的魔法伤害 |
| 手速（攻击速度） | 影响普攻频率 |
| 润速（移动速度） | 影响行走与追击速度 |
| 攻击距离 | 影响普攻的有效距离，不等同于所有技能的施法距离 |
| 精神状态、精神状态上限（生命资源） | 表示存活资源与上限 |
| 电量、电量上限（法力资源） | 表示技能资源与上限 |
| 精神状态回复、电量回复 | 决定相应资源的自然恢复 |
| 暴击率 | 影响允许暴击（会心一击）的攻击；不是所有技能自动获得暴击能力 |
| 整活频率（技能急速/冷却属性） | 影响适用主动技能的再次使用时间；面板与技能图标反映真实效果 |

**所有参赛者初始使用近战单体普攻**，普攻默认造成物理伤害。
装备或属性成长可以让普攻获得群攻效果、增加攻击距离；初始形态不是永久的近战/单体限制。
首版具体装备或属性路径、群攻效果与射程参数由内容和战斗设计提供，不因此强制采用投射物。

技能与装备明确标记伤害类型、属性加成、法力消耗、冷却和作用方式。属性面板应能解释基础值、成长与装备/状态带来的加成，不能只显示没有实际效果的字段。

**属性卡**可重复选择，每张每次都完整生效；少数“狂野”属性卡在带来较大加成的同时明确扣减另一项属性。
所有属性（含扣减后）统一限制在内容写明的上下限之内：超出上限的部分不生效，扣减后不低于下限，不会因此拒绝选卡、购买或进阶。

存活时，升级、属性或装备导致生命/法力上限变化，**保持变更前的生命/法力百分比**。
一次复合变更先算出最终上限，再统一换算当前值；精度与取整不得让反复换装/属性往返获得额外血蓝。
死亡等待中的构筑选择不治疗尸体或提前复活；正常复活仍按届时上限补满生命和法力。

**脱战慢回**：所有参赛者脱离战斗一段时间后，按当前精神状态上限和电量上限的固定比例持续恢复；一进入战斗立即停止。
“战斗”与被动“发疯文学”使用同一个判定（有效出手、伤害技能释放、承受伤害），两者可以叠加；死体不恢复，复活时刻重新开始计时。
延迟与比例写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

**躺平角**（D21）：地图边缘有 2 处公开的躺平角（快速回复点）。参赛者的脚点站在躺平角圆形判定区内（边界算在内），
并且脱离战斗满躺平角延迟后，每秒按当前精神状态上限和电量上限的固定比例快速恢复，约 10 秒从零回满；
它与脱战慢回、“发疯文学”各按自己的延迟起算并叠加。一进入战斗、离开躺平角或死亡立即停止，野怪不受影响。
躺平角不是安全区：不阻挡攻击、技能、视野或寻路，也不另加碰撞。位置、半径、延迟与比例写在
[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 按同一规则使用躺平角。

前摇、命中、伤害、控制、死亡及恢复使用一致的战斗规则。控制效果需要明确说明禁止的是移动、攻击还是施法，并在角色与 HUD 上可辨识。

**战斗联动规则**（#112）：

- **命中特效**只有吸血、横扫和开盒大师叠层三种。普攻主击按系数 1.0 触发；个别技能按其内容写明的系数触发。
  由命中特效、反伤或附加伤害（潜水党、折叠椅第三击等独立命中）产生的命中不再触发任何命中特效。
- **强化普攻**：一个滑铲的附加伤害在暴击判定前并入同一次普攻主击，因此可以暴击，并带动吸血、横扫和普攻命中特效。
- **技能暴击**：只有内容明确列出的技能可以暴击（掏蛋子 3 级、专攻下三路 3 级列出的技能），倍率 1.5；
  每次施放对每个目标只判定一次。其余技能仍不暴击。
- **技能吸血**按该次伤害实际扣掉的精神状态计算，不含心理防线吸收的部分和溢出伤害。
- **反伤**同时按反伤者的嘴硬与精神状态上限计算；反伤不暴击、不吸血、不再触发对方反伤。
- **受控增伤**（已截图）对处于定身、眩晕、缴械、嘲讽、击退或减速中的敌人生效。
- **硬控递减**：定身、眩晕、缴械、嘲讽是硬控；减速与击退不递减。同一身体在上一次硬控生效期间或结束后 2 秒内
  再中硬控时，持续时间依次为 60%、30%（第三次及以后），最短 0.2 秒；计数跨所有来源共享，连续 2 秒没有新硬控即清零。
- **剩余冷却缩减**：部分效果会缩短指定技能尚未结束的冷却；只改结束时间，不改基础冷却，缩到当前时刻即立即可用。
- **击退**是服务器强制的位移：沿地面把目标推开，遇到阻挡停在最远的合法位置，不传送；击退是一种控制，
  期间不能移动、普攻、施法或使用装备，并打断目标未出手的动作与当前移动/攻击指令。
- **诱饵**是不可攻击、不可选中的地面标记，到期消失；被它嘲讽的敌人被迫走向诱饵，期间不能攻击、施法或使用装备。
- **心理防线事件**：身上始终只有一份心理防线，新的不弱于当前剩余量才替换。替换一份仍有剩余量的心理防线叫“刷新”
  （从无到有不算）；被伤害打空叫“打破”，到期或被技能主动消耗、击碎都不算。由刷新/打破触发的效果所带来的控制或心理防线
  不会再次触发获得心理防线的效果。
- **减疗减盾**按比例降低目标受到的一次性治疗与心理防线获得量，同类效果只取最强、不叠加；自然回复与脱战慢回不受影响。
- **持续伤害、破防叠层与地面区域**按固定间隔结算，伤害按施放时的属性计算，不暴击；结束时削减的嘴硬与心大全部恢复。
- **负面状态**按定身、减速、缴械、眩晕、嘲讽、破防（含持续伤害）六种计数，同一种只算一次。

战斗效果、持续时间、距离、属性上下限和其他换算公式不在本规格中预设；
上述比例保留规则不授权任何具体基值或取整默认值。

## 4. 经验、金币与三选一成长

### 4.1 奖励与升级

击杀野怪或其他参赛者获得经验和金币。**野怪的两种奖励全部归完成最后一击的参赛者**，不设附近经验分摊或按伤害贡献结算。

**参赛者之间的击杀另有助攻（参考 LoL）**：

- **资格**：受害者死亡前 15 秒内（含 15 秒整），对其造成过正伤害（含被心理防线吸收的部分）或施加过任何控制与减益
  （减速、定身、眩晕、缴械、嘲讽、击退、破防、持续伤害、减疗减盾）的其他在局参赛者，算作助攻。
  每次新的贡献重新开始 15 秒计时；击杀者本人不算助攻；死亡中的参赛者仍可得助攻，已离局的不能。
- **金币**：击杀者拿全额击杀金币；另按受害者基础击杀金币的 50% 生成助攻金币（不含额外赏金），由助攻者平分，向下取整。
- **经验**：受害者的经验奖励由击杀者和所有助攻者平分，向下取整。
- 没有击杀者的死亡不发任何奖励，也没有助攻。15 秒与 50% 写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。


技能、装备效果或持续伤害造成的击杀也归属于其实际所有者。同一次死亡的击杀与助攻奖励一起结算、只结算一次；没有参赛者拥有该次致死伤害时，不凭空指定奖励获得者。

金币用于商店购买装备；经验用于升级。不开设任务、采集、制作、银行或玩家交易等额外经济循环；
唯一的地图拾取是公开的天降外卖（D26，见 §6.1），它与击杀奖励走同一套流量和米结算。

### 4.2 三选一

对局开始、进入发育期时，每名参赛者立即获得一次开局选择机会；之后每次从当前等级升到下一级，再获得一次选择机会。每次展示三个不同且当前可合法选择的选项，从中选择一个：

| 选项类别 | 结果 |
| --- | --- |
| 新主动技能 | 学习该技能，从 1 级开始，并装入角色主动技能槽 |
| 新被动技能 | 学习该技能，从 1 级开始，按条件自动生效 |
| 已学技能升级 | 将已有的主动或被动技能提升一级，最高 3 级 |
| 角色属性提升 | 获得本局持续生效的属性加成 |

三张卡不要求分别来自不同类别。新技能候选只包含当前未学会的技能；已学技能只能作为升级候选，满级后不再出现。每组选项都必须可兑现，属性选项可用于补足合法候选，但不得悄悄改变玩家选中的内容。

被动技能没有额外槽位上限，但仍受本局实际获得的选择机会和技能最高等级约束。装备被动不算一次角色学习，随对应装备生效或移除。

连升多级时，选择机会排队，逐次处理；前一次选择生效后再生成下一组候选，避免出现已经失效的升级选项。每组候选由服务器生成并保留，关闭页面、死亡或重复请求不能重新抽取。

选择页面可以暂时关闭，未使用的选择机会继续保留。选择本身不暂停世界，不强制替玩家自动选择。

**免费重抽**：升到 4 级、7 级时各获得 1 次重抽，可以留到以后用。每组候选最多重抽 1 次，重抽按同样的规则生成新的一组，并尽量不重复上一组的三张；重抽不消耗选择机会，也不能花米重抽。三选一页面提供重抽按钮并显示剩余次数。重抽与选择一样由服务器确认，同一请求重复到达只生效一次。

**死亡等待期间可以确认三选一及主动技能替换，只更新保留的构筑。**
合法选择仍消费对应机会并推进候选队列，但不会提前复活、治疗尸体、修改复活等待或产生身体战斗效果。
请求仍须属于当前 Match/Life；死亡前或复活前的迟到旧请求不能改动新生命。

开局选择机会每局只在对局开始时给予一次，复活不再给予；新一局重新给予。真人参赛者开局时选择页面自动打开一次，可以关闭，几秒内未操作或本人受击时自动收起为待选提示，机会继续保留，不替玩家自动选择。整局最多获得 10 次选择机会；达到 10 级后不再升级或新增选择机会，但仍可处理本局已经获得、尚未使用的选择。

**开局卡池**：开局那一次的三张卡固定为 2 个 1 级主动技能加 1 个 1 级被动技能，各自在可进卡池的技能中等概率抽取；卡池不足时明确拒绝开局，不用其他卡补足。

**升级三选一（第 2–10 次）**：前两个卡位从技能池抽；第三个卡位 65% 从属性卡池抽、35% 从技能池抽，因此每组最多 1 张属性卡。技能池中已学技能的升级权重 2.2；未学主动在 Q/W 有空槽时权重 1.5，满槽时 0.30，且满槽时每组最多 1 张新主动；未学被动权重 1.0。候选与你已学的其他技能和已穿装备共有 k 个机制标签时，权重再乘 min(1.30^k, 1.70)；已学技能的升级不把自己算进 k。按权重逐张不放回抽取，属性卡池内等概率。

每个技能和装备在内容数据里登记 1–3 个机制标签（普攻、位移、控制、护盾、挨打、破防），只用于上面的抽卡权重；界面、三选一卡片和装备说明不显示流派或标签名。内容数据标记为暂不进卡池的技能不会出现在任何三选一中。具体组成与参数写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

### 4.3 两个主动技能槽

角色主动技能只使用 Q/W 两个槽。空槽时可以直接学习；两个槽已满时，学习新主动必须明确选择要替换的旧技能，并确认后才消耗本次选择机会。

**被替换的主动技能会被遗忘**，不进入备用技能库、不返还米或已投入的选择。新学的主动从 max(1, 旧技能等级 − 1) 级开始。被遗忘的技能将来再次获得时，从 1 级重新学习。

装备主动使用 1/2，不占 Q/W。因此，角色最多同时有两个角色主动入口和两个装备主动入口；不是所有来源共用两个按钮。

升级、槽位调整或资源买卖不能成为重置尚未结束冷却的捷径。技能与装备能力要按其实际来源管理，不能因为图标换了位置就恢复可用。

**失去来源期间冷却继续计时，重新持有时沿用原结束时间。**
D 键通用冲刺以及带冲刺或跳跃的角色主动、装备主动，其冷却结束时间都在释放那一刻按当时的装备固定；
之后穿上或卖掉强化位移的装备（《润学指南》）都不改写它，不会因此提前或推后，换装不能成为刷新冷却的捷径。
遗忘技能或卖出装备不会冻结、清空或重新计算尚未结束的冷却；
重学同一技能或重购装备时，继承对应来源的原冷却结束时间，装备副本仍分别计时。

出售装备或替换遗忘技能后，已经成功释放的独立效果继续到原定结束，不因来源移除而取消。
需要持续装备或持续施法维持的光环、被动和引导不在此列，失去维持条件时失效；
仍在运行的独立效果不授予继续使用已失去技能/装备的权限。

## 5. 装备与商店

每名参赛者最多持有并装备两件装备，没有额外背包。**两个装备槽允许同时装备两件相同装备。** 装备可以只有属性，也可以带被动效果或一个主动入口。装备能力来自装备本身，不通过角色三选一提升等级。

同款双持时，**基础属性加成相加，同名被动只生效一次**。
**两份装备主动各自独立冷却**；当两份均可用且满足正常释放条件时，可以连续使用两次。
不能因为第一件进入冷却，就用同款共享冷却锁住第二件。卖出重买或更换槽位仍不能刷新未结束的冷却。

商店是地图中的固定交互对象，本体不可攻击。**商店周围不是安全区**；浏览、买卖期间仍可能受到攻击。

商店页面显示当前米、两个装备槽、商品价格、属性与效果说明，以及明确的购买和出售操作。必须有“米不够”“装备槽已满”“不在范围内”等可理解的失败反馈。

购买要求角色存活、对局进行中且处于交互范围内。槽位已满时，先在商店卖出旧装备，再买入新装备，不自动销毁或替换玩家的物品。卖出会移除对应属性与能力，并按出售规则返还金币。

商店不额外检查视线；满足合法接近区和交互距离即可。
服务器仍在交易提交时检查存活、对局阶段和真实位置，不能用先前寻路成功或接近票据代替当前资格。

**预购**：HUD 右下角的商店按钮（显示当前米与预购件数）在任何位置都能打开商店页面；不在商店时页面列出已批准的商品、价格与说明，只能浏览和预购，不能买卖或进阶。商品以图标网格显示（正式图标到位前用占位图标），悬停图标显示完整说明；右键图标时，站在商店交互范围内且已开张就直接购买，否则加入预购，页面没有单独的“加入预购”按钮（2026-11-05 用户决定）。预购最多 2 件，按加入顺序排队，整局保留（死亡不清空，新一局清空），点预购项可取消。角色存活并站在商店交互范围内时，按队列顺序自动买入第一件米够且有空装备槽的预购；一次只发一笔，价格以当时商店报价为准，仍走正常购买并由服务器检查资格。买入（自动或手动）后从预购中移除一件同款；被拒绝时保留，等米、装备或报价变化（或几秒后）再试。预购不会卖出或替换已有装备。

离开交互范围或死亡后不能继续交易；交易只在服务器确认成功后变更金币与装备。重复点击、延迟回包或重复请求不得造成重复购买、重复出售或额外金币。

**装备进阶**：在商店花 240 米进阶一件已穿装备，每人整局只能进阶 1 次，卖掉进阶过的装备后也不能再进阶别的。进阶后固定属性提高 35%（按各字段精度向下取整），被动与主动增强一档。进阶状态绑定这件装备，卖出即失去；出售价仍按买价 × 0.65 计算，进阶费不返还。进阶不刷新任何冷却。同款双持时，同名被动只生效一次，有进阶的一件优先；两件的主动按各自是否进阶分别计算。商店页面在每个装备槽旁提供进阶入口并显示进阶后的效果。

装备目录必须覆盖属性加成、主动效果和被动效果，并支持有取舍的战斗构筑。不要求制作合成树、消耗品、商店刷新、稀有度抽奖或庞大装备目录。

占领点要有可辨识的喷漆区边界和接近路线，不能通过不可行走地形从外部计入喷漆区。障碍布局需要支持绕行、追击、撤退与视野取舍，不以巨大面积或大量装饰性地点作为目标。

10 个出生点是预先布置的合法落点。开局出生和每次复活都从这同一组点中完全随机选择，各点被抽中的机会相同，不按敌人距离、视野、危险程度或胜率筛选，也不优先沿用本人的初始点。允许再次抽到同一点。

若多个角色同时落在同一点，只进行必要的合法落地、防重叠处理，不借机重新选择“更安全”的出生点。

**天降外卖**（D26）：从开局起按固定节奏在公开落点之一落下一份外卖；每一份都提前公开落点和倒计时，所有人同时看到。
每份的落点由服务器从上一份以外的落点中随机选出，到公告时才公开，不能从已公开的信息推知。
落地后，第一个脚点进入拾取圈（边界算在内）、且不在复活保护中的存活参赛者独得一份流量和米；
同一时刻有多人在圈内时，离中心最近者得，仍并列时由服务器随机决定。
公开信息只有落点、落地时间和“已被领走”，不公开是谁、在何时领走；领取者本人会得知。
任何时刻只有一份当前外卖：下一次公开时，上一份不论是否被领走都被取代。
时间、拾取半径、奖励与落点写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 按同一规则争夺。

**上热搜**（D27）：从开局起按固定间隔刷新一次。刷新时仍在对局中的参赛者里，等级唯一最高且不低于门槛者上热搜；
等级相同按击杀数定，仍相同则本次无人上热搜；被选中者此刻已死亡也不上热搜。上热搜对所有人公开：名字、赏金和小地图上的一个
模糊圆，圆心是其此刻脚点加一个不超过圆半径的随机偏移，因此本人一定在圈内，但圆不随其移动，直到下次刷新。
连续上热搜每次加一档赏金，有上限；击杀上热搜者的人在正常击杀奖励之外另得致死瞬间的赏金；这是额外赏金，不计入助攻金币的基数。上热搜者死亡即结束本次上热搜，
下次刷新重新计数。间隔、门槛、圆半径、偏移和赏金写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

**画饼老板 Boss**（D26）：每局只出现一次。开局后固定时间出现在第一个公开巡逻点，按顺序沿四个巡逻点循环巡逻，
走合法导航。它优先追打最近一段时间内打过它的参赛者（其中最近的一个），否则打攻击半径内最近的可见参赛者；
它与野怪一样受视野与隐身规则约束，身体只在合法视野内可见。公开的只有出现时间、是否存活和最后一击者，
不公开它的实时位置或血量。它不复活；最后一击的参赛者获得一份流量和米，并“吃到大饼”：一段时间内
力大砖飞、阴阳怪气和润速按比例提高（死亡时随身体消失）。被它击杀计为“被 画饼老板 淫了”。
数值与巡逻点写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 会主动避开它，不会主动挑战它。

### 6.2 野怪

地图固定设置五组野怪，覆盖两档难度。具体分配、每组数量、能力与收益交由 Demo 内容和数值设计确定。

野怪不是对手 AI 参赛者，不购买装备、不选择成长、不计入喷漆区人数、不能获胜。
**未受攻击时不主动攻击；同组成员受击后共同反击，但不共享隐藏坐标。**
目标选择和追击仍遵守合法感知；超出营地活动范围或失去目标后返回，避免被永久拖离营地。

返回营地期间仍可受到伤害、控制或被击杀，受击不会使其回头重新追击。
成功回到营地后，仅存活成员恢复满生命/法力、清除临时效果和仇恨、使技能就绪；
不复活已经死亡的成员、不产生奖励，也不将回位当成一次新生命。
回位找不到合法路径时（#28）：连续规划被拒或长时间没有进展达到[内容与数值](demo/CONTENT_AND_BALANCE.md)的上限后，
该成员在原地按同一规则重置（不传送回家、不发奖励）。此后它在营地活动范围外坚守原地：受击时就地反击，
不追击、也不因活动范围返回，失去目标且宽限期结束后才再次尝试回家；回到家中重置后恢复正常规则。
这是野怪回位规则，不改变参赛者的死亡保留冷却或上限变化保持百分比规则。

营地被清空后进入刷新等待，随后重新生成该组野怪。每个野怪生命的死亡与奖励独立且只结算一次；回位重置不等于死亡，不能发放奖励。

基础角色只靠初始近战单体普攻就必须能够开始低难度打野和首次升级。高难度营地应体现更高风险与成长价值，不能只是外观不同。

### 6.3 局部视野与战争迷雾

每位参赛者只有自己的局部视野，真人和对手 AI 遵守同样规则。地图地形、固定营地、商店和占领点位置可以公开；隐藏单位的位置、当前行为和资源状态不能持续透过迷雾更新。

离开视野的敌人不再提供实时位置，不能通过镜头平移、选择面板、小地图、寻路目标或 AI 决策绕过限制。地形的“阻挡行走”与“阻挡视线”需明确区分。

目标失去视野时取消锁定，并停止与该目标绑定的追击订单，不自动走向其最后可见位置。
首版不保留 LastSeen 单位标记，世界和小地图只显示当前合法可见单位；过期信息不能伪装成当前观察。

查看当前可见对手时，只展示名称、角色等级、血量、蓝量、状态、装备，以及 Q/W 两个主动技能的图标、等级和 Lv3 标记。
不展示冷却、被动列表、完整属性或金币；可见动作/外观表现不等于授予这些私有字段。
失去视野后清除该目标的当前查看信息，不通过面板保留实时观察。

存活时，小地图展示自身位置、固定地点、视野覆盖及当前合法可见的单位。旗杆的喷漆与守护状态、全场击杀通知与上热搜的模糊圆（D27）是明确的公共信息例外，但不能附带无关的隐藏位置或构筑数据；
上热搜只公开刷新瞬间的模糊圆，不公开实时位置。
天降外卖只公开落点、落地时间和是否已被领走，不公开领取者或领取时间（领取等于暴露此刻身在落点）。

侦察和藏匿主要来自移动、障碍与视野。当前核心 Demo 不要求隐身系统、插眼道具、昼夜循环或可破坏地形。
2026-11-02 批准的构筑扩展方向允许在核心门槛之后的扩展批次接入隐身，合同与建议值由内容报告 §15 单点维护；
文字换皮不启用隐身，也不改变当前观察权限。

## 7. 死亡、复活与对手 AI

### 7.1 死亡与复活

死亡后角色退出战斗和喷漆区判定，清零自己的喷漆进度；若他是涂鸦主人，涂鸦立即清除。向玩家显示“你寄了”及“回出租屋 emo”倒计时。
等待结束后，从随机出生点以完整生命值、法力值复活，清除死亡前的临时控制状态。
“回出租屋”是等待文案，不增加出租屋地图、可操作身体或提前返回战场的入口。

**死亡只损失等待时间和场上位置。等级、经验、技能、装备、金币及未处理的升级选择全部保留。** 不掉装备，不扣金币，不重新发放成长或初始奖励；已有冷却按时间继续，不因死亡自动刷新。

正常死亡取消尚未释放的动作；已经成功释放的独立效果继续到原定结束，
后续击杀仍归属于留在本局的实际释放者。旧目标生命上的排队命中或持续伤害不能转移到复活后的新身体。
这不同于正式离局：退出/断线时，身体和未结束独立效果按 §9 立即清理。

死亡等待期间可以自由拖动镜头查看地图，但世界观察只使用静态地图和既定公共信息；
不新增活体视野，不能跟随或观察隐藏玩家，也不继续展示死亡前缓存的单位标记。
自身保留的构筑与候选仍可按 §4.2 查看和确认。

复活后有短暂保护（显示为“免死金牌”），不受伤害和控制。**只要发出进攻意图，就解除保护**：
服务器先确认合法调用身份、当前 Match/Life、请求通过去重/拒旧校验且终局写闸开放，
再因普攻、施法或装备主动意图解除保护，之后才校验具体动作条件。
即使目标、距离、蓝量等无效而无法执行动作，也不会恢复保护；未通过动作校验的请求不扣资源或启动冷却。
伪造身份、旧局/旧生命、重放失效请求或终局后的请求不能借此改动角色。
保护期间可以移动，但不计入喷漆区人数，不能喷漆，也不能暂停别人的喷漆或守护。保护状态和剩余时间必须可辨识。

### 7.2 对手 AI

对手 AI 是可独立获胜的参赛者，而不是站立靶子或只会巡逻的 NPC。至少能够自主完成：

- 找到适合当前战力的营地，打野获得经验和金币。
- 处理升级三选一，使用所选主动、被动和属性构筑。
- 前往商店购买装备，必要时出售并更换装备，使用装备主动。
- 与真人或其他 AI 战斗，根据局势追击、撤退和恢复。
- 在旗杆开放后去喷漆并守住自己的涂鸦；旗杆上是别人的涂鸦时围攻涂鸦主人或去改漆；看到公开的对手喷漆进度时，用定身、眩晕、嘲讽等硬控或击杀打断他。
- 状态良好时争夺公开的天降外卖。
- 等级达到上热搜门槛且状态良好时，前往上热搜者的模糊圆追猎赏金。
- 进入画饼老板的索敌范围时主动走开；不主动挑战 Boss。
- 死亡等待、随机复活并继续对局。

AI 使用同一套属性、奖励、经济、技能槽、死亡和胜利规则。它可以读取自身状态、合法视野和旗杆的公共喷漆与守护信息，但不得直接获取迷雾中的敌人位置、免费生成资源或绕过商店与施法条件。

Demo 只要求一种可完成核心循环的 AI，不要求机器学习、多档难度或模拟人类社交。

关键状态不能只依靠颜色区分。喷漆、涂鸦、死亡、受击、技能释放与购买结果需要明确的视觉反馈，关键全场事件应有简洁音效或提示。可见单位施放技能或装备主动的那一刻，头顶飘出技能显示名，不显示等级和冷却；目标查看仍不列出技能。旗杆挡住本人或可见单位时淡化。占位素材不能妨碍辨认敌我、自身、野怪与交互对象。


角色、场地道具与音效只使用确认为 CC0 的素材，并随素材记录来源与许可。道具只做装饰：不产生碰撞、不阻挡视线、不改变寻路，也不改变已批准的地图几何。

## 9. 联机与数据边界

采用 Unreal Listen Server：Host 一边运行权威世界，一边作为一名普通参赛者游玩；最多另有两名真人客户端连接。对手 AI 和野怪由 Host 驱动。

IP 直连验收覆盖局域网，以及正确配置防火墙、端口映射后可到达的公网地址。**不承诺家庭网络之间免配置连接，不实现自动 NAT 穿透或中继。**

移动合法性、伤害、经验、金币、三选一候选、装备交易、随机出生、复活和胜负均由服务器裁定。客户端可以立即表现操作意图，但不能自行确认购买、奖励或胜利。

计时以服务器为准，客户端显示同步后的状态。对手 AI 与真人使用相同的权威玩法接口，视野展示不得泄露只属于服务器或其他玩家的私有数据。

对局开始后锁定参赛名单。Demo 不提供中途加入、断线重连或 Host 迁移；普通客户端断线视为离开本局，其他参赛者继续按喷漆与守护规则游玩，不因人数减少自动获胜。离开连接本身不算一次击杀。

服务器确认正式退出或断线后，立即移除该参赛者的身体，不留可攻击或阻挡道路的身体；
立即取消其未结束的独立效果，离局者不再继续影响战斗。此前已提交的伤害、奖励和回执不因清理回滚，
但不能再由该离局者的残留效果产生新的命中或奖励。其本局结算记录保留到结果提交。

Host 离开或连接丢失导致会话结束时，客户端返回菜单并显示原因，而不是停留在失效的世界中。需要清楚区分房间已满、对局已开始、版本不兼容、地址不可达等失败。

所有战力与经济数据仅属于本局。新局重新初始化角色、选择、装备、金币、经验、冷却、野怪与旗杆喷漆、涂鸦和守护状态；本地名称及设置可以保存。

## 10. 内容与数值设计边界

**本规格只固定会议给出的结构数量，不填写平衡数值，也不给“临时默认值”。**

| 本规格已固定 | 需要针对同一个 Demo 专门设计 |
| --- | --- |
| 人数、地图对象数量、等级上限、选择次数、技能与装备槽位、技能等级上限 | 发育期、喷漆、守护、复活、保护、野怪刷新等时长 |
| 奖励归属、死亡保留、技能遗忘、商店买卖和喷漆打断、守护暂停规则 | 初始资源、经验曲线、击杀与打野收益、商品价格和出售回报 |
| 属性类别、主动/被动来源与视野规则 | 属性基值、等级成长、伤害与减伤、暴击、回复、冷却等计算 |
| 地图包含的功能地点和可通行/视野要求 | 地图尺度、喷漆区大小、射程、移速、视野、野怪追击范围 |
| 三选一类别与合法性 | 具体技能与装备目录、各级效果、随机权重、叠加与触发规则 |

数值设计必须检验：基础角色可以开始发育；升级和装备确实能形成优势；高难度营地有合理风险收益；从地图各区赶回旗杆打断喷漆、围攻涂鸦主人有实际可能；控制、复活和保护不能让喷漆或守护永久无法完成；不存在稳定的买卖套利或无限奖励循环。

最终内容只需足以展示不同战斗选择及主动、被动、升级、属性、装备之间的取舍，不因“完善目录”扩大 Demo。技能、装备和野怪的具体内容仍需针对本 Demo 选定，不能把属性或槽位框架本身当作完整可玩内容。

数值方案确定前，不把喷漆或守护时长、属性或售价写死为产品事实；技术占位数据也不代表已批准的平衡方案。

## 11. Demo 完成标准

| 验收场景 | 必须达到的结果 |
| --- | --- |
| 正常启动 | 从主菜单进入 Lobby，经准备与开始进入对局；设置和退出有效 |
| 满规模联机 | 3 名真人与 3 个对手 AI 在同一局独立参赛，未占用名额不产生额外角色 |
| 地图与寻路 | 唯一旗杆（喷漆区）、五组两档野怪、唯一商店和十个合法随机出生点齐备；路径遵守地形阻挡 |
| 营地反击与回位 | 未受击不主动；同组受击共同反击但不共享隐藏坐标；返回途中可受伤/控制/击杀、不回头重追；到家仅存活成员满血蓝、清临时效果/仇恨、技能就绪，不复活死者或发奖 |
| 从零发育 | 基础角色依靠初始近战单体普攻打野获得经验与金币，完成升级选择和商店购买 |
| 普攻成长 | 通过首版装备或属性路径使普攻获得群攻效果、增加攻击距离，效果与有效范围真实生效；不把初始形态限制为永久单体近战 |
| 成长边界 | 最高 10 级、最多 10 次三选一（开局一次，每次升级一次）；每个技能不超过 3 级；连升多级和延迟选择不丢失、不重复；死亡等待可确认选择，只更新构筑，不复活或治疗尸体 |
| 三选一与重抽 | 开局一组为 2 个 1 级主动 + 1 个 1 级被动；升级三选一按已批准的技能池权重与机制标签亲和抽取，每组最多 1 张属性卡、满槽时最多 1 张新主动；界面不显示流派；4 级、7 级各得一次免费重抽，可保留，每组最多重抽一次且不消费选择机会，不能花零花钱重抽 |
| 上限变化 | 存活时升级/属性/装备变动保持原生命/法力百分比；按最终上限一次换算，往返操作不因精度/取整获益；死亡不因此复活，正常复活仍满血蓝 |
| 技能替换 | Q/W 不超过两个；满槽学习明确替换，新主动从 max(1, 旧主动等级 − 1) 级开始，旧技能被遗忘，不返还零花钱或选择次数，以后再学从 1 级开始；遗忘期间冷却继续，重学沿用原结束时间 |
| 装备边界 | 不超过两件装备，允许两件同款，无额外背包；属性相加、同名被动一次、两份主动独立冷却；失源继续计时、重购沿用原结束时间；交易在合法区域/距离内提交，不额外检查视线 |
| 装备进阶 | 在商店花已批准的进阶费进阶一件已穿装备，每人每局只能一次；固定属性按批准比例提高，被动与主动增强一档；进阶绑定该件，卖出即失去且进阶费不返还；不刷新任何冷却；同款双持时同名被动只生效一次且进阶件优先 |
| 奖励与死亡 | 野怪由最后一击独占经验与金币；参赛者被击杀时，击杀者拿全额击杀金币，死亡前 15s 内造成过正伤害或施加过控制/减益的其他在局参赛者为助攻者，平分受害者基础击杀金币的 50%，经验由击杀者与助攻者平分（均向下取整）；无击杀者不发奖；一次死亡的击杀与助攻奖励一起只结算一次；死亡后成长财产保留；已释放独立效果继续并归属仍在本局的释放者，未释放动作取消；等待后随机复活 |
| 复活保护 | 保护期间免疫伤害和控制，不计入喷漆区人数，不能喷漆或暂停他人的喷漆与守护；身份/当前 Match/Life/终局写闸准入后的进攻意图即解除，目标/距离/蓝量无效也解除；旧包不改新生命 |
| 喷漆与守护 | 发育期不能喷漆或获胜；开放后独自在喷漆区满喷漆时长即喷上涂鸦并覆盖原涂鸦；多人在区内时所有人的喷漆进度暂停保留；离区、死亡、离局及定身/眩晕/嘲讽/击退清零且他人不能继承，普通伤害、减速、缴械不清零；涂鸦主人受伤、受控、出区不影响守护，他人独自喷漆时守护暂停、改漆失败后续计，主人死亡或离局立即清除涂鸦；守护连续满时长唯一获胜，结束原因为“守护成功” |
| 战斗原语 | 定身、眩晕、缴械、嘲讽按共享递减链缩短（减速与击退不递减）；击退沿地面停在最远合法位置并打断目标的移动与攻击订单，被击出喷漆区按离区处理；只有列明的技能可技能暴击，每次施放对每个目标只判一次；命中特效、反伤与附加伤害产生的命中不再触发命中特效；护盾只有一个记录，“刷新”与“打破”按批准定义触发，到期不算；负属性进入投影后仍受各属性下限约束 |
| 视野一致 | 当前可见对手仅按名称/等级/血蓝/状态/装备及 Q/W 主动图标、等级与 Lv3 标记的白名单查看，不显示冷却、被动列表、金币或完整属性；失视停追击且无 LastSeen 标记；死亡镜头只观察静态/公共信息；隐藏单位不泄露 |
| AI 可玩 | AI 能自主发育、选奖励（含重抽与替换）、购物与进阶、战斗、复活，并能喷漆、围攻涂鸦主人、以硬控或击杀打断改漆，通过同一守护条件获胜 |
| UI 完整 | 自身 HUD/技能/属性、可见目标查看（含对手 Q/W）、商店（含进阶入口）/成长（含重抽按钮）/死亡/设置均可操作；喷漆进度、涂鸦主人与守护剩余时间在 HUD 与旗杆涂鸦上公开可见；击杀播报列出助攻者；结算含全部参赛者名称/击杀/死亡/助攻/最终等级、赢家、结束原因和用时，不用统计判胜 |
| 网络失败 | 超员、开局后加入、地址或版本失败有明确反馈；普通离局身体立即移除且未结束独立效果取消；Host 退出不会使客户端卡在无效对局 |
| 新局隔离 | 返回 Lobby 再开局后，对局数据完全重新初始化，只保留明确允许的本地设置 |
| 正常完整对局 | 不依赖调试授予、传送或强制判胜，能完成发育、对抗、喷漆、守护与围攻、获胜和结算的闭环 |

验收时使用已批准的实际数值验证时长、边界、资源与效果，不能以“有这段代码”“有按钮”或“有动画”代替规则成立。
