# Lockdown Demo App Spec

**目标版本：v0.11.0**

**平台：Windows PC，键盘与鼠标，Unreal Engine 5.8.4**

本文定义首个可玩 Demo 的产品规则和验收要求，不是当前代码的完成声明。
开发方式见 [开发指南](DEVELOPMENT.md)，AI 协作约束见 [AGENTS](../AGENTS.md)。

## 1. 产品目标与范围

Lockdown 是一款采用 MOBA 操作和俯视斜角镜头的自由混战游戏。每位参赛者通过争夺野怪、击杀对手和成长构筑建立战斗优势，再把优势转化为在唯一旗杆上喷上并守住自己的涂鸦。

**核心循环：探索与侦察 → 战斗获取经验 → 选择成长 → 判断继续发育还是去旗杆 → 喷上涂鸦并守住获胜。**

击杀和等级都是获胜手段，不是独立胜利条件。策略同时来自构筑、资源争夺、局部视野、进退时机，以及喷漆、守护与围攻涂鸦主人之间的取舍，不以堆叠系统数量作为深度。

| 项目 | Demo 范围 |
| --- | --- |
| 对抗关系 | 所有参赛者各自为战；没有队伍或共享胜利 |
| 真人 | 最多 6 人，包含 Host 本人；与 AI 共用六个名额 |
| 对手 AI | 最多 3 个；与真人一样独立参赛，不是队友 |
| 总规模 | 最多 6 名参赛者；野怪不计入参赛人数 |
| 地图 | 一张地图，1 个占领点（旗杆及其喷漆区）、34 组野怪、3 档野怪难度（随对局时间变强）、2 处躺平角、12 个预设出生点 |
| 角色 | 所有人使用相同的基础角色，开局只有近战单体普攻；身份通过名称、头像和可辨识外观区分 |
| 成长 | 从 1 级到最高 16 级；用属性点购买五维属性：开局 3 点，每次升级 3 点，16 级后按流量继续给点；开局一次主动技能三选一，3 级、6 级各额外一次（§4.2） |
| 角色技能 | Q/W/E 共 3 个主动技能槽；每个技能只有一级，数值随角色等级成长；基础构件、改装件与连接件改变构筑（§4.4） |
| 联机 | Host 同时作为玩家和 Listen Server；其他真人通过 IP 直连 |
| 表现目标 | 功能 Demo，可使用占位资源，但游戏状态、攻击、技能、视野、喷漆、涂鸦与 UI 必须清晰可辨 |

本文只定义这个 Demo。不设置跨局战力成长、长期世界模拟或后续版本路线图。

### 1.1 雾港世界观与表现

对外标题为 **《谁是雾港最强淫人王》**，副标题为“脆皮大学生无差别大乱斗 · 旗杆上插谁的名，谁就是淫人王”；
技术项目名仍为 **Lockdown**。“淫”是雾港黑话，只指把人揍趴下，可以公开用于标题、菜单、击杀播报
（“X 把 Y 淫了”）与宣传文案。主菜单常驻一行小字：“雾港黑话：淫 = 把人揍趴下，跟色情没关系”。

舞台是雾港大学城后街的烂尾球场：白天有人跑步，晚上全是来“整活”的。沿用
[世界报告](demo/WORLD_CAMPS_AND_VISION.md)中已批准的单层地图布局。真人与对手 AI 都是已成年的
“脆皮大学生”（一碰就碎，但嘴很硬）；野怪也按成年人表现：低档野怪显示为已读不回的 HR（两只一组），
高档野怪显示为追着办卡的私教，外圈高台上的精英野怪显示为催毕设的导师。它们仍是非参赛者，不因此增加席位或改变野怪规则。

基调是简中互联网与贴吧式的整活：人人嘴硬、到处是梗，不中二、不严肃。梗留在名称、播报与界面口吻里，
规则用词保持通用（见 §1.2）；生命归零表现为“寄了”或“被淫了”，复活等待表现为“回出租屋 emo”。招牌阴招是扒裤子与掏蛋子：它们是定身技能 S02 与眩晕技能 S03 的显示名，这两个名字固定不换。
名称、衣物和尴尬动作的表现不改变原有伤害类型、控制期限或动作权限。

内容边界：

- 扒裤子只露出夸张的大花裤衩或秋裤，不露身体；掏蛋子隔着衣服、卡通化表现。
- “淫”只指把人揍趴下。以上表现都不带性意味，不做裸露或色情。
- 不做血腥。
- 不美化毒品：世界观里的“禁药”只作背景，不做成技能或其他条目。
- 不使用真实品牌名或商品名。

这次换皮只改玩家可见文字；美术、音效、数值、机制、
内容 ID、显示键、枚举与地图几何都不变。参赛者外观后来换成篮球手（hooper，按座位色重染球衣），画饼老板 Boss 换成持铁勺、披布料披风的厨师（chef），其余野怪与场地外观不变，
等正式美术（[#93](https://github.com/rlsn/Lockdown-alpha/issues/93)）按雾港世界观统一。
技能与属性目录统一见[内容与数值 §4](demo/CONTENT_AND_BALANCE.md#4-技能状态和属性目录)，
不是新增另一套玩法模式，也不扩大当前完成门槛。

## 2. 对局流程与胜负

### 2.1 从菜单到结算

主菜单提供 **开始、设置、退出**。开始入口提供创建房间与通过 IP 加入房间。Lobby 也提供设置入口，关闭设置后返回原房间，不改变准备状态。

房间展示参赛者名称、真人/AI 标识、Host 标识和准备状态。Host 设置 AI 数量；未使用的名额无需自动补满。所有已连接真人准备后，由 Host 开始。单人也可以创建房间进行练习，使用同一套玩法规则。

对局开始时，参赛者站到同一封闭公共休息室内的各自槽位，角色状态初始化，野怪生成，然后进入开局休息 R0。

**外层流程**：开局休息 R0 → 野外 1 → 休息 R1 → 野外 2 → 休息 R2 → 野外 3 → 休息 R3 → 最终野外（旗杆开放）→ 结算。
时长写在[内容与数值 §3.4](demo/CONTENT_AND_BALANCE.md#34-空间与对局节奏参数)（`MATCH.FieldSegmentSec`、`REST.*`、`LIFE.RespawnSec.*`）。

- **对局时间**：服务器只有一条单调时钟。野外进度 T 只在野外推进，休息与 PK 期间暂停；三段定时野外各 `MATCH.FieldSegmentSec`。
  营地刷新、野怪成长阶段、画饼老板、天降外卖与上热搜都按 T 计时，休息既不消耗也不跳过它们。
  对局用时（小地图计时与结算用时）从开局、即 R0 开始时起算，包含休息。
- **公共休息室**：
  同一对局、世界与连接中的真人和 AI 共处封闭休息室，保留身份与成长记录，互相看见人物与原有公开状态，不公开他人的背包或完整成长。
  参赛者之间不能攻击、施加控制或伤害，但仍可攻击共享训练假人。三个 NPC、北侧训练区与全部活体真实假人对休息室连接可见；
  各连接经获准观察帧看到同一目标的位置、生命与状态，不用静态模型代替。假人只按所属槽位的公开角色等级生成无构筑底盘，
  不泄露所属玩家背包或私有成长；不能接触冻结野外或 PK 场内身体。取代私人休息位与私人假人，不保留双模式。
- **准备提前结束配装**：所有真人都准备后，配装提前结束，只保留最后 10 秒报名，之后结束休息。
  准备仅属当前 match/rest 配装窗口，AI 不阻塞；准备不可撤销。所有仍在局真人准备后只把剩余配装时间缩短到 `REST.SignupSec`，
  已在最后报名窗口时不延长；重复准备不会重置窗口。截止仍走站圈报名、锁名单、PK 或返回倒计时，不立即跳过报名。
- **休息步骤**：先是配装（R0 为 `REST.OpeningBuildSec`，R1–R3 为 `REST.BuildSec`），其最后 `REST.SignupSec` 兼作 PK 站圈报名，截止时刻仍可报名：
  报名是实体的——所有人共用一个可见报名圈，脚点站在圈内即为已报名，走出圈即取消，截止时刻圈内的人就是锁定名单；没有报名按钮。圈半径复用 `AIRDROP.PickupRadiusCm`。
  截止时锁定报名名单。锁定的报名者至少 2 人时，依次进行抽签、押注、PK 准备、PK（有上限，提前分出结果即结束）、结算与派奖；
  不足 2 人时直接进入返回倒计时 `REST.ReturnSec`。自己的构筑命令（选技能、学图纸、加点、开局构件、安装/拆下/搬动构件、精英二选一）
  在每个休息步骤都可以做，PK、押注与返回倒计时中也不锁，
  不锁定报名者的构筑快照：每次权威构筑变更直接投影到当前 PK 生命。休息 NPC 服务（§4.4）只在配装与派奖期间受理，
  其他步骤拒绝并提示“PK 与返回倒计时期间不能找 NPC”。返回倒计时内移动、攻击、施法与冲刺都被拒绝，提示“还没开始呢，急什么”；被拒绝的请求进入野外后也不会生效。
- **进入休息**：每个存活的野外角色直接离场，不算死亡，不计击杀、死亡、奖励，也不产生复活等待；仍在等待的复活等待结束。
  所有进行中的效果（投射物、待结算命中、区域、引导、地面效果）与控制、减速、限时加成、标记、灼烧、破防、护盾、嘲讽、强化及硬控递减一律清除，
  不产生命中或死亡；每人以满生命/法力、全部冷却与普攻就绪的新身体进入休息位。
- **返回野外**：同样清除休息中的效果。进入休息时存活的人回到原脚点；原脚点被占用时在其 `REST.ReturnSearchRadiusCm` 内、同一可达地面上找不重叠的位置，
  仍找不到则正常随机出生；进入休息时已死亡的人正常随机出生。新身体满生命/法力、冷却就绪，所有人获得 `LIFE.ProtectionSec` 复活保护。R0 结束即全员首次进入野外。
- **共同入场**（外层参数 §1：“阶段资源/加载未就绪时冻结入场，30秒仍无法建立合法场景则本场NoContest并明确报错，不偷偷改阵地或开赛”）：
  返回野外与 PK 入场都先为全体准备好位置，再一次性共同提交；只要有一人放不下，谁都不入场，T、旗杆与 PK 计时都停在边界，之后每拍重试。
  超过 `REST.EntryReadyTimeoutSec` 仍放不下时，PK 记为场地失败（NoContest，不发奖励），选手回到休息位；返回野外则以权威故障明确报错，不偷偷开赛。
- **野外冻结**：休息时野怪与画饼老板原地冻结，保持生命/法力，不回复，不能被攻击，也不行动；返回野外时从冻结处恢复，生命不变，忘掉原目标重新索敌；休息中不刷新、不回复（批准规则：随 T 冻结并保留剩余生命）。
- **野外复活等待**按死亡时的 T 固定：野外 1、2、3 与最终野外分别为 `LIFE.RespawnSec.Field1/Field2/Field3/Final`。
- **PK**（[外层参数 §2–§4、§6](https://github.com/rlsn/Lockdown-alpha/issues/198#issuecomment-6752601175)）：锁定后才抽赛制与分队——2 人单挑；3、5 人混战；
  4、6 人按 `PK.TeamFormatRatio` 在混战与等分随机两队（全部无标号等分中均匀抽取）之间选择。PK 准备时选手的休息生命结束，
  在以旗杆点为中心、半径 1000–1400 cm 的 6 个已批准 PK 出生锚点上站起（满血满蓝、技能就绪、无保护、同队友伤关闭、同队共享视野），
  3 秒内禁止移动与攻击。PK 在原地图进行，安全圈按 `PK.*` 缩小（1800→600→150 cm，节点 0/10/40/55/60 s，提前 `PK.RingPreviewSec` 显示下一圈），
  圈外按开赛时最大生命的 5%/12%/25% 每秒、每 `PK.RingDamageTickSec` 结算真实圈外时长，直扣生命、不吃抗性护盾、不触发构件与奖励。
  最后一方存活即胜并提前结束；时限到仍有多方存活或同批全灭为平局。被淘汰者立即回到休息位只读观战，不复活。
  结算：以 `PK.ParticipationPoints` 乘符合资格的选手数作为参与奖池；胜方基准奖池为 `min(ceil(N/2), PK.WinnerPointsMax)`；
  竞猜基准奖池为 `min(PK.BettingPoolMaxPoints, 竞猜资格观众数)`。所有三类奖池都乘 `PK.RewardMultiplier` 后向上取整，
  再按场次序号与席位顺序轮换分配；参与奖只分给未弃权且仍在局的选手，胜方奖分给未弃权且仍在局的胜方成员（包括已淘汰但仍在局的队友），
  竞猜奖分给猜中且仍在局的观众。平局只发参与奖，场地失败（NoContest）不发。点数是未分配属性点。
  PK 死亡不给击杀/助攻奖励、不计 K/D，不进入喷漆名单。
- **观众**：锁定时在场且未报名的参赛者可在押注步骤免费押一方（可改，步骤结束封盘），PK 中可向 PK 区内合法地面投掷：
  冷却 `THROW.CooldownSec`（自成功投掷起）、预警 `THROW.TelegraphSec`、半径 `THROW.RadiusCm`、从场外投掷锚点起射程 `THROW.RangeCm`，
  命中落点视线内的任一选手：减速 `THROW.SlowRatio` `THROW.SlowSec` 并暴露 `THROW.ExposeSec`（只向本场选手揭示位置），不扣血、不硬控、无受干扰次数保护。
  观众与被淘汰者在 PK 准备与 PK 中镜头对准场地并看见全部场内选手及其技能投射物与预警，自己的普通操作被锁定；同队选手共享的视野同样包含队友视野内的投射物与预警。
- **休息服务**：三个可识别、可接近交互的 NPC 分工：
  技能商人只出售现有主动机会；构件工匠提供现有补缺/拆解；训练师提供现有洗点/替换/遗忘。费用不变，不增加商品池或库存。
  仅在配装与派奖窗口、本人靠近对应 NPC 时可提交服务；离开范围或切步骤后服务器重验并明确拒绝。
- **训练**：北侧公共训练区有六个批准槽位与开放地面边界，每位参赛者在对应槽位生成一个真实共享假人。
  休息室连接可观察全部活体假人，也可攻击其他槽位的同一真实目标；外观、位置、生命、受击与控制结果来自该目标的权威状态。
  目标按该槽位生成时的公开角色等级建立无构筑底盘，不复制所属玩家私有成长。命中、承伤、状态与反馈使用真实施放来源与目标身份；归零回满，不死亡、不发经验或奖励。
  “重置训练”仅重置本人目标；请求只在当前休息步骤与生命有效。目标保留到返回野外，不随某选手进入 PK 消失；
  阶段清理保证训练资源、冷却和在途效果不带回野外。
- 未做的开局主动选择和未分配的属性点一直保留，不替玩家选择或加点（D7）。

前三段野外可以打野、战斗和升级，但不能喷漆或获胜。最终休息 R3 不举行 PK；玩家保留普通构筑整理，额外获得独立的一次性终局改装三选一。八张卡为旗杆房东、破门而入、现场翻盘、全城开麦、人肉保龄球、强制退场、交通管制、一分为二，行为、代价和合法来源见[内容与数值 §4.7](demo/CONTENT_AND_BALANCE.md#47-终局改装)。候选由服务器按本人的合法来源生成，四张普适卡保证任意合法构筑都有三项；揭示后不随编辑构筑重抽。机制卡须绑定一个仍合法的来源，选择与构筑锁定在同一权威提交完成，不替换 Q/W/E、不退回挂件、不占普通工坊容量、不增加操作按键。没选的人在返场时也锁定。全体随后进入隔离的六入口封街战场，入场十秒后旗杆解锁；终局不发经验、属性点或普通构件，普通构筑命令关闭。

守护成功后立即锁定唯一胜者，停止继续结算战斗、奖励、喷漆和守护。结果页面展示胜者和本局基本结果；Host 可以带房间返回 Lobby 开始新局，玩家也可以离开房间返回主菜单。

结算展示所有参赛者的名称、击杀数、死亡数、助攻数和最终等级，并标出赢家，同时显示结束原因和本局用时。
离局不删除其本局结果记录；没有胜者时不从击杀统计中另选赢家。结算同时展示历史守护贡献和成功喷漆次数。

### 2.2 唯一胜利条件：喷漆与守护

旗杆开放后，**一名有效参赛者在喷漆区内独自喷上自己的涂鸦，再独自站在喷漆区内把这幅涂鸦守护满规定时长，即获胜**。进入喷漆区自动开始判定，无需交互键、钥匙、门票或其他前置任务。
喷漆需要时间；喷上之后要守住，期间可以挨打，但挨打本身不打断守护。守护只在涂鸦主人独自站在喷漆区内时计时；主人不在区内时暂停，有别人在区内时冻结。

表现为在旗杆上喷上涂鸦、守住后成为“淫人王”；喷漆、涂鸦与加冕反馈只跟随服务器已提交的状态与唯一胜者，
不能通过动画、称号或统计提前判胜。

- **开放**：终局入场十秒后旗杆开放，直到本局结束。独占喷漆需 3.5 秒，当前所有者独占守护累计 20 秒立即获胜。
- **有效参赛者**：仍在本局、存活且不在复活保护中的真人或对手 AI。死亡角色、野怪以及技能视觉效果不计入喷漆区人数。
- **喷漆区**：以旗杆为中心的圆形区域，按角色脚点的平面距离判定，边界算在内。半径与喷漆、守护时长写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

| 情形 | 规则 |
| --- | --- |
| 喷漆区内只有一名有效参赛者，且他不是当前涂鸦主人 | 他的喷漆进度累积；满规定时长即喷上涂鸦 |
| 喷漆区内有两名以上有效参赛者 | 所有人的喷漆进度暂停并保留 |
| 喷漆者受到普通伤害、减速或缴械 | 不影响喷漆 |
| 喷漆者离开喷漆区、死亡、离局，或受到定身、眩晕、沉默、嘲讽、击退 | 他的喷漆进度清零 |
| 喷上涂鸦 | 旗杆显示该参赛者的涂鸦，守护计时从 0 开始；原涂鸦被覆盖（喷上时只有他在区内，守护随即计时） |
| 涂鸦主人独自在喷漆区内（区内没有其他有效参赛者） | 守护计时累积；他受伤、受控不影响守护计时 |
| 旗杆有涂鸦，但喷漆区内没有有效参赛者（主人在区外） | 守护计时暂停在当前值、不清零；主人重新独自回到区内后从暂停值继续。主人可以离开喷漆区自由移动和战斗，但离开期间守护不计时 |
| 涂鸦主人以外有任一有效参赛者在喷漆区内（不论人数、是否在累积喷漆进度、是否与主人同在区内） | 守护计时冻结；区内的非主人全部离开（或死亡、离局）后，主人独自在区内时守护计时从冻结值继续，主人不在区内时保持暂停 |
| 守护冻结期间，涂鸦主人从喷漆区内走出 | 守护仍暂停在原值，涂鸦保留；主人重新独自回区后续计 |
| 涂鸦主人本人在喷漆区内 | 他不喷漆；有其他有效参赛者同在区内时，所有人的喷漆进度暂停，守护计时冻结 |
| 涂鸦主人死亡或离局 | 守护暂停，涂鸦及历史贡献保留；死亡或离局者不具备当前冠军资格 |
| 守护计时累积满规定时长（暂停与冻结期间不计） | 涂鸦主人获胜 |

定身、眩晕、沉默、嘲讽、击退只在施加的那一刻清零喷漆进度；之后即使仍被控制，只要他仍独自留在喷漆区内，就从 0 重新累积。
喷漆进度只属于本人，别人不能继承；暂停保留的进度在争夺结束、他重新独自在区内时从暂停值继续。
复活保护者不计入人数，既不能喷漆，也不能暂停别人的喷漆或冻结守护，避免利用无敌状态争夺旗杆。

只有对手成功重新喷漆才清除前主人的当前守护进度；离圈、被推出圈、死亡和复活均不清除它。
`BankedGuard` 记录每名参赛者实际完成的所有独占守护时间，换主或死亡不清除历史贡献。

喷漆开始、争夺暂停、进度清零、喷上涂鸦、覆盖、守护暂停、守护冻结、守护清零、涂鸦清除与获胜必须有清楚反馈。旗杆开放状态、喷漆进度、当前涂鸦主人和守护剩余时间属于全场公开信息，不受战争迷雾遮蔽。人数与边界判定以服务器上的真实位置为准，不依赖客户端画面或个人视野。

同一结算时刻先处理位移、控制、死亡和离局，再处理喷漆与守护，最后处理期限裁决。达到完成时刻时，必须仍然满足对应条件；不能跳过同刻争夺或死亡。服务器只提交一次最终结果。

终局最长 240 秒。到期时只在存活、仍在本局且不受复活保护的参赛者中，依次比较历史独占守护时间、成功喷漆次数；最高贡献完全并列或无人有贡献时无人获胜，不按击杀、等级或 GUID 破平。没有活人且没有合法排队的复活时可提前无人获胜；最后幸存者仍须完成目标。

终局每人最多两次复活，分别等待 18、24 秒；第 150 秒起不接收新复活，此前已经合法排队的仍可完成。第 120 秒开始封街，安全圈逐步收缩；圈外伤害由服务器按真实运动路径累计，表现环不参与伤害。规则配置来自 `SourceData\Demo\content.json` 的 `CAPTURE.*` 与 `SHOWDOWN.*`，沿内容同步入口生成后生效。

房主离开则关闭房间，所有玩家返回主菜单，不产生结算。

| 按住 Shift + 右键 / A 左键 / Q W D | 指令队列：把这条指令排在当前指令和已排指令之后，依次执行，而不是替换当前指令 |

使用固定俯视斜角镜头，不要求自由旋转镜头。输入绑定允许修改并保存；镜头速度、边缘平移与跟随偏好属于本地设置。

操作手感：保持 MOBA 点击操作，不改用方向键移动或朝鼠标方向攻击。右键地面在落点给出移动标记，路线不可达时给出红叉；右键目标在其身上给出攻击标记；光标悬停在可攻击的可见单位上时高亮该单位（脚下悬停圈）。光标始终是游戏自己的箭头（白面深色描边），不出现系统的十字、手形或文字光标；按 A 进入攻击移动待确认时箭头边缘发红光，按下主动技能进入待确认时边缘发蓝光，其余时候（包括悬停单位）都是普通箭头。按住右键时角色持续朝光标移动（发令频率受限）。自身技能前摇尚未出手时按下的下一个技能键先暂存一个，前摇结束后作为普通请求发出；按 S、进入新生命或新对局、或暂存超过 1 秒时丢弃。可选的本地设置“快速施法”默认关闭；打开后，指针已指着合法单位或地面时按技能键直接施放，否则仍需左键确认。预输入与快速施法只改变客户端何时发出请求，服务器的准入与结算规则不变。

指令队列：按住 Shift 下达的移动、攻击目标、攻击移动以及 Q/W/E/D 依次排在当前指令之后，由服务器保存，最多 8 条，再多时提示“指令队列已满”并拒绝。前一条结束后（到达、施放完成）才开始下一条；技能轮到时才由服务器按当时的规则判定，朝方向施放的技能（含 D）从角色当时的位置朝排队时指向的地面点出手。某一条失败或提前结束（路线不通、受阻、目标不可见或死亡、被击退、技能被拒绝）时跳过它继续下一条；按 S、下达任何不按 Shift 的指令或被受理的不按 Shift 的技能（被拒绝的技能不清空）、死亡、新生命或新对局时清空整个队列；被嘲讽时也清空，结束后不恢复。排队的进攻指令和技能在发出时就算作进攻意图，立即解除复活保护。每个排队的地面点显示一个小标记，并有一条虚线从角色经当前目的地连到各个排队点。Shift 固定用作队列键，不能改绑给其他操作。

技能可采用指向单位、指向地面、方向或自身释放等目标形式，由技能内容定义。释放前显示有效目标、范围或方向；无效输入不消耗资源，并反馈失败原因，但已通过身份/代次准入的进攻意图仍按 §6.1 解除复活保护。Q/W/E/D 的请求被拒绝时（冷却未好、法力不足、受控制、空槽等），不打断、不替换也不暂停当前的移动或攻击指令，也不清空指令队列，角色继续移动或攻击，拒绝原因照常提示；只有被受理的施放才会取代当前指令。

点击 UI 不得同时向世界发送移动、攻击或施法命令。打开面板、处理成长（选技能、学习、加点）和修改设置都不暂停联机对局，也不赋予角色无敌。

### 3.2 属性模型

角色采用 MOBA 式战斗属性。下表固定属性含义，不包含数值和计算公式。

| 属性 | 作用 |
| --- | --- |
| 攻击力（AD） | 决定普攻及具有物理攻击加成的技能效果 |
| 法术强度（AP） | 决定具有法术加成的技能效果；不默认让普攻变成魔法伤害 |
| 护甲 | 影响承受的物理伤害 |
| 魔抗 | 影响承受的魔法伤害 |
| 攻速 | 影响普攻频率 |
| 移速 | 影响行走与追击速度 |
| 攻击距离 | 影响普攻的有效距离，不等同于所有技能的施法距离 |
| 生命、生命上限 | 表示存活资源与上限 |
| 法力、法力上限 | 表示技能资源与上限 |
| 生命回复、法力回复 | 决定相应资源的自然恢复 |
| 暴击率 | 影响允许暴击的攻击；不是所有技能自动获得暴击能力 |
| 技能急速 | 影响适用主动技能的再次使用时间；面板与技能图标反映真实效果 |

**所有参赛者初始使用近战单体普攻**，普攻默认造成物理伤害。
普攻可以成长：攻击距离、元素附着、强化普攻、反应范围等；初始形态不是永久的近战限制。普攻不要求获得群攻。
具体成长路径与射程参数由内容和战斗设计提供，不因此强制采用投射物。
当前运行目录的普攻成长来自强化普攻主动（贴脸补一拳、左右开抽）与构件：射程（伸长胳膊抽你）和普攻元素（§4.4）。

技能明确标记伤害类型、属性加成、法力消耗、冷却和作用方式。属性视图的悬停弹层写明基础值、成长与状态带来的加成，不能只显示没有实际效果的字段。

**五维属性**：体格、脸皮、力道、脑力、身手，用属性点购买，每点可以加在任意一项，
同一项可以反复加。每点收益写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；同类固定值与加法比例相加后统一投影，不逐点相乘。
所有属性统一限制在内容写明的上下限之内：超出上限的部分不生效，不会因此拒绝加点。

存活时，升级或加点导致生命/法力上限变化，**保持变更前的生命/法力百分比**。
一次复合变更先算出最终上限，再统一换算当前值；精度与取整不得让反复属性往返获得额外血蓝。
死亡等待中的加点或主动选择不治疗尸体或提前复活；正常复活仍按届时上限补满生命和法力。

**脱战慢回**：所有参赛者脱离战斗一段时间后，按当前生命上限和法力上限的固定比例持续恢复；一进入战斗立即停止。
“战斗”的判定是有效出手、伤害技能释放、承受伤害；死体不恢复，复活时刻重新开始计时。
延迟与比例写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

**躺平角**：地图边缘有 2 处公开的躺平角（快速回复点）。参赛者的脚点站在躺平角圆形判定区内（边界算在内），
并且脱离战斗满躺平角延迟后，每秒按当前生命上限和法力上限的固定比例快速恢复，约 10 秒从零回满；
它与脱战慢回各按自己的延迟起算并叠加。一进入战斗、离开躺平角或死亡立即停止，野怪不受影响。
躺平角不是安全区：不阻挡攻击、技能、视野或寻路，也不另加碰撞。位置、半径、延迟与比例写在
[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 按同一规则使用躺平角。

前摇、命中、伤害、控制、死亡及恢复使用一致的战斗规则。普攻一旦合法起手，出手时不再判定距离，但仍须目标可见且视线无遮挡。控制效果需要明确说明禁止的是移动、攻击还是施法，并在角色与 HUD 上可辨识。

**战斗联动规则**：

- **命中特效**（如吸血）由普攻主击触发。由命中特效、反伤、灼烧或附加伤害（独立命中）产生的命中不再触发任何命中特效。
  吸血、反伤等来源由构件提供（§4.4）。
- **强化普攻**：贴脸补一拳、左右开抽的附加伤害在暴击判定前并入同一次普攻主击，因此可以暴击，并带动普攻命中特效。
- **伤害加成池**：一次伤害的所有“伤害 +X%”（如对被减速或被控制目标的增伤）相加后乘一次，结算顺序为 原始量 ×（1 + 加成池）→ 抗性（含破防）→ 护盾 → 生命。普攻暴击仍 ×2，在加成池之前。
- **技能不暴击**：只有普攻主击及并入它的强化普攻按暴击率判定暴击。
- **技能吸血**按该次伤害实际扣掉的生命计算，不含护盾吸收的部分和溢出伤害。一次伤害的所有吸血来源相加，
  总比例最多 35%。灼烧不吸血。
- **反伤**按反伤者的生命上限计算；反伤不暴击、不吸血、不再触发对方反伤。
- **控制**指定身、眩晕、沉默、缴械、嘲讽、击退，不含减速。
- **沉默**：只禁止施放 Q/W/E；可以移动、普攻和冲刺 D。施加时正在前摇的 Q/W/E 被取消，不扣法力和冷却；
  排队的技能轮到时被拒绝即跳过。沉默是硬控，并在施加瞬间清零喷漆进度（§2.2）。
- **硬控递减**：定身、眩晕、沉默、缴械、嘲讽是硬控；减速与击退不递减。同一身体在上一次硬控生效期间或结束后 2 秒内
  再中硬控时，持续时间依次为 60%、30%（第三次及以后），最短 0.2 秒；计数跨所有来源共享，连续 2 秒没有新硬控即清零。
- **剩余冷却缩减**：部分效果会缩短指定技能尚未结束的冷却；只改结束时间，不改基础冷却，缩到当前时刻即立即可用。
- **击退**是服务器强制的位移：沿地面把目标推开，遇到阻挡停在最远的合法位置，不传送；击退是一种控制，
  期间不能移动、普攻或施法，并打断目标未出手的动作与当前移动/攻击指令。
- **护盾事件**：身上始终只有一份护盾，新的不弱于当前剩余量才替换。替换一份仍有剩余量的护盾叫“刷新”
  （从无到有不算）；被伤害打空叫“打破”，到期或被技能主动消耗、击碎都不算。由刷新/打破触发的效果所带来的控制或护盾
  不会再次触发获得护盾的效果。
- **地面区域**按固定间隔结算，伤害按施放时的属性计算，不暴击。
- **破防与灼烧**：每个目标身上各只有一份，所有来源共享层数，最多 5 层，新的一层把整组时间刷新为满值。
  破防每层固定 −3 护甲和 −3 魔抗（最低 0），4 秒，来源离局层仍保留。灼烧每层每秒造成魔法伤害（施加者等级成长 + 法强系数，
  按施加时快照），3 秒、每 0.5 秒结算；到 5 层时新的一层替换最早的一层；每层记住施加者，伤害、击杀与助攻按层归属，
  施加者离局时他的层移除，野怪回位时清空。数值写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

战斗效果、持续时间、距离、属性上下限和其他换算公式不在本规格中预设；
上述比例保留规则不授权任何具体基值或取整默认值。

## 4. 经验与成长

### 4.1 奖励与升级

击杀野怪或其他参赛者获得经验。**野怪的经验全部归完成最后一击的参赛者**，不设附近经验分摊或按伤害贡献结算。

**参赛者之间的击杀另有助攻（参考 LoL）**：

- **资格**：受害者死亡前 15 秒内（含 15 秒整），对其造成过正伤害（含被护盾吸收的部分）或施加过任何控制与减益
  （减速、定身、眩晕、沉默、缴械、嘲讽、击退、破防、灼烧）的其他在局参赛者，算作助攻。
  每次新的贡献重新开始 15 秒计时；击杀者本人不算助攻；死亡中的参赛者仍可得助攻，已离局的不能。
- **经验**：受害者的经验奖励由击杀者和所有助攻者平分，向下取整。
- 没有击杀者的死亡不发任何奖励，也没有助攻。15 秒写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。


技能效果或持续伤害造成的击杀也归属于其实际所有者。同一次死亡的击杀与助攻奖励一起结算、只结算一次；没有参赛者拥有该次致死伤害时，不凭空指定奖励获得者。

经验用于升级，满级后按流量继续给属性点（§4.2）。Demo 没有装备、金钱与商店；
不开设任务、采集、制作、银行或玩家交易等额外经济循环；
唯一的地图拾取是公开的天降外卖（见 §5.1），它与击杀奖励走同一套流量结算。

### 4.2 属性点与主动技能

成长是 v0.11“规则工坊”的五维属性点、单级主动技能与构件，两份规范的目录与数值已批准并进入运行数据。
规范原文是[玩法与完整目录](https://github.com/rlsn/Lockdown-alpha/issues/198#issuecomment-6739619912)与
[AI 实现规范](https://github.com/rlsn/Lockdown-alpha/issues/198#issuecomment-6739620418)；数值只在
[内容与数值 §4](demo/CONTENT_AND_BALANCE.md#4-技能状态和属性目录)维护。
本节、§4.3 与 §4.4 定义已批准的成长和工坊规则；实现与验收状态见[实施就绪评估](demo/READINESS.md)。

**属性点**

- 供给：开局（进入开局休息 R0）时，每名参赛者得到开局点数；之后每次升级（2–16 级）得到每级点数；
  满 16 级后不再升级，超过 16 级阈值的流量每满一段再给一份点数，流量继续累计。
  开局 3 点、每级 3 点是已确认决定；参数为 `GROWTH.OpeningPoints`、`GROWTH.PointsPerLevel`、
  `GROWTH.MaxLevelPointsXP`、`GROWTH.MaxLevelPoints`。复活不再给开局点数，新一局重新给予。
- 分配：一次把至少 1 点未分配点分到五维属性，各项点数之和不能超过未分配点数；整次生效或整次拒绝。
  已分配的点是永久的；洗点只在休息的配装与派奖期间进行，只退已分配的点（§4.4）。
- 时机：对局进行中随时可以——野外（交战中也可以）、
  休息的每个步骤（含 PK、押注与返回倒计时）、存活或死亡等待中都可以；只有对局已结束（结算后等阶段关闭时）明确拒绝并说明原因，点数保留。
  没有构筑安全窗，也没有休息中的构筑锁定。

**交战窗口（只用于界面）**：Combat 仍按 `GROWTH.BuildSafeWindowSec`（4 秒）记录本人最近一次交战——普攻成功开始前摇或释放带进攻效果的技能、
对敌方造成或受到敌方正伤害（含灼烧与地面区域每一跳）、被施加定身、眩晕、沉默、缴械、嘲讽或击退（单独减速不算）；
菜单、视野与脱战回复不刷新，死亡不重置。它只供 HUD 在交战中收起野外文字摘要（[界面与设置](demo/UI_AND_SETTINGS.md) §3.1），不再限制任何成长命令。

**主动技能机会**

- 1 号是开局机会：开局（进入开局休息 R0）时给出，从内容标为开局池的主动中等概率、不重复抽 3 个，选 1 个。
- 达到 3 级、6 级时各额外给一次机会（`progression.active_offer_levels`），从全部主动中等概率、不重复抽 3 个；
  这两级正常的属性点照发。
- 每组候选都排除已学的主动和已有的待学图纸。合格的只有 1–2 个时如实只显示这些；一个都没有时机会保留排队、
  不生成候选，等有合格主动时再生成；排队的机会从不阻挡加点。
- 同一时间只有一组当前候选，其余机会排队，逐次处理。候选由服务器生成并保留；关闭面板、死亡或重复请求都不换组。没有重抽。
- 每组可选“不选”：永久消费本次机会。开局或升级机会获得 5 未分配属性点；NPC 购买机会花费 5 点后不选返还 3 点，净花费 2 点。
- 复活不再给开局机会；新一局重新给予。

**选择与学习**

- 在本局进行中随时（野外交战中、休息的每个步骤、存活或死亡时）都可以从当前候选中选 1 个。选中的主动成为一份待学图纸（显示为“图纸”）。
- 有空的 Q/W/E 槽时，同一次确认直接把它学到空槽（玩家指定的空槽，否则按 Q、W、E 顺序第一个空槽）；
  Q/W/E 已满时存为图纸，并说明原因“没有空槽”。选择、学习与机会消费一起生效，不会只成一半。
- 之后可以随时把图纸学到指定的空槽；学习消耗图纸。
- 野外不能替换或遗忘已学主动：满槽时新选的主动保留为图纸，学到已占用的槽被明确拒绝。满槽替换与遗忘只在休息的配装与派奖期间进行（§4.3）。
- 死亡等待中可以加点、查看、选择并学到空槽，不需要复活。请求仍须属于当前 Match/Life；死亡前或复活前的迟到旧请求
  不能改动新生命。死亡中的成长不提前复活、不治疗尸体、不修改复活等待，也不产生身体战斗效果。
- 不替玩家选择、学习或加点。真人参赛者的开局候选在本局首次显示时自动展开一次构筑选择卡，可以收起，
  几秒内未操作或本人受击时自动收起回构筑按钮，机会继续保留。选择卡不暂停世界。

**技能只有一级**，数值随角色等级成长：卡上的固定数值 = 基础值 × G(L) + Σ 系数 × 当前属性，L 是拥有者当前等级；
1–10 级每级增长基础值的 15%，之后每级增长 7.5%，所以 G(10)=2.35、G(16)=2.80（参数见内容与数值 §4.1）。
伤害（含强化普攻、地面区域与灼烧）、护盾与限时属性加成的点数随 G 成长；持续时间、比例、冷却、法力、射程、层数和属性系数不成长。
主动在释放时按当时的等级和属性计算；护盾、灼烧在施加时固定。

**卡面**：选择卡上只有图标和名称；悬停弹层写一句规则，数字是你当前等级与属性下的实际数值，并显示法力、冷却和目标形式，
其后逐个解释用到的关键词（列表见内容与数值 §4.5），“控制”不含减速。卡面与解释不写喷漆、守护或“未知效果”。
五维属性只写每点收益。

### 4.3 三个主动技能槽

角色主动技能使用 Q/W/E 三个槽，D 继续是通用冲刺。只能学到空槽（§4.2）。

**满槽替换与遗忘**：休息的配装与派奖期间可以确认把已学主动换成一份待学图纸，也可以单独确认遗忘一个已学主动；
有未处理的主动候选时先处理候选。被换下或遗忘的主动**被遗忘**，不进入备用技能库、不返还图纸，想再用需要重新获得
（新的主动机会、野外图纸、Boss/空投奖励或休息 NPC；被遗忘的主动重新进入候选范围）；
它上面安装的构件仍归你，退回构件库或迁往合法对象，不复制、不丢失。

升级或槽位调整不能成为重置尚未结束冷却的捷径。技能冷却要按其实际来源管理，不能因为图标换了位置就恢复可用。

**失去来源期间冷却继续计时，重新持有时沿用原结束时间。**
遗忘技能不会冻结、清空或重新计算尚未结束的冷却；
重学同一技能时，继承该技能的原冷却结束时间。

替换遗忘技能后，已经成功释放的独立效果继续到原定结束，不因来源移除而取消。
需要持续持有来源或持续施法维持的光环、被动和引导不在此列，失去维持条件时失效；
仍在运行的独立效果不授予继续使用已失去技能的权限。

### 4.4 工坊规则

下列规则与 §4.2 同时批准，外层流程见 §2.1；实现与验收状态见[实施就绪评估](demo/READINESS.md)。
完整语义见两份规范与[外层参数](https://github.com/rlsn/Lockdown-alpha/issues/198#issuecomment-6752601175)，
目录与参数索引见[内容与数值 §4.4](demo/CONTENT_AND_BALANCE.md#44-构件与工坊参数)。

- **构件**：三种材料。基础构件直接给一个完整效果；改装件改变一个效果的覆盖、时机、目标、射程或运动形态，一件只装一处；
  连接件读取一个真实发生的结果再产生另一个结果，是否消耗输入单独写明。开局另自选一个当前可用的基础构件；
  每次正常升级另得 1 件随机构件，2、4、6……16 级再多得 1 件，2–16 级共 23 件（先按等级段抽类别，再从未持有的定义中均匀抽取，
  同名只持有一件）。拿到的构件先进构件库（§7）。
- **工坊容量**：每件已安装的构件（基础、改装、连接都算）占 1 格，所有技能、本体与 D 共用；L1 5 格，之后每 2 级多 1 格，L16 12 格。
  拥有不受限，装满后要拆下一件或直接用新件替换一件已装的，所以中后期总要决定哪些能力值得占格子。
- **形态互斥**：同一种形态的构件在同一个目标上只能装一件，用于不能同时执行的形态：冲刺的冲穿或小跳、持续区域的聚集或单次爆发；
  装在不同技能上不冲突。元素普攻、冲刺收益、穿透与返程以及冲刺接触联动可以组合。
  形态写在内容里（[内容与数值 §4.4](demo/CONTENT_AND_BALANCE.md#44-构件与工坊参数)）。
- **替换**：把库中构件拖到一件已装构件上，在同一次提交里卸下旧件（连同装在它上面的件）并装上新件；
  只在装满或形态冲突时提供，时机与安装相同，旧件回到构件库，不刷新冷却或生命。
- **分类**：纵向是基础规则 / 技能改装 / 联动规则三种类型；横向是弹道、法术、控制、元素、区域、冲撞、普攻、防御、节奏、记账等用途标签，
  只帮玩家看懂一件构件干什么，规则不读标签。安装、拆下与搬动（含曾经装过的旧件重装、改接连接件）与学习同一时机（§4.2）：
  对局进行中随时可以，交战中、死亡等待中与 PK 中也可以；拆下一件宿主时，装在它上面的改装件与连接件一起回到构件库。
- **新主动与元素**：再加入 6 个主动。元素只有水、火、电，技能与普攻、冲撞都能附着，共用起雾、导电、过载三种反应；
  另有账目（对同一目标积累命中，满批兑现）。
- **休息与服务**：开局一次、中场三次休息（§2.1）。休息时可以在公共训练区用共享真实假人试招；
  休息的配装与派奖期间可以靠近 NPC 洗点（只退已分配的点）、确认遗忘后替换满槽主动；休息 NPC 用 5 点换一次主动三选一（不足三个合格候选时拒绝且不收费）；补缺用 4 点换一个能补上缺失入口的基础构件；
  拆解用 2 件不同的普通材料换 1 件随机普通材料。这些 NPC 服务要求存活、靠近对应 NPC，PK 与返回倒计时等其他休息步骤拒绝，野外不可用。
  事务边界见[成长事务](systems/GROWTH_TRANSACTIONS.md)。
- **PK 与观众**：休息时自愿站圈报名，先锁名单再抽赛制（构筑不锁），在原地图缩圈对战，最后存活的一方获胜；
  观众免费竞猜，可以用有冷却的投掷减速或暴露选手。PK 不决定整局胜负，整局仍只由旗杆喷漆与守护决定。
  PK、竞猜与投掷的详细规则见 §2.1。
- **其他**：野外主动图纸、Boss 与空投的构筑奖励、符咒、局末构筑蓝图（只保存配方，不授予能力）与评估工具。

## 5. 地图、野怪与视野

### 5.1 地图组成

4 处天降外卖落点、2 处躺平角。地形三层：边缘最高（四周高台），中心最低（旗杆盆地），中间有起伏的坡地；
高处看得见低处，反之不行；坡道可走，悬崖只连视线、不能走。层高只为视线服务（每层 0.5 m），悬崖由隐形挡块封住；
身体不能迈台阶，只能走上坡面，坡上移速与平地相同。障碍有挡走挡视线的树（同一尺寸的圆柱，直径与身体相同）与矮墙、
挡走不挡视线的栅栏。树成小片树丛，树丛之间的空隙就是小路；四条宽路从高台坡道通向旗杆盆地；
四个角的高台各有一块中层台地，经两段坡道从角上直通旗杆盆地（东南角再接上山坡的第三段坡道），躺平角和角落出生点可以直接走向中心
；外卖落点在开阔处，营地在半包围的林间空地（营地净空 3 m）。

地图需要清楚区分可自由行走区域与阻挡行走的地形。出生点、野怪营地和占领点之间必须存在合法路径；寻路不能依赖穿墙或瞬移。

占领点要有可辨识的喷漆区边界和接近路线，不能通过不可行走地形从外部计入喷漆区。障碍布局需要支持绕行、追击、撤退与视野取舍，不以巨大面积或大量装饰性地点作为目标。

12 个出生点是预先布置在高台上的合法落点。首次进入野外、野外复活以及返回野外时原脚点附近找不到位置，都从这同一组点中完全随机选择；休息室使用独立的名单槽位锚点（§2.1）。野外各点被抽中的机会相同，不按敌人距离、视野、危险程度或胜率筛选，也不优先沿用本人的初始点。允许再次抽到同一点。

若多个角色同时落在同一点，只进行必要的合法落地、防重叠处理，不借机重新选择“更安全”的出生点。

**天降外卖**：按野外进度 T（§2.1）在固定的几个时刻（全房共 6 份，之后不再有）于公开落点之一落下一份外卖；每一份都提前公开落点和倒计时，所有人同时看到。
每份的落点由服务器从上一份以外的落点中随机选出，到公告时才公开，不能从已公开的信息推知。
落地后，第一个脚点进入拾取圈（边界算在内）、且不在复活保护中的存活参赛者独得一份流量和一次构筑奖励（主动图纸或稀缺件各半）；
同一时刻有多人在圈内时，离中心最近者得，仍并列时由服务器随机决定。落地后一段时间仍无人领取，外卖消失，不发奖励。
公开信息只有落点、落地与消失时间和“已被领走/已消失”，不公开是谁、在何时领走；领取者本人会得知。
任何时刻只有一份当前外卖：下一次公开时，上一份不论是否被领走都被取代。最终野外没有外卖。
时刻、消失时间、拾取半径、奖励与落点写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 按同一规则争夺。

**符咒**：按野外进度 T 每隔固定间隔落一波，每波若干枚不同种类（血量、蓝量、移速），放在当前外卖与其他符咒都没占用的不同外卖落点上，
所有人同时看到（场景与小地图，不另发事件提示）。第一个脚点进入拾取圈、存活且不在复活保护中的参赛者拿到；同一拍多人在圈内由服务器随机决定。
一段时间无人拾取或进入休息时消失，不发奖励。公开信息只有地上符咒的种类、落点与到期时刻，不公开拾取者。
波次、数量、效果、拾取半径与持续时间写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

**上热搜**：按野外进度 T 每隔固定间隔刷新一次。刷新时仍在对局中的参赛者里，等级唯一最高且不低于门槛者上热搜；
等级相同按击杀数定，仍相同则本次无人上热搜；被选中者此刻已死亡也不上热搜。上热搜对所有人公开：名字和小地图上的一个
模糊圆，圆心是其此刻脚点加一个不超过圆半径的随机偏移，因此本人一定在圈内，但圆不随其移动，直到下次刷新。
击杀上热搜者只得正常击杀奖励，没有额外奖励。上热搜者死亡即结束本次上热搜，
下次刷新重新选出。间隔、门槛、圆半径与偏移写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

**画饼老板 Boss**：每局只出现一次。野外进度 T 到达固定时刻时出现在第一个公开巡逻点，按顺序沿四个巡逻点循环巡逻，
走合法导航。它优先追打最近一段时间内打过它的参赛者（其中最近的一个），否则打攻击半径内最近的可见参赛者；
它与野怪一样受视野规则约束，身体只在合法视野内可见。公开的只有出现与退场时间、是否存活和最后一击者，
不公开它的实时位置或血量。它不复活；最后一击的参赛者获得一份流量，此时仍存活的还得一次构筑奖励（没有额外的属性增益）。
到第三次休息开始时仍未被击杀，它退场：不算死亡、不发奖励，不进入最终野外。被它击杀计为“被 画饼老板 淫了”。
数值、时刻与巡逻点写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 会主动避开它，不会主动挑战它。

**标记营地**：前三个野外段开始后不久，各公开标记一处高档营地和一处精英营地（精英营地优先在与高档营地相对的地图象限，
两类都不连续标记上一段的同一处）。本段第一个清掉该营地的参赛者领取一次奖励：高档营地一份主动图纸，精英营地一次普通材料
已知二选一；正常的野怪经验照旧。标记时营地已清空就等它正常刷新；领取后本段不再发；段结束未完成则机会消失；最终野外没有标记。
公开的只有被标记的营地、状态与时间，不公开领取者。时刻与候选写在[内容与数值](demo/CONTENT_AND_BALANCE.md)；对手 AI 会优先去打已标记的营地。

### 5.2 野怪

地图固定设置三十四组野怪（18 组低档、12 组高档、4 组精英）。具体分配、每组数量、能力与收益交由 Demo 内容和数值设计确定。

**野怪随对局时间变强**：每条野怪新生命在生成时按野外进度 T（§2.1）已过的整阶段数取一个成长阶段（有上限），
整条生命保持这个阶段，回位重置也不改变；每阶提高生命、攻击、双抗和经验奖励。开局时生成的野怪为 0 阶。
画饼老板不是营地，不随时间成长。阶段长度、上限与每阶增幅写在[内容与数值](demo/CONTENT_AND_BALANCE.md)。

野怪不是对手 AI 参赛者，不选择成长、不计入喷漆区人数、不能获胜。
**未受攻击时不主动攻击；同组成员受击后共同反击，但不共享隐藏坐标。**
目标选择和追击仍遵守合法感知；超出营地活动范围或失去目标后返回，避免被永久拖离营地。

返回营地期间仍可受到伤害、控制或被击杀，受击不会使其回头重新追击。
成功回到营地后，仅存活成员恢复满生命/法力、清除临时效果和仇恨、使技能就绪；
不复活已经死亡的成员、不产生奖励，也不将回位当成一次新生命。
回位找不到合法路径时（#28）：连续规划被拒或长时间没有进展达到[内容与数值](demo/CONTENT_AND_BALANCE.md)的上限后，
该成员在原地按同一规则重置（不传送回家、不发奖励）。此后它在营地活动范围外坚守原地：受击时就地反击，
不追击、也不因活动范围返回，失去目标且宽限期结束后才再次尝试回家；回到家中重置后恢复正常规则。
这是野怪回位规则，不改变参赛者的死亡保留冷却或上限变化保持百分比规则。

营地被清空后进入刷新等待，随后重新生成该组野怪。每个野怪生命的死亡与奖励独立且只结算一次；回位重置不等于死亡，不能发放奖励。

基础角色只靠初始近战单体普攻就必须能够开始低难度打野和首次升级。高难度营地应体现更高风险与成长价值，不能只是外观不同；
精英营地的风险与收益都高于高档营地，只有普攻的角色单挑打不过精英。

### 5.3 局部视野与战争迷雾

每位参赛者只有自己的局部视野，真人和对手 AI 遵守同样规则。地图地形、固定营地和占领点位置可以公开；隐藏单位的位置、当前行为和资源状态不能持续透过迷雾更新。

离开视野的敌人不再提供实时位置，不能通过镜头平移、选择面板、小地图、寻路目标或 AI 决策绕过限制。地形的“阻挡行走”与“阻挡视线”需明确区分。

目标失去视野时取消锁定，并停止与该目标绑定的追击订单，不自动走向其最后可见位置。
首版不保留 LastSeen 单位标记，世界和小地图只显示当前合法可见单位；过期信息不能伪装成当前观察。

查看当前可见对手时，只展示名称、角色等级、血量、蓝量、状态，以及 Q/W/E 三个主动技能的图标（技能只有一级，不显示技能等级）。
不展示冷却、属性点、构件或完整属性；可见动作/外观表现不等于授予这些私有字段。
失去视野后清除该目标的当前查看信息，不通过面板保留实时观察。

存活时，小地图展示自身位置、固定地点、视野覆盖及当前合法可见的单位。旗杆的喷漆与守护状态、全场击杀通知与上热搜的模糊圆是明确的公共信息例外，但不能附带无关的隐藏位置或构筑数据；
上热搜只公开刷新瞬间的模糊圆，不公开实时位置。
天降外卖只公开落点、落地时间和是否已被领走，不公开领取者或领取时间（领取等于暴露此刻身在落点）。

侦察和藏匿主要来自移动、障碍与视野。当前核心 Demo 不要求插眼道具、昼夜循环或可破坏地形。

## 6. 死亡、复活与对手 AI

### 6.1 死亡与复活

死亡后角色退出战斗和喷漆区判定，清零自己的喷漆进度；若他是涂鸦主人，涂鸦立即清除。向玩家显示“你寄了”及“回出租屋 emo”倒计时。
等待时长按死亡时的野外进度 T 固定（§2.1）；等待中进入休息时等待结束，直接进入休息位。
等待结束后，从随机出生点以完整生命值、法力值复活，清除死亡前的临时控制状态。
“回出租屋”是等待文案，不增加出租屋地图、可操作身体或提前返回战场的入口。

**死亡只损失等待时间和场上位置。等级、经验、技能、属性点、待学图纸及未处理的主动机会全部保留。** 不重新发放成长或初始奖励；已有冷却按时间继续，不因死亡自动刷新。

正常死亡取消尚未释放的动作；已经成功释放的独立效果继续到原定结束，
后续击杀仍归属于留在本局的实际释放者。旧目标生命上的排队命中或持续伤害不能转移到复活后的新身体。
这不同于正式离局：退出/断线时，身体和未结束独立效果按 §8 立即清理。

死亡等待期间可以自由拖动镜头查看地图，但世界观察只使用静态地图和既定公共信息；
不新增活体视野，不能跟随或观察隐藏玩家，也不继续展示死亡前缓存的单位标记。
自身保留的构筑与候选仍可按 §4.2 查看、选择、学到空槽、加点，并在构件库安装或拆下构件。

复活后有短暂保护（显示为“复活保护”），不受伤害和控制。**只要发出进攻意图，就解除保护**：
服务器先确认合法调用身份、当前 Match/Life、请求通过去重/拒旧校验且终局写闸开放，
再因普攻或施法意图解除保护，之后才校验具体动作条件。
即使目标、距离、蓝量等无效而无法执行动作，也不会恢复保护；未通过动作校验的请求不扣资源或启动冷却。
伪造身份、旧局/旧生命、重放失效请求或终局后的请求不能借此改动角色。
保护期间可以移动，但不计入喷漆区人数，不能喷漆，也不能暂停别人的喷漆或冻结守护。保护状态和剩余时间必须可辨识。

### 6.2 对手 AI

对手 AI 是可独立获胜的参赛者，而不是站立靶子或只会巡逻的 NPC。至少能够自主完成：

- 找到适合当前战力的营地，打野获得经验。
- 处理主动技能选择、学习图纸与加点，使用所学主动与五维属性构筑。
- 与真人或其他 AI 战斗，根据局势追击、撤退和恢复。
- 在旗杆开放后去喷漆并守住自己的涂鸦；旗杆上是别人的涂鸦时围攻涂鸦主人或去改漆；看到公开的对手喷漆进度时，用定身、眩晕、嘲讽等硬控或击杀打断他。
- 状态良好时争夺公开的天降外卖。
- 等级达到上热搜门槛且状态良好时，前往上热搜者的模糊圆追猎他。
- 进入画饼老板的索敌范围时主动走开；不主动挑战 Boss。
- 死亡等待、随机复活并继续对局。

AI 使用同一套属性、奖励、技能槽、死亡和胜利规则。它可以读取自身状态、合法视野和旗杆的公共喷漆与守护信息，但不得直接获取迷雾中的敌人位置、免费生成资源或绕过施法条件。

Demo 只要求一种可完成核心循环的 AI，不要求机器学习、多档难度或模拟人类社交。

关键状态不能只依靠颜色区分。喷漆、涂鸦、死亡、受击与技能释放需要明确的视觉反馈，关键全场事件应有简洁音效或提示。可见单位施放技能的那一刻，头顶飘出技能显示名，不显示等级和冷却；目标查看仍不列出技能。旗杆、树木等障碍挡住本人或可见单位、或紧贴身体时淡化，淡化后仍保持 70% 可见度。占位素材不能妨碍辨认敌我、自身、野怪与交互对象。


角色、场地道具与音效只使用确认为 CC0 的素材，并随素材记录来源与许可；背景音乐使用项目所有者为本项目提供的原创曲目，随素材记录来源。道具只做装饰：不产生碰撞、不阻挡视线、不改变寻路，也不改变已批准的地图几何。

## 8. 联机与数据边界

采用 Unreal Listen Server：Host 一边运行权威世界，一边作为一名普通参赛者游玩；最多另有五名真人客户端连接。对手 AI 和野怪由 Host 驱动。

IP 直连验收覆盖局域网，以及正确配置防火墙、端口映射后可到达的公网地址。**不承诺家庭网络之间免配置连接，不实现自动 NAT 穿透或中继。**

移动合法性、伤害、经验、属性点、主动候选、随机出生、复活和胜负均由服务器裁定。客户端可以立即表现操作意图，但不能自行确认奖励或胜利。

计时以服务器为准，客户端显示同步后的状态。对手 AI 与真人使用相同的权威玩法接口，视野展示不得泄露只属于服务器或其他玩家的私有数据。

对局开始后锁定参赛名单。Demo 不提供中途加入、断线重连或 Host 迁移；普通客户端断线视为离开本局，其他参赛者继续按喷漆与守护规则游玩，不因人数减少自动获胜。离开连接本身不算一次击杀。

服务器确认正式退出或断线后，立即移除该参赛者的身体，不留可攻击或阻挡道路的身体；
立即取消其未结束的独立效果，离局者不再继续影响战斗。此前已提交的伤害、奖励和回执不因清理回滚，
但不能再由该离局者的残留效果产生新的命中或奖励。其本局结算记录保留到结果提交。

Host 离开或连接丢失导致会话结束时，客户端返回菜单并显示原因，而不是停留在失效的世界中。需要清楚区分房间已满、对局已开始、版本不兼容、地址不可达等失败。

所有战力数据仅属于本局。新局重新初始化角色、选择、经验、冷却、野怪与旗杆喷漆、涂鸦和守护状态；本地名称及设置可以保存。

## 9. 内容与数值设计边界

**本规格只固定会议给出的结构数量，不填写平衡数值，也不给“临时默认值”。**

| 本规格已固定 | 需要针对同一个 Demo 专门设计 |
| --- | --- |
| 人数、地图对象数量、等级上限、属性点与主动机会的供给结构、技能槽位、技能只有一级 | 野外段与休息、喷漆、守护、复活、保护、野怪刷新等时长 |
| 奖励归属、死亡保留、技能遗忘和喷漆打断、守护暂停、冻结与清零规则 | 经验曲线、击杀与打野收益 |
| 属性类别、主动与构件来源与视野规则 | 五维每点收益、属性基值、等级成长、伤害与减伤、暴击、回复、冷却等计算 |
| 地图包含的功能地点和可通行/视野要求 | 地图尺度、喷漆区大小、射程、移速、视野、野怪追击范围 |
| 主动机会、学习与加点的合法时机 | 具体技能与构件目录、效果、随机权重、叠加与触发规则 |

数值设计必须检验：基础角色可以开始发育；升级和构筑确实能形成优势；高难度营地有合理风险收益；从地图各区赶回旗杆打断喷漆、围攻涂鸦主人有实际可能；控制、复活和保护不能让喷漆或守护永久无法完成；不存在无限奖励循环。

最终内容只需足以展示不同战斗选择及主动、构件与属性点之间的取舍，不因“完善目录”扩大 Demo。技能和野怪的具体内容仍需针对本 Demo 选定，不能把属性或槽位框架本身当作完整可玩内容。

数值方案确定前，不把喷漆或守护时长、属性写死为产品事实；技术占位数据也不代表已批准的平衡方案。
