### A.2 普攻流为什么强

1. **只有普攻能暴击**，且暴击会同时翻倍并入的强化包 [代码]。力道同时给攻击力和暴击；身手给攻速，进而放大所有按命中触发的构件。
2. **普攻不消耗法力或主动技能冷却**，但有攻速决定的攻击间隔和前摇；前摇可被控制或新技能打断。合法命中可触发 B01、B02、B04、B06、B08、B10、B11、C09。
3. **B04 吸血只吃普攻**，而 C11（技能吸血）有每动作 30G 的上限。这构成回复入口差异，但不能仅据此认定普攻流拥有最高输出或最稳定回复 [代码]。
4. 旧解析模型给出了不同套装的 DPS 和 HPS，但未完整处理安装与获取，不可用来排序流派 [解析，非公平对照]。

### A.3 远程流为什么弱

1. 弹道技能（S06/S21）要预判，会被闪避，还会被第一个身体挡住。S04 是点选而非弹道，但仍受合法目标、视野等条件约束，射程差距只有 50–150cm [代码]。
2. 基础普攻射程不因技能射程自动增加。远程在接近、脱身和控制空间中的实际收益尚未对战验证。
3. M05 以 20% 的伤害代价增加射程 [代码]。第二轮核对现有合法主动：最高基础射程是 S06 的 750cm，安装后为 950cm，当前内容没有已证实的“到达 1000cm 上限却没有收益”实例；上限行为只是未来内容的边界风险。
4. 旧原生的 ranged_ap 样本不完整，未覆盖风筝与主动闪避，不能据此比较远程构筑胜率。

### A.4 法师流为什么弱

1. 脑力原先给 5 法强/点；旧模型不能证明同等合法资源下 AP 和 AD 的流派强弱。
2. 技能伤害**不能暴击**，冷却与法力限制出手；脑力的急速和回蓝在实际多策略对局中的价值尚未量化。
3. 旧原生对局中 AP 方案多次阵亡，但配对不完整且没有风筝策略；自保能力是否不足仍需验证。

### A.5 是否存在机制实现问题

存在，但规模不大。未发现崩溃或资源重复消费（详见 §C.4），已发现的问题如下：

## Report G：Gameplay Expansion Proposal（全部未实施，需评审）

每项列出：规则、意义、构筑、滥用与反制、复杂度、建议。

**G1 墙体反弹（击退流）**
- **规则：** C02 撞墙后，若 0.5s 内被同一施法者再次击退，方向改为墙面法线反射，并造成第二次撞击（每目标 4s 一次）。
- **意义：** 让站位和墙角产生连续操作，而不只是一次眩晕。
- **构筑：** S01/S09/B06 + C02 + M03。
- **滥用：** 墙角无限连推，由 4s 门控与递减限制。
- **反制：** 远离墙体，S14。
- **复杂度：** 中（CMC 阻挡法线已经可读）。
- **建议：** 加入下一轮原型。

**G2 远程距离收益（远程流）**
- **规则：** 弹道主动（S06/S21）命中时，飞行距离超过 450cm 的部分，每 100cm 伤害 +6%，最多 +18%；或改为命中后返还 1.5s CD。
- **意义：** 让“难命中、远距离”有回报，并与 S04 点选但仍受目标合法性约束区分开。
- **滥用：** 极远距离消耗，受射程上限 1000 限制。
- **反制：** 贴近，身体挡弹。
- **复杂度：** 低（弹道已经记录起点）。
- **建议：** **优先评审**。

**G3 脑力的法术专属收益**
- **规则：** 脑力每点给“技能伤害 +0.5%”（只作用于主动原生直接伤害），替代部分法强。
- **意义：** 消除前期法师更想加力道的反直觉现象，又不放大混合构筑。
- **滥用：** 叠满后 B17、M07 乘法叠加。
- **反制：** 魔抗。
- **复杂度：** 低（统一加成池已经存在）。
- **建议：** 与 G9 一起评审。

**G4 缴械反制奖励（控制流）**
- **规则：** 被缴械期间，目标每次尝试普攻，都给施法者返还 0.5s CD（最多 2s）。
- **意义：** 让缴械真正惩罚普攻流，并给对手“停手”的决策。
- **滥用：** AI 可能不停尝试攻击。
- **反制：** 改用技能。
- **复杂度：** 中。
- **建议：** 考虑。

**G5 控制链终结（控制流）**
- **规则：** 硬控自然结束时，若目标在 1s 内被第二种控制命中，施法者获得一次小护盾。这是对 C05“打伤害”的防守替代。
- **复杂度：** 低。
- **建议：** 可作为新 C 件的候选。

**G6 冲刺资源转换（冲撞流）**
- **规则：** 新改装件：D 冲刺消耗 30 法力，获得“本次冲刺接触视为 S12 首次接触”的效果。
- **意义：** 让法力在近战构筑里有用途。
- **滥用：** 与 C03 组合形成循环，由每目标 4s 门控限制。
- **复杂度：** 中。
- **建议：** 观察。

**G7 区域形变（区域流）**
- **规则：** 区域内发生元素反应时，区域半径永久 +30cm（最多 +90）。
- **意义：** 鼓励把区域流和元素流结合，形成阵地。
- **反制：** 驱逐、远程消耗。
- **复杂度：** 中。
- **建议：** 考虑；区域每跳的 B07 来源项已在第二轮修复。

**G8 延迟咒文（法术联动）**
- **规则：** 新改装件：主动的伤害延迟 1.2s 结算 ×1.35，并显示可见标记。
- **意义：** 与 M02 账目延迟对称，为技能提供高风险高收益选项。
- **反制：** 走出标记、驱散。
- **复杂度：** 中。
- **建议：** 考虑。

**G9 普攻收益分流（普攻流，平衡）**
- **规则：** 强化包并入主击但**不吃暴击**；改为“强化包伤害 +25%”作为补偿；或者 B04 只吸主击本体。
- **意义：** 保留普攻流特色，削掉“暴击 × 强化 × 吸血”的三重叠乘。
- **风险：** 改变 #198 §7/§10.2 已批准的语义。
- **复杂度：** 低。
- **建议：** **需用户拍板**，先做原生 A/B。

**G10 召唤：自动拳桩（代理战斗）**
- **规则：** S19 陷阱可以改装为“桩”：6s 内对 300cm 内的敌人每秒做一次普攻级判定，触发绑定的 B01/B10/B11（不触发 B04）。
- **意义：** 不增加微操，让普攻构件服务区域流。
- **滥用：** 自动触发过多元素，受每秒一次限制。
- **复杂度：** 高（需要新实体与新事件）。
- **建议：** 远期。

**G11 风险换速（风险收益）**
- **规则：** 新基础构件：最大生命 −15%，所有主动 CD −20%。
- **意义：** 给法师一个明确的玻璃大炮选项。
- **反制：** 突进爆发。
- **复杂度：** 低。
- **建议：** 考虑。

**G12 返程弹道（远程）**
- **规则：** S06 可改装为返程：到达射程后返回施法者，返程伤害 50%，可二次命中。
- **意义：** 预判和走位操作更丰富。
- **复杂度：** 中（弹道实体需要支持反向）。
- **建议：** 与 G2 二选一。
