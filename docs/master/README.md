# Project Lockdown master plan

Revision 4 • 19 October 2026 • Long term reference

Project Lockdown is a competitive session RPG in a living world. Characters begin with a class and develop their own attributes, skills, profession and specialization. Combat, work, knowledge, theft, exploration and influence can support competing approaches to the Grand Heart. Appearance provides incomplete information about capability.

The full-match target is now **60–90 minutes**. There are **no predefined heroes**, no assigned primary attribute and no automatic class-specific attribute growth. Learned combat and utility actives compete for **one shared equipped-slot budget**. Four outer cities and a central city are a candidate layout, not a fixed world rule.

## Authority

Direct user decisions take precedence. Revision 4 replaces hero-roster plans, the 20–30 minute full-match target, fixed three-district assumptions and separate combat versus utility slot budgets. Earlier numerical attribute bonuses were brainstorming examples, not approved coefficients.

The source's eight-slot example, level-20 cap and city themes remain proposals. The v0.4 specification selects a smaller implementation target and marks new tuning explicitly. A short prototype does not validate the full 60–90 minute experience.

The user reported v0.2 complete. This plan was authored without auditing the Unreal implementation. The repository now retains [v0.3 implementation evidence](../v03/implementation/README.md), a [v0.4 baseline review](../v04/BASELINE_REVIEW.md) and [fresh B40 prerequisite verification](../v04/B40_BASELINE_AUDIT.md).
