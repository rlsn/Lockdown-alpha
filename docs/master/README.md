# Project Lockdown master plan

Revision 6 • 23 October 2026 • Long term reference

Project Lockdown is a competitive session RPG in a living world. Characters begin with a class and develop their own attributes, skills, profession and specialization. Combat, work, knowledge, theft, exploration and influence can support competing approaches to the Grand Heart. Appearance provides incomplete information about capability.

The full-match target is now **60–90 minutes**. There are **no predefined heroes**, no assigned primary attribute and no automatic class-specific attribute growth. Learned combat and utility actives compete for **one shared equipped-slot budget**. Four outer cities and a central city are a candidate layout, not a fixed world rule.

## Authority

Direct user decisions take precedence. Revision 6 adds a hybrid economy; revision 5 retained the character direction and adds a consistent interface and right-click navigation. Revision 4 replaced hero-roster plans, the 20–30 minute full-match target, fixed three-district assumptions and separate combat versus utility slot budgets. Earlier numerical attribute bonuses were brainstorming examples, not approved coefficients.

The source's eight-slot example, level-20 cap and city themes remain proposals. The v0.4 specification selected a smaller implementation target; v0.5 retains that reduced gameplay profile while improving UI and control. New sprint tuning is explicitly proposed. A short prototype does not validate the full 60–90 minute experience.

The user reports v0.5 delivered and requests a v0.6 economy sprint. This workspace contains specifications rather than the actual delivered Unreal repository. Audit that implementation before changing it; do not assume missing behavior or claim independent verification. Prior master revisions are preserved in separate archives.

The interface direction combines a minimap and lower character/skill panel with a large inventory and a smaller quick-item bar. Right-click path navigation replaces WASD as the default movement scheme. Selecting another unit changes the inspector, never control ownership or private-information authorization. Exact v0.5 capacities and bindings are proposed release defaults.

The economy direction is stable official shops plus dynamic regional markets and light production chains. Economic progression unlocks a contested Grand Heart acquisition, rather than an automatic wealth win. Clearly marked official service NPCs are permitted; ordinary bodies retain hidden identities. A no-dialogue interaction model is the proposed baseline. v0.6 tests a small bounded economy, not the entire long-session simulation.

The complete economy replies are now available through user-supplied attachments. The current long-term plan includes unified cargo weight, protected physical banking and distinct endorsements. A registered Charter triggers a public contest rather than private physical-Seal access; prototype counts/timers remain explicit adaptations.
