## 1. 核心诊断摘要

从实际运行态（而非纸面设计）审视 Lockdown 的战斗、元素、多人混战与终局，核心结论如下：

1. **基础机动与技能几何失配（“泥潭走位 + 瞬移冲刺”）**：基础移速被下调至 `240 cm/s` 后，走完 `900 cm` 喷漆圈直径需 `3.75s`（超过 `3.5s` 喷漆总时长！），站在 `S18 板砖糊脸`（半径 `200 cm`，总预警 `0.80s`）圆心即使 **0 毫秒反应也走不出圈（需 `0.833s`）**；而 `9.0s` 冷却的 `D` 冲刺却在 `0.18s` 内暴冲 `450 cm`（均速 `10.4×`）。平时腿短躲不开技能、交完 `D` 罚站挨打。
2. **两大操作招牌（精准闪避与爆劲）在实机中沦为边缘/负收益机制**：
   - **精准闪避**：Match 1 全场 69 条野外生命仅触发 **`6` 次（占劲收入 `0.7%`）**。根源在于五重门禁锁死：8 个技能前摇 `<0.15s` 硬豁免、AI 对 22/24 个参赛者技能 `WarningRemainingMs = 0` 完全失明、弹道闪避按飞行终点而非擦身时刻判 `300ms` 窗口（近身躲鞋反而判定超时失败！`LDCombatBranchDirector.cpp:708-715`）、原生擦伤窗口仅 `0.12s`（短于冲刺 `0.18s` 本身）。
   - **爆劲（Overdrive）**：花费 **`60` 劲 + 按住 `0.35s`** 仅换取 `×1.35` 倍率；期间右键走位会直接取消蓄力或吞掉 `Alt+技能` 自动栓锁（`LDPlayerInput.cpp:314`），满 `60` 劲时连瞬发防反/护盾（`S05/S14`）都被迫从“按下触发”劣化为“松键触发”，且在高急速流派中 **`0.35s` 停手使总 DPS 反降 `31.7%`（`1301.7 → 889.0`）**！更严重的是，专为爆劲设计的稀有牌 `Y11 气短` 因 C++ 公式写反（`LDCombatCards.cpp:2125-2140`），把说明写的 `140%` 算成了 **`118.12%` 削弱（叠 3 张变成 `90.43%` 负增伤）**！
3. **元素与地面状态生态“上层华丽、底层断供，三阶勋章自毁交互”**：`24` 个主动中 **`18` 个无原生元素**；5 种地面状态里 `水洼`（0 技能直接生成）、`火场`（仅 `N4.3B2` 书包三阶子分支生成，`S08 脚底开锅` 竟不是火场地面！）、`电场`（0 直接来源，必须水洼转麻）在常规对局中几乎绝迹；而 **Ⅲ阶元素勋章** 在代码里并非文档写的确定性副元素，而是 `HitId.A % 4u` **纯随机四选一自触发反应**（`LDCombatElementsDirector.cpp:113-121`），把原本需要双技能铺垫的元素博弈彻底压缩成无脑单键抽奖。
4. **终局“单中心 `450 cm` 独处圈 × `600 cm` 终圈”在 6–8 人局必然几何死锁**：缩圈到底时喷漆区占安全区面积高达 **`56.25%`**（圈外仅剩 `1.5m` 窄边），而规则要求圈内 **严格只有 `1` 名活人** 才能喷漆或推进守护——只要第 2 个人伸进半只脚就完全冻结（`0.0s/s`）。配合 `私人旗杆`（角落单机偷赢）与 `篡位`（尾刀满进度主人直接 `+4s` 秒赢）等绕过核心博弈的改装，12 分钟构筑在最后 2 分钟被迫退化为肉盾占坑或超时判分（且超时判分还漏算了历史 `BankedGuard`！）。

### 2.2 已核实的战斗与元素 C++ 缺陷清单

1. **`Y11 气短` 爆劲倍率写反（`LDCombatCards.cpp:2125-2140`）**：忽略 `MultiplierBp = 14000`（`140%`），每装一张反而乘 `0.875`（`118.12%` $\rightarrow$ `103.35%` $\rightarrow$ `90.43%`）。
2. **双元素技能分支失效（`LDCombatElementsDirector.cpp:173-181`）**：单次命中挂完第一个元素即 `return`，导致 `S09.3A2 带电水枪` **100% 不挂麻**、`S10.3A1 电出火` **吞掉原生麻元素**。
3. **Ⅲ阶勋章副元素随机化（`LDCombatElementsDirector.cpp:113-121`）**：用 `HitId.A % 4u` 随机抽副元素，违背规格与手册写明的确定性映射表。
4. **`N6 警戒封条` 宽度放大 3.14 倍（`LDCombatSkillDirector.cpp:259`）**：全宽 `70 cm` 未除以 2 直接写入 `HalfWidthCm` 并另加 `40 cm`，实判宽达 `220 cm`。
5. **`U05 鹰眼架枪` 射程脱节空放（`LDCombatActions.cpp:1595, 2376`）**：寻路按 `+160 cm` 停步，施法释放却按原射程截断，导致直线技能在增益区间内原地打空气。
6. **`N5 疯狗乱拳` 缺失 `CastLedger`（`LDCombatActions.cpp:1357-1393`）**：每拳生成新 `EffectId` 触发 `K01` 全技能减 1 秒 CD，却吃不到技能增伤乘区与爆劲元素加成。
7. **击退完全豁免控制递减（`LDCombatControlRules.cpp:80-92`）**：硬控共享 `2s` 递减（`100%→60%→30%`），但同样封锁移动/施法/普攻并打断喷漆的 **击退（Knockback）完全不计入递减**，多击退可无缝乒乓连控。

## 3. 元素系统深度评估：10 种反应与地面状态何去何从？

- **真正改变了玩家决策的高价值反应（4 种）**：
  1. **冻住（湿+冻）**：`1.2s` 定身，将两个软减速转化为留人/打断喷漆硬控。
  2. **碎冰（麻+冻）**：`4s` 内下一发直接技能 `+50%` 伤害，明确要求“先铺垫反应、后交重炮”的连招顺序。
  3. **起雾（烫+湿）**：瞬间结清全部剩余灼烧并留 `3s` 湿雾场，具备“挂火叠层 $\rightarrow$ 一发水引爆结算”的节奏感（遗憾的是当前“起雾”完全没有遮挡远距离视野/锁定的真烟雾效果，且不算 `GroundState`）。
  4. **导电（湿+麻）**：`450 cm` 潮湿连锁电弧，在多人团战与群怪中提供显著走位威慑。
- **存在感薄弱或高度同质化的“后台小数字”反应（3–4 种）**：
  - `过载（烫+麻）` 与 `沼气爆（烫+馊）` 均为 `1.5 R` 小范围溅射（后期扣魔抗仅 `45–65` 点伤害，占最大生命 `<2%`），无位移、无打断、无地面转换，在混战中玩家根本感知不到区别。
  - 反应基础值 $R = 30 + 4(L-1) + 0.25\,\text{AP}$ **完全没有额外 AD 加成**，导致物理/身手流派拿到元素勋章也打不出反应伤害。
- **Ⅲ阶勋章自触发批判**：Ⅲ阶勋章单次命中自触发反应直接摧毁了“先挂 A 元素、再找角度打 B 元素（或借别人挂的元素截胡反应）”的双步博弈。将其改为 **“元素共鸣：180cm 范围挂主元素 + 连招末段/爆劲在脚下生成对应地面状态”**，既保留三合一勋章的视觉与阵地质变，又完美守住双技能配合深度，还能一举补齐当前极度匮乏的地面状态供给！

## 4. 多人自由混战（FFA）、对局节奏与终局胜利条件评估

### 4.1 玩家注意力与时间预算审计

在真实试玩 Match 1（总长 `776.8s` = `12m 57s`，单人秒点准备）与多人满窗（最长 `994s` = `16m 34s`）中：
- **野外战斗段占比偏低**：前三段野外固定 `480s`，占 Match 1 总时长仅 **`61.8%`**（多人满窗仅 **`56.9%`**），低于规格 §16 设定的 `>= 65%` 健康线。

### 战斗、操作与元素提案
- **方案 A（最小修复）**：修复 `D1–D10` 全部 C++ Bug（`Y11` 倍率、`S09/S10` 双元素、`N6` 宽度、`U05` 射程、弹道擦身闪避时钟、`135 cm` 冲刺停步锥扩展至 `585 cm`）；基础移速提至 **`280 cm/s`**，`D` 冷却缩至 **`7.0s`**，闪避窗对齐冲刺全程 `0.18s`；反应公式加入自适应额外 AD。
- **方案 B（中等重构 · 推荐）**：在 A 基础上，**取消 `0.35s` 按住蓄力税**，改为 **`Alt + Q/W/E`（或 `R` 预装填）零延迟瞬发爆劲**（彻底恢复瞬发防反/护盾按键手感与 2 步预输入队列）；将 `S08/S09.2B/S10.2B` 接入真实地面状态并允许技能落点直接转化地面；将 **Ⅲ阶勋章改为“180 cm 范围挂元素 + 脚下生成微型地面状态”**，废除无脑自触发反应。
- **方案 C（激进重构）**：开局按主修方向分化三种普攻形态（近战重拳 / 横扫 / `460 cm` 篮球弹道远程平 A）；`D` 改为 **2 层充能冲刺**；击退纳入 `2s` 控制递减；5 元素精简为 **4 元素 6 种纯空间/机制反应**（浓雾真遮视野、爆震真击退破盾）。
- **方案 D（删减简化）**：删除手动爆劲按键，改为 **`60` 劲满槽自动强化下一发技能（普通施法零劲耗）**；勋章封顶 **Ⅱ阶**，溢出自动折算商店资源。

### 混战节奏与终局提案
- **方案 A（最小修复）**：修好 `D-04/05/06`（擂台、守护棘轮、`BankedGuard` 超时结算），`0` 观众自动跳过 `10s` 押注，休息窗压缩至 `25s / 45s / 45s / 30s`，终圈扩至 **`950 cm`**，重做 `私人旗杆` 与 `篡位`，全面修复 AI 7 大策略盲区。
- **方案 B（中等重构 · 推荐）**：采用 **`950 cm` 终圈 + “人数优势拔河守护”**（主人在圈内 `0` 挑战者 `+1.0s/s`，单挑 `1` 名挑战者仍按 `+0.4s/s` 慢速推进逼迫对手真打而非踩边混时长，`>=2` 名挑战者冻结）；**取消休息室独立 PK 子阶段**，将全休息窗压缩为紧凑的 **`25–30s` 整备站**，把擂台对决与场外快捷押注搬回修好后的 **F2 实景中心街区擂台**！野外 PvP 击杀即时回复 `20% 已损生命 + 30 劲` 对抗黄雀收割。
