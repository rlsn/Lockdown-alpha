# Lockdown 游戏性实验重构提案全集 (Experimental Redesign Proposals & Adversarial Review)

> **设计原则与授权边界**：本提案集中所有方案均建立在真实 C++ 源码核验、实机遥测与 `GameplayResearchLab` 实验之上，并经过独立审查 Agent 6（`rubber-duck`）的逆向反证与二阶副作用挑刺。**所有方案均为待用户拍板的研究提案，未直接改动正式对局规则。** 每个核心问题均提供 **A（最小改动）、B（中等重构）、C（激进替代）、D（删除/合并）** 四档方案及明确回滚策略。
