只记录 Product Owner（PO）的决定与待决事项。原文见 [batch-01/CHARTER.md](batch-01/CHARTER.md)。

## 已确认原则（不再讨论）

| ID | 原则 |
| --- | --- |
| P-3.1 | 构筑是游戏核心：构筑改变操作、战斗方式、连招、站位与策略；保留破格构筑、机制联动、稀有组合、多人混战与派对属性。 |
| P-3.2 | 保留属性点经济：属性点同时承担属性成长、关键石与商店购买；禁止独立构筑货币、商店津贴、额外代币或替代经济架构。 |
| P-3.3 | 终局允许根本性重构（Batch 04）；Batch 01 只修现有终局确定性逻辑错误。 |
| P-3.4 | 默认不改正式地图几何、角色模型与美术资产；允许修导航、碰撞配置、生成点准入与技术缺陷；二进制地图走 LFS 与关卡协作规范。 |
| P-3.5 | 效率 = 减少串行等待、重复编译与无意义沟通，不减少有价值的设计研究。 |
| P-4 | 审批分类：AUTO（工程，已授权）/ REVIEW（玩法，须 PO 明确批准）/ EXPERIMENT（隔离研究，可自行进行，不进正式默认规则）。 |
