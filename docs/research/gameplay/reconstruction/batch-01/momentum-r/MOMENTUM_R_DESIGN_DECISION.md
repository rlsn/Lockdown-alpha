# 劲 + 构筑驱动 R：设计决策报告（Batch 01）

> 交付人：S0 Coordinator。研究支撑：劲资源 [`momentum/`](momentum/)、R 架构 [`r-architecture/`](r-architecture/)、构筑融合 [`build-integration/`](build-integration/)、外部研究与独立反证 [`critique/`](critique/)、删除迁移清单 [`removal/MIGRATION_INVENTORY.md`](removal/MIGRATION_INVENTORY.md)。
> 本报告是**选择方向的材料，不是实施授权**。所有数值都是示意值，方向确定后再研究。
> 证据分级：L1 源码 / 配置 / 数学 · L2 离线模拟 · L4 原生整局（AI）· L5 真人（目前仅 1 局 1 人）。**本研究没有任何 L5 级的“好玩”证据**；凡写“玩家会觉得……”的都是假设。

## 第一部分：执行摘要

**1. 当前劲最根本的问题：它没有自己的职责。**
- 普通技能的劲耗与冷却设计成近似比例：不叠冷却急速时，3 个技能的劲耗速率（约 12–18/s）与交战收入（约 12–15/s）大致持平（L1）。
- 真人试玩中，技能按键被冷却拒绝 70 次、被劲拒绝 5 次（L5，n=1）。劲是冷却之外**重复的第二把锁**，锁住时玩家只是“等”，不是“选”。
- 劲唯一真正起作用的地方是：①限制冷却急速（急速只放大支出、不放大收入）；②已经删除的爆劲。
- 另一个关键事实：脱战后劲回落到 50，所以**几乎每场遭遇都从约 50 劲开始**（≥60 只有 8–12%，满劲 1–4%，L4/L5）。打野攒的劲在赶路中被吃掉。

**2. 删除长按爆劲与精准闪避之后，劲应该承担什么？**
- 精准闪避只占劲收入的 0.6–0.9%，删除几乎无影响；爆劲占原生花费的 5–20%，删除后这部分劲失去去处。
- AI 建议：**劲 = R 与构筑机制的燃料**，普通 Q/W/E 只看冷却。劲因此第一次有了清晰、可读的职责（“他的劲条快满了” = 他快有 R 了）。
- 代价：劲耗是冷却急速唯一的玩法刹车。去掉技能劲耗必须同时给急速另一个约束，并改写约 15 张劲相关牌——这部分属于 Batch 02 的构筑与属性研究。

**3. AI 认为 R 最有潜力的方向：「引信 + 宿主印记」。**
- **按 R** = 在身上装一发可见的“引信”。
- 每个玩家有一枚免费的 **R 印记**，放在自己的一个“宿主”上：Q、W、E、本体（普攻）或 D（冲刺）。自动模式在 Q/W/E/D 中选你投入最深的那个；放在本体需要手动选择（防止“3 记重拳”成为人人默认）。
- 印记所在宿主的**下一次动作**引爆引信。宿主类型决定引爆效果，共 5 种：**拳**（普攻）、**攻**（攻击技能）、**守**（防御技能）、**动**（冲刺）、**阵**（放置物），再叠加元素。
- 引爆效果**发出游戏里已有的事件**（例如“接下来 3 拳都按第 3 段结算”），于是你宿主上已有的卡牌、技能分支、勋章自动参与 R。
- 构筑改变的是 R 的**种类**（你的 R 是三记重拳、一面爆炸护盾、一次穿人冲刺还是一个立即武装的书包），而不只是倍率。

**4. 为什么？**
- **操作最简单**：全员只多一个 R 键，不长按、不组合、不瞄准；Q/W/E 永远不受劲影响。
- **构筑真正驱动 R**：R 的身份来自玩家已经在做的事（往哪里堆牌、点哪个分支），不需要新的成长系统，也不绑定关键石（避免加重“堆属性点、不买牌”）。
- **维护成本可控**：内容按 5 个处理器增长，而不是“技能 × 卡牌”的组合；新卡牌只要走已有事件就自动接入 R。
- **能被看见和反制**：引信有颜色（攻击 / 防御 / 机动 / 阵地四族）和起势音效；攻击类引爆按最高威胁等级给可读起手；硬控能打掉引信。

**5. 值得你选择的方案**（第五部分详述）
- **方案 B（AI 推荐）**：引信 + 宿主印记 + 「战斗热度」劲（技能不耗劲，劲在 PvP 交战中积累，R 是中盘转折点）。
- **方案 A（保守）**：「上劲」强化下一招 + 「急速税」劲（基础速度施法免费，只有被急速加快的部分付劲）。改动小，几乎不依赖 Batch 02。
- **方案 C（激进）**：「热度兑现」——劲变成冷 / 温 / 热三档的可见状态，R 一次花光，档位决定引信发数，可升级为短时“爆气”状态。高潮感最强，公平性风险最大。

**诚实标注**：方案 B 的两个卖点“构筑间公平”和“开局按 R 就有意义”目前只是**可设计 / 有理由相信**，没有证据。三套方案都需要一个隔离原型回答“按 R 是否像空按钮”和“8 人同屏是否看得清”。

### 2.2 四个实质不同的劲架构（另有一个属 Batch 03 的模块）

| | **劲-A 共享钱包** | **劲-B 战斗热度** | **劲-C 急速税** | **劲-D 档位状态** |
| --- | --- | --- | --- | --- |
| 劲怎么获得 | 不变 | PvP 交战被动（保留，约 30–40%）+ 普攻 + 技能命中（按冷却折算）+ 玩家亲手引发的反应（单独封顶）+ 构筑牌 | 不变 | 交战中按行为上涨，同时持续冷却；脱战归零 |
| 劲怎么消耗 | 技能 + R | **只有 R 和少数构筑机制** | 只有被急速加快的那部分施放 + R | R 一次清空当前档位 |
| 普通技能耗劲 | 是 | **否** | 只对急速部分（无急速构筑看不到劲耗） | 否 |
| R 与劲 | R 和技能抢同一份劲 | 劲 ≥ R 价格才能按；脱战回落到低于价格 → R 必须在交战中挣出来 | 进场就约 50 = R 价格 → R 可以开战 | 冷 / 温 / 热三档，R 按档位兑现 |
| 玩家的决策 | “这 50 劲放 R 还是放两个技能” | 什么时候按 R（看对手劲条、冷却）；要不要留在交战里挣 R | 急速流：快放技能还是留 R；其他构筑几乎无劲压力 | 早兑现低档，还是冒险维持高热 |
| 对构筑的影响 | 支出低的构筑（护盾、攻速）几乎白拿 R；技能、冲刺、区域流很少拿到 | 所有构筑在 2.5–5 s 内拿到 R（约 2 倍机会差）；回劲牌变成“R 加速牌”；急速流去掉劲锁后会变强 | 无急速构筑开场即有 R；高频技能流的 R 稀少（45% 短交战） | 不做强归一化时，只有元素和技能流能进高档 |
| 优点 | 改动最小；回劲牌全部保留意义 | 劲第一次有唯一职责；Q/W/E 永远简单；劲条成为可读的强势期信号 | 保留“劲是急速刹车”这唯一有用的功能；不依赖 B02 重做急速 | 强势期最可读；“攒还是花”是清楚的决策 |
| 主要风险 | 与“每个构筑都有自己的 R”直接冲突（L2：护盾 95% vs 冲刺 34% 短交战用得上 R） | **不能单独上线**：必须带着急速约束和约 15 张牌 / 分支的新含义；“计时器感”；R 不能开战；高收入构筑一场可多次 R | 规则不直观（同一个技能有时耗劲有时不耗）；技能说明要显示动态劲耗 | 变成“行为频率竞赛”；档位成为流派特权 |
| 研究证据 | L2 | L1/L2，原生校准 | L2 | L2 |
| AI 推荐 | **低** | **高** | **中**（不愿动技能劲耗时的次选） | **中低**（只作为方案 C 的骨架） |

**劲-E「攻防热度」**（劲-B + 挨打也涨劲）是 FFA 中的反收割机制，属于 Batch 03（A17 滚雪球与翻盘）范围，本轮不作推荐，只记录。

### 2.3 不论选哪个架构都要定的杠杆

| 杠杆 | AI 建议 |
| --- | --- |
| 进场基线 vs R 价格 | 决定 R 是“开战”还是“中盘”。劲-B：基线低于价格（中盘）；劲-C：基线 = 价格（开战） |
| 打野存劲 | 默认不让打野直接带满劲进 PvP；劲-B 下交战被动只计 PvP（否则刚打完营地的第三方带 R 进场） |

| | **R4 引信（+ 宿主印记）** | **R5 回响** | **R3 爆气状态** | **R1 上劲** | **R2 招牌大招** |
| --- | --- | --- | --- | --- | --- |
| 开局的 R | 按 R 装一发引信；印记自动落在你投入最深的技能或 D（本体需手动）→ 例如**下一次施放变成劲爆施放**，手动放在本体则是**下一次普攻起 3 拳按第 3 段结算**（3 拳总量按一次 2 级技能定预算） | 把你**刚放过的**那招再放一遍（约 60–70% 效果），只回响 5 s 内的技能 | 约 4 s 光环：冷却流速 ×1.5、移速小幅提升 | 约 5 s 内下一个 Q/W/E 变强化版 | 一个通用小招（例：原地震地 + 小护盾） |

| 未来扩展成本 | 低–中：5 个处理器；新卡牌走已有事件即零成本 | 最低 | 中高：子句数 ≈ 卡牌数 | 低，但 24 个技能都要设计强化版 | 高：每个原型一个完整大招 |

### 3.1 推荐方案的规则边界（R4 + 宿主印记，示意）

| 问题 | 规则 |
| --- | --- |
| 激活 | 劲 ≥ 价格才能按；**只能在交战中装填**（距最近一次战斗事件 ≤5 s） |
| 扣费 | **引爆时扣**；过期、被打掉、劲不足哑火都不扣 |
| 冷却 | 引爆、过期或主动卸下后进入同一个 R 冷却（示意 6 s），堵住“免费重装、永远上膛” |
| 持续 | 一发引信最多约 6 s；宿主冷却中可以按，引信等宿主就绪（R 按钮显示宿主图标和冷却） |
| 谁能引爆 | **只有自己的主动动作**（施放、普攻、冲刺）；自动卡牌、持续伤害、地面、反伤、派生施放都不引爆。拳 / 攻 / 动的引爆要命中参赛者；视野内没有敌方参赛者时野怪也算 |
| 控制下 | 眩晕、击退、嘲讽时不能按；硬控打掉已装好的引信（“泄劲”，不扣劲，双方都有提示） |
| 发数 | 默认 1 发；改写牌最多 3 发，一次按 R 只付一次价 |
| 防递归 | 引爆动作本身算一次正常施放（宿主牌照常触发一次）；引爆新增的事件可以触发伤害、控制、元素、护盾、额外打击类牌，**不能**产劲、偷劲、刷新宿主冷却（R 标记的冲刺接触不刷新冲刺）、免费重放、重新装填；冷却缩减类在一条引爆链里只结算一次；引爆动作及其派生事件都继承“R 标记”但不继承载荷；每张派生施放牌每次引爆最多 1 次；穿人接触按人数递减 |
| 改写与修饰 | 改写牌同时只生效 1 张（工坊拒绝第二张并说明）；修饰数值相加不相乘 |
| 换牌 / 换印记 | 印记随时可换，装着引信时不能换；换牌下次装填生效 |
| 死亡、阶段切换 | 清空且不扣费；休息室可对训练假人练习 |
| 关键石 | 不与 R 显式挂钩，只通过它们已有的效果自然参与 |

### 3.2 R 的可读性需求（交给 S3b 的分级预警规范）

起势动作 + 专属音效 + 脚下颜色环（只在视野内、一定距离内显示）；颜色只用 4 个族，与元素色、席位色可区分；攻击类引爆按 Threat Grammar 的 Type4（高威胁 / 承诺）显示；剩余发数图标化；被打掉有双方可见的反馈。8 人同屏可读性是**原型的首要验证问题**。

## 第四部分：真实构筑示例（R4 宿主印记，括号内为 R5 回响对照）

以下全部使用现有技能、卡牌、关键石与元素（完整 12 项见 [`build-integration/BUILD_INTEGRATION.md`](build-integration/BUILD_INTEGRATION.md) §3）。

**1. 普攻攻速 ·「千厘加特林」**（左右开抽、手快有手慢无、越打越上头、隔空抽你、身手 18、本体麻勋章）
- 玩家把印记手动放在本体（自动模式只在技能与 D 中选）。平时 580 cm 远程飞拳走 A，第 2、3 段挂麻。
- 对手在你射程边缘晃。你按 R，脚下亮起红环；接下来 3 拳全部按第 3 段结算、全部挂麻，每一下第 3 段直击再追加一次电。手快有手慢无的追加拳照常出，但不消耗引信。
- 对手看到红环和拳套发光，可以拉开距离、躲到书包后挡飞拳，或用缴械、冻疮（攻速 −40%）和硬控打掉引信。
- 未成型时只是 3 拳 ×1.3；拿到左右开弓后变成 6 下全挂麻，R 从“加一点伤害”变成“一串连电”。
- 风险：越打越上头没有层数上限（已转 Batch 02），R 绝不能让追加拳叠层。（R5：没有拳类技能时，R 只能回响别的技能，身份断裂。）

**2. 慢速重击 ·「千斤重锤推墙」**（千斤重锤、慢工出细活、第三拳滚蛋、拧你手腕 3A2、力道 18）
- 平时每第 3 段必暴击并推人 150 cm，撞墙眩晕。按 R 后 **3 拳全是必暴重拳**，把对手沿墙连推、撞墙晕、再推。
- **把印记换到拧你手腕**：R 变成“劲爆招架”（持续 ×1.5、零延迟），招架成功照常接 3 拳——同一套牌，一个是推墙重锤，一个是防反重锤。
- 对手的反制：远离墙、拉开 250 cm 风筝；眩晕有递减；看到每拳 1.33 s 的慢起手。
- 风险：两墙之间来回撞，击退本身不计递减，需要验证峰值伤害。（R5：重锤在回响下价值偏低。）

**3. 技能循环 ·「技能永动机」**（甩你一鞋、电你个哆嗦、板砖糊脸 2A、打完换下一招 ×2、一招接一招、脑力 18）
- 印记默认在板砖。鞋 → 电 → 按 R → 劲爆连环砖（金光起手 + 0.55 s 落点圈）。R 是一轮连招的终结技，轮转顺序成为决策。
- 对手：走出 200 cm 落点（走位不够就得冲刺）、沉默打断轮转、硬控泄劲。
- 关键：**在劲-A 下这个构筑几乎付不起 R**，在劲-B / C 下正常。（R5：最适合这个流派——回响就是把刚才的砖再落一次。）

**4. 元素反应 ·「湿麻冻导电」**（滋你一脸 + 湿勋章、冰可乐、电你个哆嗦 + 炸了接着放、炸得更响、反应回本、脑力 18）
- 先用滋把人群打湿，按 R，劲爆电弹到湿身对手 → 导电**范围化**，450 cm 内所有湿身敌人一起被电。
- 对手：别带着湿靠近他（湿 4 s 后消失）、散开、堆魔抗；R 标记的反应不产劲，避免“又快拿 R 又会用 R”。
- R 从“单体加电”变成“对一群湿身对手的阵型威胁”。（R5：回响滋你一脸只是再泼一次水。）

**5. 冲刺机动 ·「穿人列车」**（撞着就刷新、穿人而过、蹿过去抡一拳、失控列车、身手 18）
- 印记默认在 D。按 R 后选一条能穿过 2–3 人的线：劲冲穿人、每人吃一拳、落地震地减速；撞着就刷新让下一次普通冲刺也能再穿一次。
- 对手只能靠蓝环预判（冲刺只有 0.18 s）：定身禁冲、警戒封条撞线眩晕、别扎堆、站在空地。
- 待定：在 D 冷却时按 R 能否让 D 立即就绪（触及“冲刺基础定位不变”）。AI 默认**不刷新**。（R5：D 不是技能，纯冲刺流没有回响身份。）

**6. 护盾防反 ·「锅盖反应装甲」**（锅盖挡脸 3A1、扯嗓子喷你 3B2、反应装甲、壳碎了也崩你、挨揍起硬皮、体格 18）
- 等对手的爆发砸上来，按 R 开劲爆锅盖（×1.5 盾、零延迟、解减速 / 定身、反弹），再开扯嗓子叠第二层盾触发弹片，最后 3B2 主动引爆：大盾碎裂时向周围爆开。
- 对手看到绿环 = “他的下一面盾更强”：用馊 / 发酵削盾、别往反弹盾上打、等 4 s 过期、离开 300 cm 爆炸圈。
- R 从“更厚的盾”变成“一颗由敌人伤害喂大的炸弹”。（R5：第二面盾，护盾流在回响下过强。）

**7. 召唤与工事 ·「书包封点」**（占座书包 3A1、电风扇 3A2、违章工事、双摊位、脚底开锅、体格加点）
- 先放一个普通书包，按 R，第二个劲爆书包落在旗杆另一侧 → 墙立即成形、持续 6 s、爆炸半径 +30%；在墙后开锅、开风扇刮出元素风暴。
- 对手：远程先拆书包、绕路、等 6 s、离开爆炸圈。
- 风险：**阵地内容断供**（6 张牌、0 张稀有，电风扇 / 陷阱 / 封条不在开局池），Batch 01 只能交付半成品；封点对终局的影响属 Batch 04。

**8. 文武混合 ·「文武魔剑」**（脑转手快、咒刃回响、读书人打架、文武双全、拳里带招、甩你一鞋、本体烫勋章）
- 印记在本体：放鞋 → 3 拳劲拳带剑气和灼烧；拿到拳里带招后每拳再放一次 45% 的鞋。印记在鞋上：R 变成劲爆鞋 + 剑气——同一套牌两种 R。
- 文武双全“技能命中后下一拳偷 8 劲”在劲喂 R 的世界里 = **压低对手的 R**，成为可读的反制工具。
- 风险：拳里带招在一次引爆内放 3 次技能，超出预算 → 传说破格能否超预算需要决定（建议方向确定后再定）。

**9. 压力测试 ·「憋一发板砖」**（板砖 3B1、攒够一顿狠的、憋着一发狠的、攒个大的、技能也能暴击）
- 不出手攒乘区（最高约 12.6×），开战一砖。它证明**攻击类引爆必须是加法固定预算**，不能再乘一层，否则 R 就是秒杀开关。

**小结**：R4 能承载全部 9 类，且同一套牌可以通过换印记得到不同的 R；R5 只在技能循环流最好，对护盾 / 工事过强、对重锤 / 冲刺无身份。

## 第五部分：三套综合设计候选

### 方案 A —「上劲」（简洁、保守、低改动）

R1 上劲 + 劲-C 急速税。

1. **怎么获得劲**：与现在相同（交战被动、普攻、技能命中、反应、牌）。
2. **普通技能耗劲吗**：按技能原始冷却节奏施放**免费**；只有被冷却急速加快的那部分付劲。不叠急速的玩家看不到劲耗。
3. **按 R 后**：拳头亮金，约 5 s 内下一个 Q/W/E 变强化版：攻击技能更痛并附带元素效果（复用现行爆劲元素表，追加约 0.15 s 金光起手）；防御技能持续与范围 ×1.5，零延迟；位移技能更远并穿人。
4. **R 怎么随构筑成长**：卡牌改强化次数、对象、连锁（例：气短改为降低 R 价格）。
5. **构筑如何改变 R**：主要改大小，不改种类。
6. **对手如何反制**：看到金光就躲或打断下一招；硬控打掉“上劲”状态。
7. **为什么愿意用**：R 价格约 50 = 进场劲，开战第一招就能是强化招，用法和直觉都接近原来的爆劲，但不再长按。
8. **为什么适合 Lockdown**：几乎不依赖 Batch 02；现有劲相关牌大多保持意义（急速流仍需回劲牌）；新手心智模型最简单。
9. **牺牲什么**：R 很快退化为伤害倍率；“构筑驱动 R”的诉求基本没有实现；构筑间价值差偏向大技能构筑；高急速技能流很少拿到 R；“同一个技能有时耗劲有时不耗”需要解释。
10. **实现与维护**：低。复用爆劲载荷与特效；需要“急速部分付劲”的计算与技能说明显示；24 个技能各需一个有意思的强化版。

### 方案 B —「引信印记」（构筑驱动、结构性重构，**AI 推荐**）

R4 引信 + 宿主印记（5 个处理器）+ 劲-B 战斗热度。R5 回响、R3 爆气作为 Batch 02 的改写牌进入。

1. **怎么获得劲**：PvP 交战中被动积累（保留，作为公平的底）+ 普攻 + 技能命中（按冷却折算）+ 玩家亲手引发的反应（封顶）+ 构筑牌。打野不再给 R 存劲；脱战回落到低于 R 价格。
2. **普通技能耗劲吗**：**不耗**，Q/W/E 只看冷却。
3. **按 R 后**：脚下亮起颜色环，印记所在宿主的下一次动作引爆：本体 → 3 记第 3 段重拳；攻击技能 → 劲爆施放 + 元素；防御技能 → ×1.5 盾或招架、碎裂时爆开；D → 穿人冲刺 + 落地震地；放置物 → 立即武装、更大更久。
4. **R 怎么随构筑成长**：你在宿主上堆的牌、点的技能分支、勋章元素都会改变引爆的样子；Batch 02 再加少量改写牌（+1 发、回响、状态化、R 价格）。
5. **构筑如何改变 R**：改变 R 的**种类**；换印记位置就能得到同一套牌的另一种 R。
6. **对手如何反制**：读劲条（“他快满了”）、读环的颜色（防哪类动作）、躲攻击类的可读起手、硬控泄劲、削盾或等过期、远离放置物。
7. **为什么愿意用**：R 是交战中挣出来的转折点（各构筑约 2.5–5 s），引爆的就是你自己构筑最拿手的那个动作。
8. **为什么适合 Lockdown**：最贴合“简单操作、复杂构筑、深度决策”；不新增成长系统、不绑关键石（不加重“堆点不买牌”）；现有约 86 张牌经事件自动参与 R，首版不需要 R 专属牌。
9. **牺牲什么**：R 不能用来开战；失去“技能耗劲”这一层取舍；必须同时做急速约束和约 15 张牌 / 分支的改写（交付边界见第七部分问题 5）；R 价值随宿主上的牌增长，构筑间不再严格等值；“印记”是一个新概念；纯普攻玩家要手动把印记放到本体（多一步操作）；阵地流内容不足（B01 只能交付“可用但不质变”的阵处理器，退路是并入攻处理器）。
10. **实现与维护**：中。5 个处理器、印记 UI、引信环与音效、按卡牌操作类型的防递归护栏与监听者审计（59 个操作 / 8 类规则，18 个待审，计入首版成本）、AI 选印记与用 R、`LD_R` 遥测；R 行为约 30 种 × 宿主技能现有变化；维护按处理器做回归，没有“R 牌 × R 牌”的组合矩阵。

### 方案 C —「热度兑现」（原创、高涌现、激进）

劲-D 档位状态 + R4 处理器 + 档位决定发数，热档可兑现为短时“爆气”。

1. **怎么获得劲**：交战中按行为上涨、同时持续冷却；脱战归零。劲条分冷 / 温 / 热三档，角色身上有对应的热度光效。
2. **普通技能耗劲吗**：不耗。
3. **按 R 后**：一次清空全部热度：温档 = 1 发引信，热档 = 2 发引信；热档也可以（通过改写牌）兑现为约 3 s 的“爆气”——这段时间内宿主动作都按处理器结算一次。
4. **R 怎么随构筑成长**：同方案 B 的印记与处理器；另有影响“升温速度”和“各档被动”的牌。
5. **构筑如何改变 R**：种类 + 强度档位。
6. **对手如何反制**：热度光效公开，“他烧红了”就是撤退或先手打断的信号；硬控打掉引信；拉开熬过爆气。
7. **为什么愿意用**：“攒还是花”是清楚、刺激的决策，热档爆气提供最强的阶段性高潮感，最适合派对观赏。
8. **为什么适合 Lockdown**：强势期可读，符合搞怪夸张的混战喜剧感；仍然只有一个 R 键。
9. **牺牲什么**：不做强归一化时，只有元素和技能流能进入热档（L2：≥60 时间 26% / 8%，其余接近 0）——档位成为流派特权；“满热度进场”的先手爆发问题；规则与 UI 最复杂。
10. **实现与维护**：中高。所有收入源都要归一化；档位 × 处理器的组合翻倍；爆气状态的可读性在 8 人混战中风险最高。

### 排序与反对意见（AI）

| 排序 | 方案 | 理由 | AI 自己的反对意见 |
| --- | --- | --- | --- |
| 1 | **B 引信印记** | 唯一真正实现“构筑决定 R 的种类”且不加成长系统、不绑关键石的方案；劲第一次有清楚职责 | 依赖 Batch 02 的急速约束与牌面改写才能正式上线；“空按钮感”和 8 人可读性没有证据；构筑间公平只是可设计 |
| 2 | A 上劲 | 改动最小、最稳；可作为 B 的第一阶段（B 只开技能宿主时就是 A 的 R） | 很快变成倍率；违背“构筑驱动 R”的核心诉求；急速流几乎没有 R |
| 3 | C 热度兑现 | 高潮感与观赏性最强 | 公平性风险最大，必须先解决收入归一化；最复杂 |

**组合与冲突**
- A → B 可以分阶段：先上“只开技能宿主”的 R4（等于 A 的 R），劲用 C；再在 Batch 02 开放本体 / D / 放置物宿主并切换到劲-B。
- B 的 R 规则与 C 的劲规则可以组合（C 本身就是 B 的处理器 + 档位劲）。
- R5 回响、R3 爆气可以作为任一方案的改写牌；R2 招牌大招与 B 的“印记决定 R”冲突，与“不绑关键石”冲突。
- 任何 R + 劲-A 共享钱包：不推荐（R 被支出低的构筑垄断）。
- 对照组「R 只看冷却、不用劲」（Battlerite Royale 在 FFA 中删除了 R 的能量消耗）：最简单，但等于决定劲的去留（删除或另找职责）。作为第七部分问题 4 的一个选项。
