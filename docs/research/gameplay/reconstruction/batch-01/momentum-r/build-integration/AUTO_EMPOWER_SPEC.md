# 自动强化实现规格（Auto-Empower · MR-Impl 编码用）

> 依据：PO 第四道指令（批准实施）；研究来源 [`BUILD_INTEGRATION.md`](BUILD_INTEGRATION.md)（宿主印记、五类处理器）、S3 [`R_ARCHITECTURE.md`](../r-architecture/R_ARCHITECTURE.md) §13、S1 [`MIGRATION_INVENTORY.md`](../removal/MIGRATION_INVENTORY.md)。
> 基线：在 `sinmentis/b01-mr-removal`（已删通用长按爆劲与精准闪避）之上实现，全部行为挂在一个隔离开关后（§8）。行号以主干 `e62ff304` 为准，以符号名为准。
> 数值都是**实验值**（PO 授权 AI 自定），集中在 §2.1 参数表；由 S2 的模拟与原生实验校准。

## 0. 一句话规则

劲 ≥ `EMPOWER.Threshold` 时，玩家在构筑界面指定的**宿主**（普攻 / Q / W / E / D）的下一次**合法动作**自动成为强化版；该动作**成功释放**即扣 `EMPOWER.Cost`（打空也扣）。非宿主动作照常、不消耗。普通 Q/W/E 不再耗劲，只看冷却。没有 R 键、没有 Alt、没有泄劲、没有强化冷却、没有新状态机。

## 1. 合法动作与扣费

### 1.1 判定时点（全部宿主通用）

| 时点 | 规则 | 代码位置 |
| --- | --- | --- |
| **起手**（动作被接纳、进入前摇；无前摇动作即释放帧） | `Action.bEmpowered = (Action.Entry == Body.EmpowerHost) && Momentum ≥ Threshold && 该动作是合法动作（§1.2）`。前摇与观察帧从这一刻起显示强化起手（§4） | 普攻：开始挥击处；技能/冲刺：`ProcessDirect` 接纳并写入 `Body.Action` 处；预输入在出队开始时判定 |
| **释放**（服务器放行，所有可能失败的检查都已通过） | 若 `bEmpowered` 且 `Momentum ≥ Cost`：扣 `Cost`、应用载荷（§2）、写 `LD_EMPOWER`。若此刻 `Momentum < Cost`（前摇中被偷劲等）：按普通动作释放，不扣费，`LD_EMPOWER outcome=short` | 技能/冲刺：`ReleaseAbility` 中现 `PaidP2` 扣费处（原爆劲扣费点）；普攻：`ReleaseBasic` 通过 `BasicReleaseGate` 之后、`LandBasic` 之前 |
| **释放之后** | 已扣费，不退：打空、无目标、目标闪开、施法者随后死亡都不退 | — |

不变量：`Cost ≤ Threshold`（导入校验），所以扣费永不使劲 < 0；起手判定与释放扣费之间只差一次 `Momentum ≥ Cost` 复核，不保存其他状态。

### 1.2 每类宿主的合法动作

| 宿主 | 算合法动作 | 不算（不强化、不消耗） |
| --- | --- | --- |
| 普攻 | 参赛者的**主普攻挥击**（`HitClass=BasicPrimary` 的起手），含追击右键、攻击移动、A05 飞行普攻；目标可为参赛者、野怪、训练假人 | A06/A07/A09 追加打击、D06 穿人普攻（`MakeBasicStrike`）、S11/S17/N5 强化包本身、U02 剑气、反伤、野怪特殊技 |
| Q / W / E | 该槽**已学主动**的一次**付费释放**：通过 `ActiveGate`、进入冷却或消耗一次充能 | K06 `auto_recast` 重放、A08 `combo_cast`、分支免费再放窗口（S02 3B2、S13 3B2 等 `bBranchRecast`）、K25/K03 等刷新后的释放**算**（它们是正常付费释放） |
| D | 通用冲刺的一次释放；D05 两段冲刺**只有第一段** | D05 后续段、冲刺技能（它们属于 Q/W/E 宿主） |

宿主槽为空（技能被遗忘、尚未学）时宿主不变、不自动转移；HUD 显示宿主灰色（§4）。

### 1.3 失败、打断与取消

| 情况 | 结果 |
| --- | --- |
| 前摇中移动、急停、右键取消、换成别的动作 | 没有释放 → 不扣费；强化机会仍在，下一次合法动作重新判定 |
| 前摇中被眩晕、沉默、嘲讽、击退打断（现有 `AbandonAction`） | 不扣费 |
| 释放被拒：目标死亡/离开视野（`BasicReleaseGate`）、被缴械、定身禁冲刺、来源已遗忘、无充能、K12 生命不足 | 不扣费 |
| 成功释放但未命中任何目标 | **扣费** |
| 释放前劲已 < Cost | 普通释放、不扣费（`outcome=short`） |
| 起手时劲 < Threshold、释放前涨过 Threshold | 本次不强化（只在起手判定），下一次合法动作再判 |
| 死亡、复活、休息开始 | 劲按现规则重置；宿主选择保留到本局结束 |

## 2. 载荷

原则：**改机制与形态，不乘伤害**。不保留 `OVERDRIVE.Scale`；伤害只来自形态变化（多打到人、多一次落点、多一段持续）。载荷 = 宿主当前已选分支的完整定义 + 一份强化补丁 + 元素层。

实现建议：技能宿主的补丁写成每个技能的 `empower` 补丁，**复用技能分支的登记补丁机制**（改目标、改字段、乘字段、加/删效果）。导入器对每个技能的 7 条分支路径各编译一次“分支 + 强化补丁”，补丁与分支已有同一机制时叠加（例：S18 2A 已再落一次 → 强化再落第二次），无法编译的组合在导入时拒绝。普攻与 D 的载荷是角色级，写在原生。

## 3. 防递归与派生事件规则（最终表）

### 3.1 四条规则

| # | 规则 | 实现 |
| --- | --- | --- |
| E1 | **强化链不给施法者产劲、不替施法者偷劲。** 强化释放打开的链（`ChainId`）内，任何 `GrantMomentum(+)` 的受益者若是该施法者，则跳过并记 `blocked`；受害者的劲变化（被偷、脸皮关键石回劲）照常 | 强化释放时把 `CurrentChain` 记入 `Body.EmpoweredChains`（随链结束清除）；在 `GrantMomentum` 正数入口按 `CurrentChain`/命中的 `ChainId` 判定 |
| E2 | **派生动作不被强化、不消耗强化、不继承载荷。** 派生 = §1.2 “不算”一列的全部，以及反应、区域跳伤、地面状态、陷阱爆炸 | 派生动作的 `bEmpowered=false`；它们沿用所在链（于是 E1 覆盖它们的回劲） |
| E3 | **强化冲刺的穿人接触最多 `DashContactCap` 人**；超出者不算接触、不触发接触类牌 | 动处理器内计数 |
| E4 | 其余卡牌效果**照常开放**：一次强化就是一次正常动作，现有护栏（`bAutoRecast`、`ChainAllows`、`EffectBudgets` 每次释放一次）不变 | — |

为什么不需要更多规则：每次强化都要付 `Cost`，而 E1 保证付出的劲不能在同一条链里赚回来；冷却刷新、减冷却只能换来**普通**动作，不能换来下一次强化。所以没有“强化 → 回劲 → 再强化”的闭环。不加泄劲、强化冷却或次数上限（PO §1）。

## 5. 宿主选择与 AI

**玩家默认宿主 = 普攻**，没有自动模式，宿主不会自己改变。
- 理由：L1 只有普攻与 D 可用；普攻宿主人人能用、无学习成本。原研究中“本体只能手动”是为了防自动模式收敛；现在宿主由玩家在构筑界面主动指定，不需要那条限制。
- 收敛风险改由提示处理：玩家第一次学会技能、或第一次往某个技能上装牌时，构筑界面的宿主行闪一次提示（纯 UI，不改状态）。
- 构筑命令：`SetEmpowerHost(Entry)`，走现有成长命令的权威提交与回执去重（match/life/order/revision）；任何时候可提交（含交战、死亡等待、休息）；本局内跨命保留。

**AI 选宿主**（重算时机：学技能、换技能、装卸牌之后）：
1. 有质变目标样板（`LDBreakoutPresets`）时，用样板表的宿主列（实现时给 10 个样板各填一个宿主）。
2. 否则对 Q/W/E/D/普攻各算分：宿主上装的牌数 + (技能等级 − 1) + 勋章阶数；普攻计本体上的第 3 段/普攻牌与本体勋章。取最高，并列按 Q→W→E→普攻→D。
3. 宿主槽为空时立即重算。

**AI 何时强化**：不做额外决策，按 PO“自然发生”。唯一调整：AI 的施法优先级在劲 ≥ Threshold 且宿主是技能时，把宿主技能留给参赛者目标（打野时仍会自然强化，但不主动用宿主技能清小怪）。删除 `LDOpponentPolicy.cpp` 中“满劲且目标血量 > 40% 时爆劲”的 `bOverdrive` 意图（S1 清单 A4，归 B01 S2，改前协调 S0）。
