# 劲的原生基线（S5 独立复核用，供各 Session 引用）

来源：现有两份原生日志的权威账本（`LD_MOMENTUM`，身体移除时写入；休息室训练生命已排除）与 1 s 心跳（`LD_HEARTBEAT momentum=`）。命令：`python -B .\Scripts\SummarizePlaytestLog.py <log> --metrics-only`；交战分布为临时分析。两份都是删除前的旧规则，且 AI 存在施法偏少等缺陷（S2 在修），只作现状参照。

读法（L4/L5 实测，单局样本）：

1. **劲的最大来源是“在交战中待着”**（约 40%），不是某个动作。现行劲更像“交战计时器”，其次才是普攻节拍。
2. **删除精准闪避只减少约 1% 收入**，对劲经济几乎没有直接影响；影响在于失去的“操作即回报”的叙事。
3. **约 85% 的劲被花掉**，主要流向 Q/W/E 的劲耗。普通技能的劲耗是劲的主要出口，这是 M1–M4 取舍的核心事实。
4. 交战中约一半时间劲 ≥60；长按爆劲的低使用率不是劲不够（见 `research\S5\T05-06_S4_REVIEW.md` E1/E2）。

需要在 Clean Baseline（AI 施法修复）后复测：AI 施法变多后，出口变大，交战中劲可能变紧。
