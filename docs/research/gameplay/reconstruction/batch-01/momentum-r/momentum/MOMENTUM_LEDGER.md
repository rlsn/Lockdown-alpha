## 2. 结构性事实（L1 推导）

1. **在无急速时，劲耗和冷却是同一个约束。**
   - 3 个技能的劲耗速率合计约 12–18 / s。
   - 交战收入约为被动 5 + 普攻 ≤7.5 + 技能命中约 2–3 ≈ 12–15 / s。
   - 两者设计上接近持平，所以劲约束只在边缘生效。
2. **冷却急速只放大支出、不放大收入。**急速 H 让劲耗速率乘以 (1 + H/100)，收入不变（除非装了脑子转得快）。所以高频技能流必然缺劲，急速投资的边际收益被劲吃掉。
3. **攻速不产生额外的劲。**普攻回劲按攻击间隔折算，每秒约 7.5 和攻速无关。所谓“攻速流劲溢出”，原因是这类构筑常搭配**便宜、长冷却的自身增益技能**（左右开抽 20 / 6.3 s、锅盖 25 / 7 s），支出低；与攻速本身无关。唯一随攻速增长的劲来源是第三拳回口气。
4. **收入的结构性差距来自反应和牌。**按单位时间算：反应 10–25 + 脑力关键石返还 + 一招回本、脑子转得快 ≫ 普攻和被动。元素循环流的收入可以达到裸构筑的 2–3 倍（L2 见研究文档）。
5. **50 是一条“引力线”。**
   - 低于 50：脱战后免费补回 50。
   - 高于 50：脱战后被收走。
   - 结果：玩家几乎总是带着 50 进入下一场遭遇，打野积攒的劲在赶路中被回落吃掉。
6. **打野怪同样触发交战回复**，而且范围技能打营地按目标数回劲。所以野区是劲的“充电站”，但充满的劲留不到 PvP。

**读法**：
- 交战中劲常常偏高（真人在 PvP 中 71% 的时间 ≥60，在打野中 54% 的时间是满的，溢出浪费）。
- 但**几乎每场遭遇都从约 50 开始**：打野存下的劲在赶路中被回落吃掉。
- 所以任何“需要 60 以上才能用”的资源都**不能在遭遇第一秒使用**；按 S5 的统计要等 2.4–3.1 s，而交战 TTK 的中位数只有 4.8 s。

## 5. 各流派的劲循环

由 `momentum_sim.py` 生成（L2），包括“饱和（一转好就放）”和“按原生校准”两种施法强度。表格与读法见 [`MOMENTUM_RESEARCH.md` §2](MOMENTUM_RESEARCH.md)。

要点：在现行规则下，攻速、元素、护盾三类流派长期溢出（15–20% 的时间顶满）；高频技能、冲刺、区域三类流派缺劲。差别来自支出（急速、贵技能、冲刺耗劲）和反应类收入，与攻速无关。
