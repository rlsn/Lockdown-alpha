## 0. 摘要

**当前劲最根本的问题：它没有自己的职责。**
- 在无冷却急速时，每个技能的劲耗与冷却成比例，3 个技能的劲耗速率（约 12–18/s）与交战收入（约 12–15/s）大致持平（L1）。
- 真人按键被冷却拒绝 70 次，被劲拒绝 5 次（L5，n=1）。普通施法基本只受冷却约束，劲是第二把重复的锁。
- 劲只在两种情况下真正起作用：
  - 一是冷却急速高的构筑，急速只放大支出、不放大收入，所以必然缺劲；
  - 二是被删掉的爆劲。
- 结果是两头不讨好：
  - 支出低的构筑（攻速、护盾）长期溢出，约 15–20% 的时间顶满（L2 校准）。
  - 高急速技能流长期缺劲，“饱和施法”下 100% 的时间在等劲（L2）。
- 此外有一条“引力线”：脱战后劲双向回到 50。所以**几乎每场遭遇都从约 50 开始**（原生：进入遭遇时 ≥60 只有 8–12%，L4/L5），打野积攒的劲在赶路中被吃掉。

**删除长按爆劲与精准闪避之后：**
- 精准闪避只占收入的 0.6–0.9%，删掉几乎没有影响。
- 爆劲占原生花费的 5–20%，删掉后这部分支出没有了去处，劲会更常溢出。
- 劲剩下的唯一职责是“第二把锁”。**劲需要一个新职责，而 R 是最自然的出口。**

**AI 推荐**：
- 首选**劲-B「战斗热度」**：普通技能只看冷却，劲只喂给 R 和构筑机制。劲的收入保留“在交战中就涨”的公平部分，加上按节拍归一化的行为收入。
- **劲-B 不能单独上线。**劲耗是冷却急速唯一的玩法刹车，删除技能劲耗时，正式版本必须同时带上：
  - 急速约束；
  - 约 15 张牌和分支的新含义。
  否则会出现 PO 禁止交付的失效构筑。所以选劲-B 等于把一部分 Batch 02 工作拉进 Batch 01 的交付条件；否则 Batch 01 只能在隔离开关下验证劲-B（§11）。
  - 影响的量级：饱和施法、急速叠满的样板中，施法次数上限 +183%；原生节奏下只有 0 ~ +11%（L2）。
- 劲-E「攻防热度」（挨打也涨劲）是反滚雪球机制，**属于 Batch 03（A17）的范围**，这里只作为劲-B 的可选研究模块，不作为 Batch 01 的默认推荐。
- 如果 PO 不愿意动普通技能的劲耗，次选**劲-C「急速税」**：只有被急速加快的那部分施放才付劲。
- **不推荐**维持现状只给 R 加一个价格（劲-A）：模拟中 R 要么在开场吃掉 30–47% 的技能施放，要么主要被支出低的构筑享用，与“每种构筑都有自己的 R”相反。

## 2. 各流派的劲循环（L2，L10，10 个代表构筑）

模型：单人视角，普攻 60% 时间在射程内，技能命中率 75%。施法强度有两档：
- **原生校准**：技能转好后平均等 4 s 才有合适的出手机会。这样校准后的平均劲 53、≥60 占 38%，接近原生 AI 的 55 / 36%。
- **饱和**：一转好就放，代表施法缺陷修好后的 AI 或熟练真人的上限。

校准的适用范围（S5 用第二个统计量检查，反证后补充）：

| 来源 | 每 4.8 s 交战的施放次数 | 交战中劲均值 / ≥60 |
| --- | --- | --- |
| 模型 τ=4 | 2.29 | 53.2 / 37.7% |
| 模型 τ=2–3 | 3.0–2.6 | 41–48 / 20–30% |
| 原生 7 AI | 2.07 | 58.7 / 45% |
| 原生真人局全员 | 2.76 | 61.5 / 46% |
| 原生真人本人 | 未单列（施法更积极） | 77.1 / 71% |

- **τ=4 对 AI 成立**：劲水平与施法频率两个量同时吻合。
- **对真人偏悲观**：真人施法更积极，劲反而更高，因为一半收入来自技能命中和反应，模型的行为收入偏低。
- 所以下表中“缺劲”“拿 R 慢”的结论对积极施法、多反应的真人偏保守。定稿劲-B 的参数之前，应先用真人或 Clean Baseline AI 的“施法频率 + 劲分布”复测（§10）。

### 2.1 现行规则（无 R）

| 流派（技能） | 原生校准：平均劲 / 顶满时间 / 溢出（劲/s） | 饱和：等劲时间占比 | 收入（劲/s） |
| --- | --- | --- | --- |
| 裸构筑（滚远点、甩鞋、锅盖） | 53 / 2% / 0.2 | 56% | 11.0 |
| 普攻攻速（左右开抽、贴脸补一拳、锅盖，第三拳回口气） | **73 / 17% / 2.2** | 9% | 13.5 |
| 慢速重击（板砖加“攒够一顿狠的”、蛮牛顶、滚远点） | 49 / 1% / 0.1 | 59% | 11.3 |
| 高频技能（电加“再来一下别喘”、板砖、滋，急速 100，脑力关键石） | 35 / 1% / 0.1，**32% 的时间在等劲** | **100%** | 13.6 |
| 元素循环（烫、滋、电，急速 40，反应回本，脑力关键石） | **70 / 19% / 2.8** | 37% | 19.0 |
| 控制（扒裤子、冰可乐、来打老子啊） | 53 / 2% / 0.2 | 60% | 11.6 |
| 护盾防反（锅盖、拧你手腕、顶着揍，厚脸皮关键石） | **71 / 15% / 1.9** | 7% | 12.7 |
| 冲刺机动（贴脸补一拳、掏蛋子、蛮牛顶，冲刺耗劲、撞着就刷新） | 33 / 0% / 0，5% 的时间在等劲 | 51% | 13.1 |
| 召唤与区域（书包、电风扇、脚底开锅） | 41 / 0% / 0，8% 的时间在等劲 | 79% | 11.4 |
| 文武混合（滚远点、电、左右开抽，文武双全） | 58 / 2% / 0.3 | 50% | 12.6 |

读法：
- 同一套规则下，有 3 个流派长期溢出（攻速、元素、护盾），3 个流派缺劲（高频技能、冲刺、区域）。差别来自**支出**（急速、贵技能、冲刺耗劲），以及反应类**收入**。
- 原生校准下劲大多不约束施法；施法越积极，劲越像一把重复的锁（饱和时一半流派有 50% 以上的时间在等劲）。

## 3. PO 十个问题的回答

1. **劲是否创造了有意义的资源管理？**
   - 基本没有。在无急速时，它与冷却重复（L1），真人被劲拒绝的次数只有被冷却拒绝的 1/14（L5）。
   - 唯一真实的决策是爆劲（“现在花 60 还是留着放普通技能”），而爆劲已被删除。
2. **冷却 + 劲耗的双重约束有价值吗？**
   - 对多数构筑没有：两者设计成接近比例，第二把锁只在施法积极时生效，生效时也只是“等着”，不是选择。
   - 它唯一有价值的作用是**限制冷却急速**：急速流因此必须投资回劲（脑子转得快、反应回本、脑力关键石）。这是劲-C 想保留的部分。
3. **劲是否只是逼玩家普攻的限制器？**
   - 不完全是。普攻每秒约 7.5、被动每秒 5，两者合起来占收入的 65–70%。普攻只是收入之一，不是必须；站在交战里不动也会涨。
   - 但对缺劲构筑来说，普攻确实是唯一能主动加快的收入。
4. **高频技能流为什么用不上爆劲？**急速只放大支出（E6），它的劲常年在 35 左右（L2）；而爆劲还要额外付钱。
5. **普攻流溢出是否有合理设计意义？**
   - 原因不在普攻（E5），而在支出低。溢出本身没有设计意义，它只是浪费。
   - 但它给了“支出低的构筑可以用 R 白拿”一个现成的口子。如果 R 不耗劲，这些构筑就失去了唯一的劲优势。
6. **劲应该奖励什么？**
   - AI 建议同时奖励“留在交战中”和“打出有效行为”。前者保证每个构筑都有 R（公平、可预测），后者保留操作和构筑表达。
   - 两者比例是核心调参：被动占比降到 0（M2），各构筑拿到 R 的时间相差 5 倍；保留 5/s（M2p），差距缩到约 2 倍（§4）。
   - 精准操作（闪避）已经不再是收入来源。
7. **PvE 是否应该成为进入 PvP 前积攒劲的方式？**
   - 现在名义上是（E7），实际上不是（E4），打野存下的劲在赶路中被回落吃掉。
   - 如果允许存劲进 PvP，R 会变成开战的第一下（先手爆发），在 8 人 FFA 中奖励偷袭和第三方。AI 建议**不让打野直接存满**，只给一个短暂余温（脱战后保持几秒再回落），由 PO 定。
8. **脱战时应该恢复、衰减、维持还是趋向基准？**
   - 趋向一个基准，这一点保留。
   - 基准值决定 R 是开战用还是中盘用（§5 杠杆 1）：
     - 基准 ≥ R 价格：所有人都带着 R 进场，第一秒就可以按。
     - 基准 < R 价格：R 要在交战中挣出来，中位数约 2.5–5 s。
9. **玩家能否以满劲进入战斗？**
   - 现在几乎不能（满 100 只有 1–4%）。
   - AI 建议默认不能，满劲进场只能通过构筑（例如一张“出场带劲”的牌）或特定地图奖励获得，而不是默认规则。理由：Lockdown 的 TTK 中位数只有 4.8 s，满劲进场的 R 会让先手方直接决定战斗。
10. **劲是否应该形成敌人可读的强势期？**
    - 应该，而且已经具备条件：劲比例在观察帧里对所有可见单位公开。
    - 在劲-B / E 下，“他的劲快满了”就是一个可读的强势期提示；R 架构再负责“按下之后看得见”（R 侧的可读性规范）。

## 4. 资源架构比较（L2）

R 在模拟里只是抽象占位，只看“能不能按到”和“挤掉多少普通技能”，不看伤害。表中的“短交战”按原生 TTK 分布（中位 4.8 s）；括号内是饱和施法下的值。

| 架构 | 普通技能耗劲？ | R 价格 / 进场劲（示意） | 短交战中能用到 R 的比例（最低流派 – 最高流派） | 首次能按 R 的中位时刻（最快流派 – 最慢流派） | 对普通施放的影响 |
| --- | --- | --- | --- | --- | --- |
| A 共享钱包（M1，见到劲就按 R） | 是 | 50 / 50 | 75–100% | 开场 0 s | **−13% ~ −47%**（饱和 −26% ~ −54%） |
| A' 共享钱包 + 理性留劲 | 是 | 50 / 50 | 34–95%（饱和 12–46%）；**护盾 95%、冲刺 34%、高频技能 45%** | 0–1.2 s | −5% ~ −17% |
| B0 纯行为积累（M2，无被动） | 否 | 50 / 0 | **5–65%**（饱和 15–90%） | 元素 2.0 s – 冲刺 10.1 s（**约 5 倍**） | 0 ~ +11%（饱和：高频技能 **+183%**、区域 +43%） |
| **B 战斗热度（M2p，保留交战被动）** | 否 | 50 / 0 | **41–83%**（饱和 48–96%） | 元素 2.5 s – 冲刺 5.1 s（**约 2 倍**） | 同上 |
| C 急速税（M6） | 只付急速加快的那部分 | 50 / 50 | 无急速构筑开场即有；高频技能只有 45%（饱和 12%） | 0 s（高频技能 1.2 s） | 高频技能 −12%，其余约 0 |
| C' 混合（M3：只有敌对技能耗劲 ×0.6，增益技能免费） | 部分 | 50 / 50 | 开场即有 | 0 s | −0% ~ −14% |
| D 档位状态（M4：交战中每秒 −6，R 清空换档） | 否 | ≥40 / 0 | 14–72%；**元素和技能流有 26% / 8% 的时间 ≥60，其余流派 ≈0%** | 2.2–7.6 s | 同 B0 |
| **E 攻防热度（M5：B0 + 每失去 1% 生命 +0.5）** | 否 | 50 / 0 | **47–83%** | 元素 2.5 s – 冲刺 4.8 s；护盾 3.0 s | 同 B0 |

结论（L2）：
1. **A 不成立**：R 和技能抢同一份劲。
   - 见到劲就按 R，等于开场把一轮技能换成 R。
   - 理性留劲时，R 主要落到支出低的构筑（护盾 95%、攻速 85%），缺劲的构筑（冲刺、高频技能、区域）最少，与“每种构筑都有 R”相反。
   - 在饱和施法下，R 几乎只属于护盾和元素流。
2. **去掉被动收入会放大流派差距**：B0 的差距约 5 倍，保留被动后约 2 倍。交战被动是天然的平衡器，代价是 R 带一点“计时器”味道（S3 的担心）。
   - **口径**：这里的“2 倍”是**首次能按 R 的中位时刻**的比值（最慢流派 ÷ 最快流派），示意值为价格 50、脱战基线 0、原生校准施法。它衡量的是“拿到 R 的机会”差距，不是价值差距。
   - 总的公平性还要乘上 R 侧各触发口的引爆机会差（R 反证 §1），应由 S0 在综合方案中用同一组构筑放进一张表。
   - 玩家行为造成的差距可能更大：同一局中真人与 AI 的交战劲相差约 20（77 对 55），所以 2 倍不是最大差距。
   - 价格 / 基线敏感度（L2，`sensitivity_m2p.py`）：

     | R 价格 / 脱战基线 | 首次可按 R 的中位时刻（最快 – 最慢） | 比值 | 短交战能用到 R 的比例 |
     | --- | --- | --- | --- |
     | 40 / 0 | 2.5 – 3.8 s | 1.5 倍 | 63–93% |
     | 50 / 0 | 2.7 – 5.1 s | 1.9 倍 | 41–84% |
     | 60 / 0 | 2.5 – 6.7 s | 2.7 倍 | 27–78% |
     | 50 / 30 | 0.5 – 2.5 s | 5 倍（起点太低，比值失真） | 83–99% |
     | 60 / 30 | 1.7 – 3.4 s | 2.0 倍 | 69–97% |

     读法：价格越高，慢流派越吃亏；基线越接近价格，R 越接近“开战即有”。
3. **不加归一化时，元素流在所有积累型架构里都最快**：反应 10、反应回本 15、脑力关键石返还叠在一起。把技能命中按冷却归一化（M2n）几乎不改变它，因为差距来自反应，不是技能命中。
   - 所以反应类回劲需要单独封顶（按来源区分，见 §5 杠杆 3）。
4. **去掉技能劲耗会大幅解放急速流**：
   - 在“饱和施法 + 急速叠满的样板”这一**上限**下，高频技能流的施法次数增加 1.8 倍（+183%）；原生节奏下只有 0 ~ +11%。
   - 无论量级如何，结构性结论成立：劲耗是冷却急速唯一的玩法刹车（冷却下限 0.3 s 只是技术下限，急速上限 400）。
   - 所以必须与冷却急速、“再来一下别喘”、“拿命换”、“脑子转得快”、脑力关键石的重做一起决定（交付条件见 §11）。
5. **R 价格与进场基线的关系，决定 R 是开战用还是中盘用**：A、C、C' 进场就是 50，R 价格 50 时 R 在 0 s 可用。
6. **D 档位状态需要强归一化**：交战中持续扣劲后，只有高收入流派能进入高档，档位反而变成流派特权。
7. **E 与 B 的公平性相近，并且把 R 稍微倾向挨打的一方**（护盾 3.0 s、裸构筑 4.0 s；B 中分别为 3.5 s、4.0 s）。在 FFA 里，这给被第三方偷袭的人一个反打窗口；反面风险是故意吃伤害换 R。

| --- | --- | --- | --- |

## 6. 架构详述（3–5 个实质不同的候选）

### 劲-A「共享钱包」（M1 保守）

| 项 | 内容 |
| --- | --- |
| 获得 | 现行不变 |
| 消耗 | 普通技能照旧耗劲；R 另付一个价格 |
| 普通技能耗劲 | 是 |
| R 的交互 | R 与技能抢同一份劲 |
| 玩家决策 | “这 50 劲用来放 R，还是留着放两个技能” |
| 对构筑的影响 | 支出低的构筑（攻速、护盾）几乎白拿 R；技能流、冲刺流、区域流很少拿到 |
| 优点 | 改动最小；保留现有回劲牌的全部意义 |
| 缺点 | §4 结论 1；R 会变成“哪个构筑劲多”的附属品 |
| 风险 | 与 PO“每个构筑都有自己的 R”冲突；R 价格稍低就开场必按 |
| 证据 | L2 §4；L1 E5/E6 |
| AI 推荐 | **低** |

### 劲-B「战斗热度」（M2p 结构性，**AI 首选**）

| 项 | 内容 |
| --- | --- |
| 获得 | 交战被动（保留，约 5/s）+ 普攻（按攻击间隔折算，保留）+ 技能命中（改为按冷却折算）+ 反应（单独封顶）+ 构筑牌 |
| 消耗 | **只有 R 和少数构筑机制**；普通 Q/W/E 只看冷却 |
| 普通技能耗劲 | 否（需 PO 批准，属于重大玩法变更） |
| R 的交互 | 劲达到 R 价格即可按 R；按 R 时扣费，或按 R 侧推荐“引爆时扣”。脱战回落到一个低于 R 价格的基线（例如 0–30，示意） |
| 玩家决策 | 什么时候按 R（看对手劲条、看对手冷却）；要不要为了 R 留在交战里；构筑上用哪些牌改变 R 和加快积累 |
| 对构筑的影响 | 所有构筑在 2.5–5 s 内拿到 R（约 2 倍机会差，口径与敏感度见 §4 结论 2）；“回劲牌”变成“R 加速牌”；**急速流去掉劲锁后会变得很强，必须同时带上急速约束** |
| 优点 | 劲有了唯一、清晰的职责（R 的燃料）；与“简单操作”一致（Q/W/E 永远不看劲）；对手可读“他快满了” |
| 缺点 | 失去“技能耗劲”这一层取舍；需要重写约 15 张牌 / 分支的含义（§7）；**不能单独上线**（§11 交付条件） |
| 必须与 R 侧一起定的三条规则 | ① **R 不能开战**：脱战基线低于 R 价格，现行“进场约 50”不再成立，R 一律在交战中挣出来（2.5–5 s，TTK 中位约 5 s）。这是劲-B 的结果，不是可选项。受击口、护盾口在遭遇开头最需要时恰好最缺劲，需要 R 侧另作安排。② **一场交战内多次 R 的频率**：L2 中价格 50 时，6.9 s 交战（原生 AI 中位）里元素流约 2.4 次、高频技能 1.6 次、冲刺 0.9 次；12 s 交战里 1.7–4.2 次。需要定频率目标（例如“每场约 1 次，长战最多 2 次”），用递增价格、引爆后冷却或每场次数上限实现。③ **打野带 R 进场**：打野也算交战（触发被动），脱战回落有 5 s 延迟，打完营地 5 s 内卷入 PvP 的第三方会带着较高的劲进场，奖励第三方。建议交战被动只计 PvP，或打野时的被动大幅降低（节奏影响属 Batch 03 边界） |
| 风险 | 计时器感（S3）；急速失控；反应回劲叠加让元素流过快；“装上—过期—再装”的引信漏洞在交战中仍然存在（R 反证 §2.1） |
| 证据 | L2 §4；L1 E6；外部参照（S5 资源研究）：怒气、Drive 类统一计量 |
| AI 推荐 | **高** |

### 劲-C「急速税」（M6 原创混合）

| 项 | 内容 |
| --- | --- |
| 获得 | 现行不变 |
| 消耗 | 按技能基础冷却施放免费；冷却急速省下的那部分节拍按比例付劲（例：急速 40 付原价约 57%，急速 100 付原价，示意）；R 另付 |
| 普通技能耗劲 | 只有被急速加快的部分 |
| R 的交互 | 无急速构筑几乎随时有劲；急速流要在“更快施法”和“R”之间选 |
| 玩家决策 | 对急速流：快放还是留 R；对其他构筑：基本没有劲压力 |
| 对构筑的影响 | 新手和裸构筑看不到劲耗；急速流保留现在的劲经济（以及回劲牌的意义）；无需 B02 重做急速 |
| 优点 | 保留劲作为“急速刹车”的唯一有用功能，同时让基础操作免于第二把锁 |
| 缺点 | 规则不直观（“为什么同一个技能有时耗劲有时不耗”）；技能说明要显示动态劲耗；急速流的 R 依然稀少（L2：45%，饱和 12%） |
| 风险 | 理解成本；急速流是否接受“几乎没有 R” |
| 证据 | L2 §4（M6 行） |
| AI 推荐 | **中**（PO 不愿去掉技能劲耗时的次选） |

### 劲-D「档位状态」（M4 状态型）

| 项 | 内容 |
| --- | --- |
| 获得 | 交战中按行为上涨，同时持续冷却（例：每秒 −6）；脱战归零 |
| 消耗 | 普通技能不耗；R 清空当前档位，档位越高效果越强（冷 / 温 / 热三档，不连续缩放） |
| 普通技能耗劲 | 否 |
| R 的交互 | R 是“把热度兑现”；也可以设计为不同档位提供被动（热档 +x）（B02） |
| 玩家决策 | 早兑现低档，还是冒险维持高热 |
| 对构筑的影响 | **不归一化时，只有元素流和技能流能进入高档**（L2：≥60 的时间 26% / 8%，其余约 0%）；需要强归一化才公平 |
| 优点 | 强势期非常可读（身上的热度光效）；“攒还是花”是清晰的决策 |
| 缺点 | 需要每个收入源都归一化；三档 × 构筑效果的组合数翻倍 |
| 风险 | 变成“行为频率”的竞赛；档位成为流派特权 |
| 证据 | L2 §4；S3 R5“劲兑现”变体 |
| AI 推荐 | **中低** |

### 劲-E「攻防热度」（M5 原创，与 B 同族；**属 Batch 03 A17 范围**）

| 项 | 内容 |
| --- | --- |
| 获得 | 劲-B 的全部来源，**再加上承受伤害**（例：每失去 1% 最大生命 +0.5，示意；护盾吸收是否计入待定） |
| 消耗 | 同劲-B |
| 普通技能耗劲 | 否 |
| R 的交互 | 被打的一方 R 来得更早 |
| 玩家决策 | 被集火时是否用 R 反打；进攻方要考虑“打他会给他 R” |
| 对构筑的影响 | 护盾、肉盾构筑的 R 更早（L2：3.0 s，劲-B 中约 3.5–4 s）；收入差距与劲-B 相近 |
| 优点 | 在 FFA 中给被偷袭、被第三方收割的一方一个反打窗口，属于反滚雪球；格斗游戏中常见的设计（承伤加计量槽） |
| 缺点 | 可能故意吃伤害换 R；与吸血、护盾叠加时需要上限 |
| 风险 | 反滚雪球过强会削弱进攻；承伤回劲在多人混战中极快（被 3 人集火） |
| 证据 | L2 §4；外部承伤计量（S5 资源研究） |
| AI 推荐 | **中**（作为劲-B 的可选研究模块；反滚雪球属 Batch 03，不作 Batch 01 默认推荐）。注意与 R 的受击口叠加：挨打既给劲又引爆防御引信，存在双重得益 |

## 8. AI 排序与反对意见

1. **劲-B 战斗热度**（劲-E 承伤模块属 Batch 03，只作研究备选）
   - 理由：劲得到唯一职责；Q/W/E 永远简单；所有构筑都能在一场交战中拿到 R；对手能读劲条。
   - 反对意见：
     - 它是一次重大玩法变更，会失去“技能耗劲”这一层；
     - **不能单独上线**，必须连同急速约束与约 15 张牌 / 分支一起交付（§11）；
     - 交战被动保留后，R 带计时器感；
     - R 不能开战。
2. **劲-C 急速税**
   - 理由：在不动 B02 的前提下，给基础操作卸掉第二把锁。
   - 反对意见：规则不直观，急速流几乎没有 R。
3. **劲-D 档位状态**
   - 理由：可读性最好。
   - 反对意见：依赖全面归一化，否则就是流派特权。
4. **劲-A 共享钱包**
   - 理由：改动最小。
   - 反对意见：L2 显示 R 会被支出低的构筑垄断，或开场吃掉一轮技能。

## 9. 建议交给 PO 的劲侧问题（供 S0 合并，最多 4 个）

1. **普通 Q/W/E 是否继续耗劲？**三个选项：
   - 继续耗（A）；
   - 不再耗，劲只喂 R（B / D）；
   - 只对被急速加快的部分收费（C）。
2. **R 是开战用还是中盘用？**即进场基线是否低于 R 价格；打野存的劲能不能带进 PvP。（选劲-B 时答案已定为“中盘”，见劲-B 规则①。）
3. **劲主要奖励“留在交战中”还是“做了什么”？**前者公平可读，后者操作表达更强但流派差距更大。（“挨打是否涨劲”属 Batch 03，本轮不问。）
4. **如果去掉技能劲耗，交付方式选哪种？**
   - 把急速约束与相关牌（“再来一下别喘”、“拿命换”、“脑子转得快”、脑力关键石等约 15 项）的新含义拉进 Batch 01 一起交付；
   - 或者 Batch 01 只在隔离开关下验证，正式切换等 Batch 02。

**劲-B 的交付条件与 B01 / B02 边界：**
- 删除普通技能劲耗、急速约束、约 15 项劲相关牌和分支的新含义，三者是一个不可拆的交付单元。
- 两种做法，由 PO 选择（§9 问题 4）：
  - **(a) 拉进 Batch 01**：Batch 01 交付这三项，以及 R 的最小可用形态。Batch 02 只在这个基础上做牌面平衡与扩展。
  - **(b) 只在隔离开关下验证**：Batch 01 在隔离开关下验证劲-B（L3 对抗 + 隔离原型），正式默认版本保持现行技能劲耗。切换在 Batch 02 完成急速与牌面重做后进行。
  - AI 倾向 (b)：急速约束本身就是 Batch 02 A13（属性与投资）的设计问题，提前在 Batch 01 拍板，会把冷却急速的数值定在还没有构筑生态研究的基础上。
- 无论选哪种，都不允许出现“删了劲耗、牌面还写着劲耗”的中间状态。

### 不同意或部分保留

1. **“R 不能开战”作为劲-B 的结果：同意，但不是死规则。**如果 PO 希望 R 能开战，可以把脱战基线设在 R 价格附近，代价写在敏感度表里：基线 30、价格 50 时，R 在 0.5–2.5 s 可用，接近开战即有。所以“开战 / 中盘”仍然是一个参数选择，只是劲-B 的推荐值落在“中盘”。
2. **τ=4 偏悲观的方向，对劲-B 是有利的。**真人行为收入更高，意味着在劲-B 下真人拿 R 会比模拟更快。所以“一场多次 R”的频率风险，对真人只会更大，不会更小。这一点强化了规则②（频率控制）的必要性，不改变推荐。
