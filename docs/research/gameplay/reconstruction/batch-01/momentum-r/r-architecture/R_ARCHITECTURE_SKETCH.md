# R 架构草图（S3 · 供 Build Integration 先读，正式版见 `R_ARCHITECTURE.md`）

> 研究候选，**不是实施授权**。前提（PO 已批准）：删除通用长按爆劲与通用精准闪避；Q/W/E 的输入永远不受劲影响；冲刺保持多用途；移速 240。
> 劲怎么来、怎么花由 `../momentum/` 定（M1–M4），这里只写 R 侧需要的接口。

## 一句话版

| 架构 | 按 R 发生什么 | 怎么随构筑成长 | 对手怎么反制 |
| --- | --- | --- | --- |
| **R1 上劲**（强化下一招） | 身上亮起“上劲”标记（最多约 5 s）；下一个 Q/W/E 变成强化版：攻击型更强并带元素爆发（多一段可读前摇），防御型更久更大（零延迟），位移型更远或穿人 | 卡牌改：强化几次、哪些招能吃、强化后连锁什么 | 看到标记就躲开下一招；控制打掉标记（泄劲） |
| **R2 招牌大招**（可构筑终极技能） | 放出一个独立的大招 | 开局是通用小招；第一个关键石（18 点）决定大招原型（五维五种），R 标签卡牌改细节 | 大招有长前摇和冷却，看动作躲 |
| **R3 爆气状态** | 进入约 4 s 公开强势期（全身光环） | 构筑里每个带 R 子句的卡牌往状态里加一条效果（普攻流加攻速、元素流加挂元素等） | 光环可见；硬控“破气”提前结束；拉开熬过 4 s |
| **R4 引信**（构筑决定触发对象） | 给自己装一发“引信”（可见）。接下来**第一个符合条件的动作**把它引爆 | 默认只有“技能”一个触发口；卡牌、关键石、分支给你开新触发口：普攻第三段、冲刺落地、元素反应、护盾破碎、书包爆炸、地面状态生成……每个触发口有自己的引爆效果 | 引信颜色表明它装在哪类动作上；控制打掉引信；躲开那个动作 |
| **R5 回响**（原创） | 把你**刚放过的那个技能**再放一遍（回响版，效率打折、零劲收益、不触发冷却类牌） | 技能分支自动改变回响；卡牌改回响从哪里放（冲刺起点、书包、地面状态）、回响什么（上一次连招、上一次冲刺） | 对手刚见过原招，回响时出现同形状幽影预警 |

其他原创变体（正式版里评估）：
- **劲兑现**：R 一次花光所有劲，效果大小随花掉的劲变化。与 M4 状态型劲配套。
- **组件 R**：关键石定动词，卡牌加修饰。

## 初步数据（L1，`r_value_model.py`）

L10、30 属性点、无卡牌，8 个构筑，每种架构用相同名义强度：

| 架构探针 | 一次 R 的价值占目标有效生命 | 构筑间最大 / 最小 |
| --- | --- | --- |
| R1 下一招 +50% | 4.2–8.5%（偏向大技能：冲刺、元素） | 2.0× |
| R5 回响上一招 70% | 4.5–10.3%（偏向护盾、工事） | 2.3× |
| R3 状态 4 s 全伤 +30% | 5.9–13.5%（偏向攻速、冲刺） | 2.3× |
| R3 状态每次命中 +30 | 3.6–7.6%（偏向高频） | 2.1× |
| R2 固定大招 / R4 每个触发口按预算设计 | 相同 | 1.0× |

含义：凡是“按现有数值放大”的 R，都会天然偏向某一类构筑，偏向方向因架构而异；加上乘法卡牌后差距还会放大。想让不同构筑的 R 不同**类**而价值相近，效果必须**按触发口或形态单独定预算**（R2、R4），而不是乘已有数值。

## 当前倾向（未定稿）

**R4 引信为骨架**：
- 开局 = R1（只有“技能”一个触发口）；
- 构筑加触发口，或增加引信发数，可以一直长成接近 R3 的“连续引爆期”；
- “回响”作为一个触发口载荷 / 核心卡进入，不单独成系统。

**R2 只借一点**：关键石决定引爆的元素或形态底色。

反对意见与反证见正式版。

## 给 Build Integration 的接口约定（草案）

- 卡牌可以携带三类 R 标签：`R口`（新增一个触发口及其引爆载荷）、`R改`（修饰某个触发口的载荷：次数、范围、元素、连锁）、`R价`（改变 R 的劲价或返还）。
- 同一时刻只有一发引信。多个触发口都满足时，**先发生的动作**引爆。
- 引爆产生的动作带 `R` 标记：不再装填引信、不产生劲、不触发“冷却返还 / 免费重放”类卡牌（复用现有 `bAutoRecast` 护栏）。
- 换牌、洗点：下一次装填时生效；已装好的引信沿用装填时的快照。
