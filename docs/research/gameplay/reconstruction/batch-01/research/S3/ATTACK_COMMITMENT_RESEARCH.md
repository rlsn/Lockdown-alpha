# Attack Commitment 攻击承诺研究（S3b 任务三）

> 研究建议，**不是实施授权**。PO 已批准“技能专属攻击承诺”作为设计方向；**不批准**为所有强力技能加固定 0.2–0.3 s 完全硬直。本文比较 A–E 五种承诺形式，给出 3 套方向。具体技能前摇/后摇/打断代价仍需 PO 审批。
> 劲（Momentum）正在由 `../../momentum-r/momentum/` 独立研究：本文**不预设**任何新的劲消耗或收入，D 型只引用冷却与“已有资源”的事实。

## 0. 现状（L1）

| 事实 | 位置 |
| --- | --- |
| 技能前摇 0–0.25 s；**没有收招**：出手后立即可移动、普攻、施放 | `content.json` `windup`；`LDCombatActions.cpp` 无收招锁（只有野怪有 `RecoveryMs`） |
| 单位 / 地面点 / 方向技能是“施法订单”：施放时订单结束、身体站住；前摇中再点右键可以边走边放（L1 推断，**X3 确认**） | `LDNavigationOrders.cpp`、`LDPlayerOrders.cpp` |
| 自身技能、冲刺技不打断移动 | `LDPlayerOrders.cpp` |
| **被打断的前摇免费**：被眩晕、沉默、击退、嘲讽打断的前摇不扣劲、不进冷却 | `LDCombatControl.cpp` `CommitControl` → `AbandonAction` |
| 普攻锁定、出手不再查射程（PO 维持必中） | `LDCombatActions.cpp` |

所以现在的“承诺”几乎只来自**冷却**。重击没有破绽，打断没有收益之外的意义（只是阻止了这次攻击——PO 认为这本身就有价值）。

## 1. 已有 L2 证据：全局加时间不可行，按技能加可以

> 【原生 X2 第二轮·支持数字，修正原因】远程风筝时近战胜率约 72%（远程约 28%），站桩打约五五开：下表基线的数字吻合，但成立前提是远程在风筝。各变体之间的**相对**方向（全局加时间伤近战、收招伤重击）没有原生检验。

| 变体（`combat_model.py`） | 近战对远程（熟手 / 普通） | 其他 |
| --- | --- | --- |
| 现状 | 72% / 57% | — |
| 全局前摇下限 0.30 + 270 移速（V7） | 25% / 33% | 熟手下近战失效 |
| 全局“站住 + 0.25 收招 + 前摇下限”（V4_commit） | 33% / 25% | 近远程全面崩塌 |
| 只给 S03/S13 加 0.25 s 完全收招（D01-B c4only @262） | — | 重击对控制（普通）80→55% |
| S02 前摇 0.14→0.22 + 收窄（S3b `S02_type2`） | 57% / 38% | 控制对远程普通得分 72→19%（纯胜率 15%；模型普通操作者不做提前量，只取方向） |

结论：**时间加在基础技能上代价极大，尤其对普通玩家**；完全收招比起手更伤。承诺应集中在少数 T4 与长距离分支上，并优先用不卡手的形式。

## 2. 五种承诺形式比较

### A — Windup Commitment（技能专属前摇 / 瞄准 / 起手）

| 应该有明显前摇 | 必须迅速响应 |
| --- | --- |
| T4 高收益（重击、长距离突进分支、高伤落点）；T3 落点（前摇期间就公开落点，前摇本身变成可读时间） | 普攻、T1 快技能（S01、S11、S07、S22）、防御（S05、S14）、所有逃生/位移的基础版 |

- 优点：信息在**出手前**，对手的反制是“看见 → 走开/冲刺/打断”；施法者的输入不被锁。
- 代价：前摇越长越“慢”；对普通玩家的削弱比对熟手大（§1）。只给少数技能。
- 关键：前摇必须**可读**（V1/V3，见 `THREAT_GRAMMAR.md`）。看不见的前摇只是延迟。

### B — Recovery Commitment（释放后的收招）

| 形式 | 对手获得 | 施法者感受（键鼠俯视角、点击移动） | 评价 |
| --- | --- | --- | --- |
| B1 完全动作锁定 | 必然的惩罚窗口 | 最“卡手”：点了移动不动 | 只适合极少数终结技；**不推荐作为通用形式** |
| B2 可移动、不能立即攻击 | 追击/拉开距离的窗口 | 流畅，几乎感觉不到 | 惩罚力度弱，近战追击时有用 |
| B3 可普攻、不能立即施放其他技能 | 防止“大招接大招”的连发 | 几乎不可见（已有冷却/预输入掩盖） | 用于防止 0 前摇技能串联 |
| B4 短时移动减速（例 0.3 s × 50%） | 位置惩罚：躲不开反击 | 有“重量感”而不卡手（Battlerite 每招单独设置） | **推荐的 B 型默认** |
| B5 可主动取消的收招（用冲刺取消） | 迫使对方交冲刺 | 有技巧上限，学习成本 | 与“冲刺多用途”一致：取消收招 = 把冲刺花在战斗上 |

- 风险：与“预输入 2 步 450 ms”交互（收招期间的输入要么排队要么拒绝），需在原型中定。

### C — Position Commitment（位置风险）

| 例 | 已有 / 新增 | 说明 |
| --- | --- | --- |
| 冲锋技结束在终点（S13、S03、S11） | 已有 | 冲进人堆就是承诺；配合“远离墙”的走位 |
| 施法订单让身体站住（方向/落点技能） | 已有（X3 待确认） | 站住即暴露 |
| 背刺条件（S03 背后眩晕） | 已有 | 要先绕到背后 |
| 重击向前小步位移（例 60–100 cm） | 新增 | 打中更爽，打空就站在对方面前 |
| 方向在起手时锁定（起手后不能转向） | 部分已有（L1 推断方向在请求时确定），新增明示 | 与 A 配合：对手看到方向就有意义 |
| 引导技要求留在范围内（N1 2B 连喷、S08 2A 跟随区域） | 已有 | 天然承诺 |

- 优点：**不限制输入**，符合“Simple Controls”；最适合 Lockdown 的搞怪物理（向前冲出去、被反推回来都好笑）。
- 代价：效果依赖对手是否能利用位置；对远程技能几乎无效。

### D — Resource Commitment（冷却与既有资源）

- 冷却已经是主要承诺。可以研究的只有**冷却的结算时机**（见 E），不新增资源。
- 劲：只引用。劲账本显示交战中约一半时间劲 ≥60、85% 的劲流向 Q/W/E（`critique/NATIVE_MOMENTUM_BASELINE.md`）；劲是否继续作为技能消耗由劲 Session 决定。**本文不提出任何劲消耗/返还规则**。
- R 引爆的 T4 攻击沿用本文最终选定的承诺方向（`R_ARCHITECTURE.md` §7.1 已约定）。

### E — Interrupt Commitment（被打断的代价）

| 方案 | 现状 / 新 | 对施法者 | 对打断者 | 评价 |
| --- | --- | --- | --- | --- |
| E1 打断后不进冷却 | **现状** | 无损失，马上再放 | 只阻止了这一次 | 对 T1/快技能合适（前摇短，几乎打不到）；对 T4 没有风险 |
| E2 打断后部分冷却（例 50%） | 新 | 失去节奏 | 获得一个窗口 | 中性；需要 HUD 显示 |
| E3 打断后完整冷却 | 新 | 重罚 | 强 | 对普通玩家挫败感高，控制流过强 |
| E4 技能类型决定打断代价 | 新 | 只有 T4 吃代价 | 打断 T4 有意义 | 与 Threat Grammar 一致 |
| E5 按“是否已产生实际效果”结算 | 新 | 已经冲出去/已经放下的不退；还没产生效果的不罚 | 清楚 | 规则最自然：“打断在出手前 = 这招没发生” |

- PO 约束：不新增全局破招回劲、全局资源惩罚、破招成长系统、大量新触发事件。E2–E5 都只改冷却的结算时机，不新增奖励。
- 推荐：**E4 + E5 组合**——T4 在“尚未产生效果”时被打断进入部分冷却；其余类型保持现状（E1）。

## 3. 三套攻击承诺方向

| | **方向 1“看得见的蓄力”**（Windup 为主）——AI 推荐 | **方向 2“冲出去就回不来”**（Position 为主） | **方向 3“重拳有收招”**（Recovery 为主） |
| --- | --- | --- | --- |
| 核心 | 只有 T4 和长距离分支有可读起手（V1/V3）；其余技能保持快 | 不加任何输入限制；重击带向前位移、方向锁定；冲锋结束在终点 | T4 释放后 B4 减速收招（可用冲刺取消 B5）；起手不变 |
| 收招 | 无（可选：极少数终结技 B4 0.2–0.3 s 减速） | 无；改为“位置暴露” | B4（示意 0.3 s × 50%），冲刺可取消 |
| 打断 | E4+E5：T4 未生效时被打断 → 部分冷却 | E1（现状） | E5（按是否生效） |
| 改动范围 | 约 5–8 个技能/分支（S18 落点提前、S08 2B、S03 2A、S13 2B、S17 2B 重拳形态） | 约 4–6 个技能/分支（S13、S03、S17 2B、S08 2B 位移/方向规则） | 所有 T4（约 5–8 个） |
| 玩家：施法者 | 选时机：在对方交了冲刺、被控、站住时出重招；快招随手用 | 选位置：冲进去要想好怎么出来；重拳打空会站在对方面前 | 出完重招要想好收招期间怎么办（是否留冲刺） |
| 玩家：对手 | 看见起手 → 走开/冲刺/打断；打断成功会让对方的重招进入部分冷却 | 躲开第一下，然后惩罚站在面前的人 | 躲开或吃下重招后，抓 0.3 s 减速期反打 |
| 操作感 | 最接近现状；“慢的只有大招” | 最流畅、最有物理喜剧感 | 有“重量感”，但最接近格斗游戏 |
| 与现有规则冲突 | 低 | 低（需要碰撞与墙边规则配合） | 中（与预输入、R 引爆、普攻节拍交互） |
| 对普通玩家 | 起手可读后，普通玩家也能躲 T4 | 位置惩罚需要对手会利用 | 惩罚窗口需要反应 |
| 构筑空间 | 卡牌/分支可以“加起手换收益”或“去起手降收益”——**构筑改变承诺方式**的最直接手柄 | 卡牌改位移距离、方向锁、终点效果（落地震地） | 卡牌改收招长度、取消方式 |
| L2 证据 | 起手版未建模；全局前摇下限已证明不可全局化 | 未建模 | 0.25 s **完全**收招已证明伤重击（80→55%）；B4 减速版未建模 |
| 主要风险 | 起手太长时 T4 构筑变弱（需要分支补伤害） | 远程 T4 没有位置承诺，需要 A 型补 | “卡手”、与预输入的边界规则复杂 |

**AI 推荐：方向 1，并在冲锋/近战重击上吸收方向 2 的位置元素。**
- 理由：信息在出手前（与分级预警是同一个接口），不锁输入，改动集中在少数 T4 与分支，并且直接给构筑一个“改变承诺方式”的手柄。方向 3 的 B4 减速可以作为某些分支/卡牌的**构筑层**承诺（例如“重锤”形态），不进基础规则。
- 普通技能、普攻、防御技能、基础位移在三套方向中都**保持现状**（PO 核心目标）。
