## 0. 结论摘要

1. **“240 移速让走位没价值”的说法不准确，问题出在攻击的时间结构，不在速度。**（L1）
   - 24 个技能里，直线、扇形、自身圈、锁定技能从“能看出打哪里”到伤害结算只有 0.14–0.25 s，比人的反应时间（约 0.23 s 加网络与输入，按 0.30 s 算）还短。
   - 移速 × 剩余时间 = 移速 × 0 = 0，所以移速 240、300、330 都躲不开。
   - 提速只影响少数几种攻击：板砖的落点（从最坏位置能走出去的面积 51% → 61%）、远距离弹道（甩鞋可躲距离 ≥851 → ≥721 cm）和区域的后续跳。
   - **结论（反证后修订）：提速几乎不帮躲招，却会显著改变控距与风筝平衡**，普通玩家受到的影响更大（L2：普通操作者近战对远程，240 时 57%，270 时 30%）。所以移速不能用来解决“走位没价值”。它是近远程平衡的强杠杆，要和反风筝规则一起定。
   - 例外：中距离弹道在 300+ 时会进入熟手可躲带（甩鞋 @650 cm 的所需反应从 0.18 升到 0.26 s），可躲距离下移约 100–130 cm。
2. **现有的走位价值是“控距”，不是“躲招”。**（L1 + L2）
   - 普攻锁定单位，一旦开始挥必中（`LDCombatActions.cpp:1186`，2026-11-07 产品决定）。直线和扇形不需要提前量就能打中横穿的目标（扒裤子：横移 34 cm < 半宽 65）。
   - 因此在近战对近战中，L2 模型**没有检出**“反应快、会躲”带来的胜率（熟手 42%，40 局的 95% 区间约 27–57%）。这只能说“未检出优势”，不能说“操作无价值”；原生答案等 X1。
   - 有价值的操作集中在远程和板砖流（62–85%），因为它们的伤害来自可躲的类别。
   - 【原生 X1 第二轮，每 arm 7–8 种子，`../S5/X1_X2_RESULTS.md` §6·修正】瞄准只影响远程（aim150 8/8 输），时机同样影响近战（latency600 7/8 输，输出 −23%）：“操作价值只在可躲类别”只对瞄准成立。
3. **近战与远程：基础规则下远程不能永久风筝近战，反而是“远程打不死人”。**（L2，模型敏感，需 L3 确认）
   - 所有角色的普攻都是 250 cm 锁定。远程构筑只有冷却技能能在远处造成伤害（约每 1.7 s 一个技能），持续伤害不够。
   - L2：近战胜远程，熟手 72%、普通操作者 57%。提速对远程有利：270 时熟手 62%、普通 30%。自由移动施法对近战有利。
   - 【原生 X2 第二轮·支持数字，修正原因】远程风筝时胜率约 28%（输出 −23%，7/8 种子），站桩打约五五开：72% 的数字吻合，原因是风筝本身，不是近战克制远程。
   - 远程镜像 70% 超时是脚本伪影（双方都停在 560 cm 不接近）。【原生第二轮·支持“伪影”】原生远程镜像只有 2/16 删失，不超时。但伪影背后有真信号：**先接近的一方吃亏**（一方改为追击时只赢 25%）。对局中靠目标和缩圈打破僵局，需 X2 原生确认。【原生 X2 第二轮·未见支持】远程主动接近、站桩打约五五开，没有看到“先接近者吃亏”。
   - 真正的“永久风筝”风险来自构筑牌（远程普攻、拉射程、减速叠加），属于 Batch 02，但基础规则需要先定好约束。
4. **构筑与操作的相对强度：同资源原生数据缺失。**（反证后修订）
   - 原生 1v1 的“成型构筑比裸构筑快 2.4–7.7 倍”混入了 48 点属性点的预算差（`bare` 对手没有分配属性点），hedgehog、dash_ghost 两组 0 施法。**不能作为“构筑强于操作”的证据。**
   - L2 里，操作优势最多相当于 1.2–2.2 倍伤害，近战镜像接近 1.0。构筑一侧还没有同资源的原生倍数。
   - 技能永动机 2.8 s 击杀（约 9 个反应时间）的反制空间问题仍成立，但它的倍数里有多少来自属性点，未知。
5. **原生整局 PvP 的节奏**（L4，7 AI 整局，含已知 Bug）：
   - 击杀用时中位数 5.9 s，30% 的击杀有 ≥2 名攻击者。
   - 1 s 内的峰值伤害中位数为最大生命的 38%，P90 为 57%。
   - 68% 的击杀战斗长于“第三人从视野边缘走进来”的 4.7 s；移速 300 时这一比例为 80%。**提速会放大第三方介入。**
   - 这个 5.9 s 是 AI 整局切片（含等级差、多人、构筑），不是同资源 1v1；旧研究的 4.8 s 是另一种切片（野外命），两者不矛盾。
6. **推荐**（AI 推荐，等 PO 决定）：
   - D01 选 **B“威胁语法”，移速保持 240**：每种攻击归入一个反制类别，按类别保证可读时间和判定宽度。反证后补跑了只改 ②③④ 类的 L2：在 240 下近远程平衡基本中性（熟手 72→70%，普通 57→68%），避免了全局加时间的崩塌（33%）；但把移速提到 262 会让普通玩家近战对远程跌到 30%。所以提速单独作为 REVIEW 项，只能和反风筝规则（D04-C）一起考虑。D01-A 是它的必要子集，可以先做。D01-D“双速”是与 S4 D02-C 二选一的可选模块。
   - D04 选 **B“承诺—反制对称”+ A“预算护栏”**。C“上头追击”是有原创性的近远程解法，值得做隔离原型。

## 2. A06：当前基础战斗的真实问题

### 2.1 “所需反应时间”表（L1，最坏站位，冲刺不计）

`r*` = 玩家最晚要在多少秒内做出反应才能走出去。负数代表看到时已经来不及。熟手的反应时间约 0.25–0.30 s，普通玩家 0.35–0.45 s，新手 ≥ 0.5 s（Woods 2015 简单视觉反应约 0.23 s，再加网络与输入；For Honor 把 ≤ 0.2 s 视为“只能读、不能反应”）。

| S02 扒裤子（直线） | 0.14 | 65 | −0.13 | −0.10 | −0.08 | −0.06 |
| S09 滋你一脸（直线） | 0.20 | 80 | −0.13 | −0.10 | −0.07 | −0.04 |
| N1 冰可乐（扇形，距离 200 处） | 0.15 | 100 | −0.27 | −0.22 | −0.18 | −0.15 |

**读表结论**：
- 移速从 240 提到 330（+37.5%），r* 只增加 0.07–0.12 s，**没有一个负数变成正数**。
- 走位价值不足的根源有三个：
  1. 前摇 ≤ 0.25 s 且立即结算；
  2. 大部分技能在前摇期间**不向对手显示范围**（只有 S07、S09、N1 画出几何，S18 的落点出手后才出现）；
  3. 直线、扇形不需要提前量。
- 只有落在 0.25–0.45 s 之间的攻击才“熟手能躲、新手躲不开”（下称**技能带**）。现状下只有甩鞋 650–850 cm、板砖中位站位落在技能带内。

### 2.3 其他确认的现状事实（L1）

- **施法承诺**：
  - 前摇本身不锁移动，没有收招。
  - 单位、地面点、方向技能是“施法订单”，施放时身体站住，玩家可在前摇中再点右键继续走。
  - 自身技能和冲刺技不打断移动。
  - 三条规则的效果是：同样是“放技能”，有的停、有的不停，玩家需要记住。**需 L3 确认**“前摇中右键能否移动”。
- **命中口径不一致**：弹道算目标身体半径（+40），直线、圆、扇形只看脚点中心。玩家看到身体擦边“没中”，属于可读性缺陷。
- **预警可见性**：只有 S07、S09、N1 在前摇期间画出真实范围。其他技能只有通用起手特效。8 人混战中，通用特效无法告诉你“打的是不是我”。
- **击退不递减**（现行规格，CONTENT §4.5；S1/S5 已核实不是 Bug）：滚远点 2B 500 cm、滋你一脸 2B 300 cm 可以接力，形成无递减的乒乓控制。

**规则变体信号的含义**（L2，方向性）：
- **提速对远程有利，普通玩家更明显。**统一加长前摇只在防守方是熟手时伤近战（熟手 62→25%，普通 30→33% 无影响），因为效应来自熟手会用冲刺躲。
- **给所有技能加可读时间，会削弱近战的接触控制。**加长前摇必须按类别做，不能全局做（这是 D01-B 的依据）。
- **对称的“普攻附带减速”反而帮了逃跑的一方。**远程贴身时也会普攻。所以近战专属的粘滞效果不能挂在普攻上（这是 D04-C 改用“被打者追击加速”的依据）。

## 4. D01 基础战斗节奏与移动：候选方案

“威胁类别”用于下列各方案，定义如下：

| 类别 | 反制方式 | 设计约束（示意值，需批准） |
| --- | --- | --- |
| ① 接触 / 锁定（普攻、S01、S10、冲刺技） | 控距、站位、招架 | 单次伤害低；控制短 |
| ② 快招 / 预判（短直线、扇形） | 横移、抖动、预判 | `移速 × 前摇 ≥ 判定半宽`：不提前量就打不中移动目标 |
| ③ 反应招（弹道、延迟落点、陷阱） | 看到再走 | 所需反应 r* 落在技能带 0.25–0.45 s |
| ④ 资源招（高伤害或硬控） | 冲刺 / 精准闪避 | 步行不可躲，可读时间 ≥ 0.30 s，冲刺可躲 |
| ⑤ 站位 / 区域（放置物、地面状态） | 绕开、拆除 | 常显、慢 |

### D01-A 保守：“看得见再说”（可读性统一）

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 不改节奏和技能数值，只让每招“打哪里”在前摇期间对所有人可见，并让判定与画面一致 |
| 具体修改 | (1) 所有方向、落点、自身圈技能在前摇期间向敌方显示真实范围（扒裤子画带、板砖从前摇起显示落点、扯嗓子画圈）；(2) 统一命中口径，二选一：直线/圆/扇形改为“与身体相交”（+40），或保留脚点判定但让 VFX 画出有效范围；(3) 移速 240 不变 |
| 当前 vs 新 | 当前 3/24 个技能在前摇期间画范围，板砖落点只显示 0.55 s。新：所有有方向或落点的技能都画，板砖显示 0.80 s |
| 玩家操作 | 不变，但能看出“这招是不是打我” |

| 为什么可能更好玩 | 混战中的死亡变得“看得懂”（Riot 2022 耐久更新的理由：死得太快、看不清是谁打的，清晰度就差）；“我躲开了”的瞬间变多 |
| 新的玩家决策 | 看到范围后选择走开、冲刺还是换位；施法者要考虑“对手看得见” |
| 近战 / 远程 | 板砖、圈类技能变弱（中位站位所需反应从 0.31 升到 0.56 s，普通玩家也能躲）；短前摇直线不受影响，近战基本不变 |

| 滥用与反制 | 显示范围后可能被高手“精确站边”。可以接受，这本来就是读招 |
| 二阶副作用 | 若选“与身体相交”，所有直线和圆实际变宽约 40 cm，躲避更难，与“可读”方向相反——更推荐保留脚点判定、只改画面 |

| AI 推荐 | **中（作为其他方案的必要前提，单独做不够）**：不解决直线、扇形“不需要提前量”的问题，也不解决承诺和节奏 |

### D01-B 结构：“威胁语法”（按反制类别设计每一招）——**推荐**

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 不追求“所有招都能躲”，而是让每一招明确属于一个反制类别，并在数值上保证该类别的反制真的成立。移速不是自由参数，由类别约束反推 |
| 具体修改 | (1) 为 24 个技能标注威胁类别（可作为 content 字段）；(2) ② 类（扒裤子、滋你一脸、冰可乐）收窄判定或延长前摇到 `移速 × 前摇 ≥ 半宽`（例：扒裤子半宽 65 → 约 35，或前摇 0.14 → 约 0.27）；(3) ③ 类调到技能带：板砖从前摇起显示落点，并把总的可读→结算时间定在约 0.6 s（例：延迟 0.55 → 约 0.35），使中位站位的所需反应约 0.35 s（熟手能躲、新手难躲），圆心附近仍需冲刺；甩鞋飞行速度不变，最短出手距离由射程表达；(4) ④ 类（重击、硬控）加 0.2–0.3 s 收招（不能移动、不能施法），可读时间 ≥ 0.30 s；(5) **移速保持 240**（反证后修订：提速另作 REVIEW 项，见 D04-C）；(6) 包含 D01-A |
| 当前 vs 新 | 当前：前摇 0–0.25 s，无收招，0.15 s 一条线决定“有没有预警”。新：五类各有时间和宽度标准，只有高回报招有收招 |
| 玩家操作 | 近身时左右抖动走位，迫使对手预判扒裤子；看到板砖圈在 0.3 s 内走开；看到对手“蓄重击”时交冲刺；对手的重击打空后，有 0.25 s 可以惩罚 |
| 战斗场景 | 近战对远程。远程甩鞋，近战提前横移让鞋擦过（需要预判，不靠反应）。近战冲刺贴身，远程放扒裤子；近战在横移中，没提前量的扒裤子打空。远程是重击构筑，蓄了板砖大招（④ 类，0.35 s），近战交第二格冲刺（S4 D02-B）躲开并抓住收招时间打出三段普攻 |
| 为什么可能更好玩 | 每次被打中都有一个可以说出口的原因（“我没抖”“我没留冲刺”“我站在圈里”），失败可学习；熟手与新手的差距来自可教会的东西 |
| 新的玩家决策 | 冲刺留给哪类招；近身抖动 vs 站定输出；大招在什么时候放（对手冲刺交了以后） |
| 近战 / 远程 | L2（反证后补跑，`--d01b`）：在 240 下，近战对远程熟手 72→70%、普通 57→68%，基本中性；控制对远程变弱（熟手 88→81%、普通 72→47%），因为 ② 类变窄。会抖动的远程对控制的胜率翻倍（14→28%）。收招让重击对控制的普通玩家胜率下降（80→55%，只开 ④ 类时）。同时开 262 移速时普通玩家近战对远程跌到 30%——问题来自移速，不来自类别规则 |
| 构筑影响 | 卡牌可以“跨类别”改写：例如让某张牌把 ② 类直线改成 ④ 类大招（加伤害也加收招），让构筑真正改变打法（符合 §3.1 产品原则）。B02 需要把类别作为牌的作用对象 |
| 滥用与反制 | “窄判定 + 快前摇”可能被高手连续抖动完全化解：保留锁定类（①）作为保底伤害；高机动构筑靠冲刺躲 ④ 类，由 S4 的冲刺格数约束 |
| 二阶副作用 | TTK 会变长（命中率下降），第三方介入增多（L4：TTK 长于 4.7 s 的占 68%）——需与 D04-A 的致死预算一起调；AI 需要学会抖动和预判（S2） |
| 技术成本与风险 | 中：多数是数值与内容字段；收招需要新增动作锁（施法者锁移动），HUD 和动画要表现收招；风险是 24 个技能逐个调参 |
| 现有证据 | L1：§2.1 r* 表；L2：E2（全局加长前摇伤近战）、E5（反应价值只在可躲类别出现）；外部：Riot“影响与反制成正比、长前摇用于保证击杀的大招”（A）；Battlerite 每招单独设置移动减速与收招（A） |
| 尚未验证的假设 | 240 下五类约束能同时满足（② 类变窄后控制流是否太弱，需要 B02 补偿）；收招 0.2–0.3 s 在键鼠俯视角下不会显得“卡手”；技能带 0.25–0.45 s 对真人成立；L2 里 D01-B 没有提高“反应快”的价值（各构筑与现状相差都在 ±15% 以内），它提高的是抖动走位的价值，需 X1 原生确认 |
| AI 推荐 | **中–高**（反证后由“高”下调）：L1 依据充分，L2 显示在 240 下不破坏近远程平衡，并提高了抖动走位的价值；但对控制流有削弱，反应价值没有提高，真人效果没有证据。与 S4 D02-B / D03-C 方向一致（S4 的攻击型爆气前摇就是 ④ 类） |

### D01-D 原创：“双速”——交战步与街头跑

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 把“跑图快不快”和“交战中走位”分开。交战几何保持精细；脱离交战后跑得快，冲刺不再用来补跑图（S4：真人一局按 90 次 D，几乎全是跑图） |
| 具体修改 | (1) 交战步：最近 2.5 s 内造成或受到 PvP / 野怪伤害，或施放了技能 → 使用基础移速（约 240–255）；(2) 街头跑：超过 2.5 s 没有上述行为 → 0.5 s 内加速到约 320，攻击、施法、受击立即回落；(3) HUD 用角色姿态（运球走 / 抱球跑）表现，不加新按键 |
| 当前 vs 新 | 全程 240 → 交战 240–255、跑图约 320 |
| 玩家操作 | 不用按任何键：不打架时自然跑得快；想脱战就停手 2.5 s |
| 战斗场景 | 远程风筝近战：只要远程还在甩鞋，双方都是交战步；远程停手想跑，2.5 s 后两人都进入街头跑（近战也没打人），同速——脱战与追击由“谁先停手、谁还有冲刺”决定。第三人从远处赶来时也是街头跑速度 |

| 新的玩家决策 | 停手脱战还是继续缠斗；跑图时保留冲刺 |
| 近战 / 远程 | 交战几何不变，近远程平衡基本不受影响（与全局提速相比是最大优点） |
| 构筑影响 | 身手移速、空投移速、“冲刺跑图”类牌（如果有）收益变化；与 S4 D02-C（F 键疾冲）功能重叠，二选一 |
| 滥用与反制 | 脱战后高速逃跑：追击者也同时进入街头跑，且任何一次命中都让被追者回落。需要防止“挨一下就回落、对方也回落”的对称死锁——规则只看“自己是否造成或受到伤害” |
| 二阶副作用 | 第三方赶到更快，混战更多（B03 关注）；喷漆争夺的赶场时间缩短；AI 的路线与交战判断要适配 |
| 技术成本与风险 | 低–中：移速投影加一个状态项；已有“交战中”判定（劲回复用的 `MOMENTUM.IdleDelaySec` 口径可复用）；表现层需要奔跑姿态 |
| 现有证据 | L5/L4（S4 引用）：D 主要用于跑图；L4：第三方到达时间与移速的关系；外部：Eternal Return 有“普攻即结束”的移速增益（A，补丁说明） |
| 尚未验证的假设 | 2.5 s 的阈值不会让战斗“粘住”；玩家能看懂速度切换 |
| AI 推荐 | **中–高**：便宜、不碰交战几何，能把 S4 发现的“冲刺跑图”问题从基础层解决。与 D01-B 可以组合；与 S4 D02-C 二选一 |

### D01-E 大胆：“可挥空普攻”（短弧判定）

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 让近战之间的走位产生价值：普攻在前摇结束时按前方短弧判定，目标离开就挥空 |
| 具体修改 | (1) 普攻仍然点人启动、自动转向，但出手时判定“目标是否仍在 270 cm × 90° 前方弧内”；(2) 挥空消耗节拍（与“出手时刻被拒”的现行口径一致）；(3) 三段第 3 段可设计成更大的弧 |
| 当前 vs 新 | 当前：开始挥就必中（2026-11-07 产品决定）。新：可以被横移或后撤躲开 |
| 玩家操作 | 近身时卡对手前摇后撤半步让他挥空，再反打 |
| 战斗场景 | 近战镜像：A 开始第 3 段重拳，B 看到起手后撤，A 挥空，B 趁 A 的间隔反打两拳 |
| 为什么可能更好玩 | 近战之间第一次有了“读招—骗招”，攻速流与稳重流打法不同 |
| 新的玩家决策 | 贴脸输出还是卡距离骗挥空 |
| 近战 / 远程 | 前摇 0.15–0.18 s、240 移速下横移只有 36–43 cm，主要是“预判后撤”而非反应，近战的稳定输出下降 |
| 构筑影响 | 攻速流（前摇更短）变强，慢攻速重拳流变弱；普攻触发类牌（18 张 `basic_hit`）命中率下降 |
| 滥用与反制 | 网络延迟下挥空判定的争议；需要宽容的弧 |
| 二阶副作用 | 推翻一个已经确认的产品决定；AI 普攻效率下降 |
| 技术成本与风险 | 中：`ReleaseBasic` 判定与表现、AI |
| 现有证据 | L1；外部：Dota 的出手前摇、可取消后摇是操作表达（C） |
| 尚未验证的假设 | 俯视角下玩家能读出普攻起手 |
| AI 推荐 | **低–中**：与已确认的产品决定冲突，收益只在近战镜像；作为 PO 知情项列出 |

**被淘汰的方向**

| 方向 | 淘汰原因 |
| --- | --- |
| 只提高基础移速（270 / 300），其他不动 | 作为“让走位有价值”的手段被淘汰：L1 不改变 ①② 类的可躲类别，③ 类只有中距离弹道受益。但移速本身是控距的强杠杆（普通玩家近战对远程 57→30%），并增加第三方介入（L4），只能与反风筝规则一起作为平衡手段考虑。旧报告的 270 / 280 推荐不成立 |
| 全局统一前摇下限（例如所有技能 ≥ 0.30 s） | L2：防守方是熟手时，近战对远程 62% → 25%（270 下），近战的接触控制被冲刺躲掉；普通防守方无影响（30% → 33%）。真人技能分布未知，但“熟练玩家下近战失效”已足以淘汰 |
| 所有招都要能走位躲 | 需要前摇 ≥ 0.5 s（直线）才能做到，节奏会拖慢一倍；与 Riot “反制过多会让技能笨重不可靠”（A）冲突 |
| 移动施法完全免费（无减速、无站住） | L2：远程失去节奏代价，结果反而让近战胜率 97%；同时削弱“施法即承诺” |

## 5. D04 基础战斗反制与平衡原则：候选方案

### D04-A 保守：“预算护栏”（把平衡写成可检查的上限）

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 不加新机制，把反制与平衡写成几条可测量的预算，供 Batch 02 的每张牌和每次调参验收 |
| 具体修改 | (1) 致死包络：同资源 1v1 TTK 目标 6–10 s；(2) 不可反应伤害预算：任意 0.5 s 内来自 ①② 类的伤害 ≤ 最大生命 25%；(3) 硬控预算：单次 ≤ 1.2 s，3 s 内累计 ≤ 1.5 s；**可选**：击退计入递减（现行规格不计，CONTENT §4.5；改动属 REVIEW）；(4) 减速覆盖率 ≤ 50%；(5) 影响与反制成正比：伤害或控制越大，越必须属于 ③④ 类；(6) 对应的遥测检查（`LD_HIT` 窗口统计）写进 BuildEvaluation 报告 |
| 当前 vs 新 | 当前没有这些预算；L4 中 1 s 峰值伤害 > 50% 的击杀占 27%（12/44） |
| 玩家操作 | 不变 |
| 战斗场景 | 新牌“板砖暴击”提案：评审时用预算检查，发现它让 ① 类普攻 0.5 s 伤害达到 40%，要求改为挂在 ④ 类大招上 |
| 为什么可能更好玩 | 不直接改变手感；保证“死得明白”，减少一刀秒的挫败 |
| 新的玩家决策 | 无直接新增 |
| 近战 / 远程 | 中性；若选击退递减，对击退流近战（S01 2B、S09 2B）是削弱 |
| 构筑影响 | 成为 B02 的平衡尺子；破格构筑仍然允许，但必须通过可反制类别达成 |
| 滥用与反制 | 预算本身不防滥用，靠评审执行 |
| 二阶副作用 | 预算过紧会压制破格爽感（产品原则 §3.1），需要允许“传说级构筑在 ③④ 类上超预算” |
| 技术成本与风险 | 低：主要是文档与遥测脚本；击退递减（若选）为小改动 |
| 现有证据 | L4：峰值与 TTK 分布；外部：LoL 12.10 耐久更新（A），Supervive 2.01 降 15% 伤害“让战斗有来回”（A） |
| 尚未验证的假设 | 6–10 s 对 8 人混战合适。**证据空白**：L4 的 5.9 s 是整局切片，不是同资源 1v1；原生同资源只有 L16 裸构筑镜像 21.4 s，差一个量级。目标值要等 X1 的同资源原生 TTK |
| AI 推荐 | **高（作为必选底座）**：成本低，给 B02 一把尺子；单独不能提高操作表达 |

### D04-B 结构：“承诺—反制对称”——**推荐**

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 每个高回报动作都要留下一个可被惩罚的窗口；每个反制动作都要有回报 |
| 具体修改 | (1) **破招**：在对手前摇期间用硬控或击退命中他 → 该技能进入 50% 冷却并扣掉一半劲耗（现在：免费取消），破招者 +10 劲，HUD 显示“破招”；(2) **收招**：④ 类技能有 0.2–0.3 s 收招（与 D01-B 同一条）；(3) **挥空代价**：冲刺技（S03、S13）首个接触落空时冷却 +1 s；(4) **受控后保护**：一次硬控结束后 0.5 s 内免疫新的硬控（递减之外的兜底，防锁死）；(5) 锁定类（①）保持低伤害、不改 |
| 当前 vs 新 | 当前：被打断免费、技能没有破绽、冲刺技落空无代价、递减只缩短时长。新：打断有收益、大招有破绽、落空有代价、硬控之间有 0.5 s 空隙 |
| 玩家操作 | 看到对手蓄大招时用滚远点或扒裤子打断；故意骗出对手的冲刺技再反打；被控后利用 0.5 s 交冲刺 |
| 战斗场景 | 重击构筑蓄板砖大招（0.35 s 可读）。控制构筑没有躲，而是用滚远点在前摇中把他踹开：板砖进入半冷却，控制方 +10 劲；重击构筑转而用掏蛋子突进，控制方侧移让它落空，掏蛋子冷却 +1 s，控制方抓住窗口连招 |
| 为什么可能更好玩 | 给“留控制”“骗技能”这类高手行为直接回报；被打的一方总有一件可以做的事 |
| 新的玩家决策 | 控制用来输出还是留着打断；先手还是等对手先交 |
| 近战 / 远程 | 对近战有利：近战的控制多为短前摇，适合打断远程的 ③④ 类大招；远程用击退类技能（滋你一脸）也能打断近战突进前摇 |
| 构筑影响 | 打开新的构筑方向（打断流、反击流，与 S05 拧你手腕一致）；B02 可以出“破招时……”类触发牌 |
| 滥用与反制 | 控制流可能变成“专门打断”而过强：破招只对 ③④ 类前摇生效（① ② 类前摇太短，本来也打不到）；受控后保护防止连锁 |
| 二阶副作用 | 0.5 s 受控保护会削弱冻住等元素控制的连招价值（B02）；打断判定需要 AI 学习（S2）。与 S4 叠加（S5 反证 §3）：破招 +10 劲会提高爆劲频率，与 D03-D（爆劲减价）同选时叠加；受控保护与 D03-E“劲爆脱”都在防锁死，同选重复 |
| 技术成本与风险 | 中：`AbandonAction` 加冷却与劲的结算；收招锁；受控保护在 `DiminishHardControl` 中加一个窗口；HUD 提示 |
| 现有证据 | L1：§2.3 现状；外部：Dota 打断前摇不进冷却、后摇可被惩罚（C）；Riot“长前摇用于保证击杀的大招”“影响与反制成正比”（A）；Supervive 为“不可反应的超快动作”加 winddown（A） |
| 尚未验证的假设 | 破招的时机人能做到（要在 0.3 s 内用一个短前摇控制命中），否则只有 AI 做得到 |
| AI 推荐 | **高**：与 D01-B、S4 D03-C 方向一致，能产生新的构筑身份 |

### D04-C 原创：“上头追击”（被打者向攻击者加速）

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 不按职业区分近远程，而是给“挨了打想报复”的一方一点追击速度：谁打你，你朝谁跑得快一点。远程风筝的代价自然出现，近战贴身后也不会被同样的规则“锁死” |
| 具体修改 | (1) 受到某敌人的直接伤害后 2 s 内，朝该敌人移动（移动方向与指向他的方向夹角 < 45°）时移速 +12%（示意值）；(2) 只对“直接伤害来源”生效，不叠加，持续伤害不刷新；(3) HUD 显示“上头”标记与箭头 |
| 当前 vs 新 | 当前：同速追逃，谁被打都一样 |
| 玩家操作 | 被远程甩鞋后直接冲向他，追击速度比他退得快 12% |
| 战斗场景 | 远程在 600 cm 甩鞋命中近战 → 近战获得“上头”，以 269 对 240 追近，远程必须再放一个控制或交冲刺才能保持距离。近战贴身打中远程 → 远程也获得“上头”，但他想跑，不是想追，所以对他没有用；近战没有额外的锁死能力 |
| 为什么可能更好玩 | 风筝要付出代价（命中即给对方追击速度），近战有明确的追击时机；规则天然不对称，却不需要“近战职业”这种标签，符合“构筑决定身份” |
| 新的玩家决策 | 远程：是否值得在这个距离打这一下；近战：抓“上头”的 2 s 冲上去，还是保留冲刺 |
| 近战 / 远程 | 压制远程风筝；对近战镜像几乎中性（双方都朝对方走）；与 L2 的教训一致：粘滞不挂在普攻上，所以不会帮逃跑方 |
| 构筑影响 | 远程普攻牌（B02）的强度天然受控；与身手移速相加，需要设移速上限检查；“受伤触发”类牌多了一个联动点 |
| 滥用与反制 | 故意吃一下伤害来获得冲锋速度去追第三人？不成立：只对伤害来源加速。混战中被多人打会对多个方向加速——只取最近一个来源 |
| 二阶副作用 | 混战中“报复”行为增多，可能让第三方更容易被卷入；喷漆防守者被骚扰时可以直接追出圈 |
| 技术成本与风险 | 低–中：移速投影加一个条件项（需要来源与方向），表现层箭头；AI 自然受益 |
| 现有证据 | L2 E2（V6 对称粘滞帮了逃跑方，说明粘滞必须挂在“被打者”身上）；外部：Riot“Nasus 被机动远程风筝”是可接受的中等劣势而非完全克制（A） |
| 尚未验证的假设 | 12% 足以改变风筝而不至于让远程无法生存；玩家能理解这条规则 |
| AI 推荐 | **中–高**：机制原创、成本低，正面回答“远程永久风筝近战”，建议先做隔离原型 |

### D04-D 大胆：“围攻保护”（FFA 专用的反第三方规则）

| 字段 | 内容 |
| --- | --- |
| 设计理念 | 8 人混战中，第三人补刀是最大的不公平源（L4：30% 击杀多人参与）。在基础战斗层给被围攻者一个有限的缓冲 |
| 具体修改 | (1) 同一时刻，若在 3 s 内受到 ≥ 2 名敌人的直接伤害，来自“第二个及以后加入者”的伤害 −20%（示意）；(2) 被围攻者显示标记；(3) 不影响最先交战的那名敌人 |
| 当前 vs 新 | 当前所有来源伤害相同 |
| 玩家操作 | 先和人打的一方不用太怕第三人；第三人想补刀要付出更多 |
| 战斗场景 | A、B 打到双方残血，C 赶来。C 对 A 和 B 的伤害都 −20%，A、B 有机会先分出胜负或一起反打 C |
| 为什么可能更好玩 | 减少“打得好却被白捡”的挫败；鼓励正面交战（Eternal Return 的首攻方保护思想，见旧外部研究） |
| 新的玩家决策 | 第三人：现在进还是等；被围者：先打谁 |
| 近战 / 远程 | 中性 |
| 构筑影响 | AoE 流在混战中收益下降 |
| 滥用与反制 | 两人“假打”来获得保护：保护只减第三人的伤害，不加强本人 |
| 二阶副作用 | 与 Batch 03（滚雪球与翻盘）的击杀奖励设计强耦合，属于跨批次依赖 |
| 技术成本与风险 | 低–中：伤害乘区加一项，需要“交战来源”账本（助攻账本 `LDAssist` 可复用） |
| 现有证据 | L4：30% 多人击杀、68% 的战斗长于第三人赶到时间；外部：Eternal Return、Supervive 对补刀者的教训（旧报告 §5、§6，A） |
| 尚未验证的假设 | −20% 足以改变补刀而不让混战拖长 |
| AI 推荐 | **中**：问题真实存在，但与 B03 耦合，建议本批次只记录为依赖，由 B03 决定 |

**被淘汰的方向**

| 方向 | 淘汰原因 |
| --- | --- |
| 架势 / 韧性条（只有破架后才能被控） | 新增一整套资源与界面，与“控制类牌”大量冲突（B02 需全部重写）；8 人混战中读不出每个人的架势 |
| 普攻附带对称减速（粘滞） | L2：远程贴身时也会普攻，减速反而帮了逃跑方 |
| 近战 / 远程职业标签规则（例如近战减伤） | 违反“构筑决定身份”；Lockdown 只有一个角色 |
| 硬性致死封顶（例如单次伤害不超过 30%） | 直接压掉破格构筑的爽感，违背产品原则 §3.1；用 D04-A 的“类别预算”代替 |

**D01-B 补跑结果**（L2，熟手 / 普通操作者，n=40，95% 区间约 ±15%）：

| 对局 | 现状 240 | D01-B @240 | 只提速 270 | D01-B @262 |
| --- | --- | --- | --- | --- |
| 近战 vs 远程 | 72% / 57% | 70% / 68% | 62% / 30% | 60% / 30% |
| 控制 vs 远程 | 88% / 72% | 81% / 47% | 85% / 54% | 79% / 38% |
| 重击 vs 远程 | 71% / 65% | 65% / 61% | 70% / 50% | 71% / 74% |
| 重击 vs 控制 | 70% / 80% | 70% / 82% | 80% / 85% | 75% / 93% |
| 抖动的远程 vs 不抖的控制（远程胜率） | 14% | 28% | — | — |

读法：
- 类别规则本身在 240 下对近远程平衡基本中性，提速才是让普通玩家近战劣势的主因。
- ② 类收窄削弱控制流（普通玩家下明显），同时让会抖动的防守方收益翻倍，这正是 D01-B 想要的“走位价值”。代价需要 B02 给控制流补偿。
- “只差反应”的价值在 D01-B 下没有提高（各构筑与现状差 ±15% 以内）。D01-B 提高的是**走位抖动**的价值，不是反应速度的价值，原生需 X1 区分这两种操作。

**不同意或保留之处**

1. **“移速不是解决走位价值的主杠杆”这一条保留。**S5 的反证针对的是“移速不重要”，我同意移速是控距的强杠杆，已改述。但原问题是“240 是否导致走位价值不足”，L1 仍然表明提速不改变 ①② 类的可躲性，而 ①② 类在 L4 整局里承担约一半以上伤害（普攻 43% 加短前摇技能）。所以“靠提速让走位有价值”的结论不变，变的是“提速的副作用”被量化为普通玩家近战对远程 57→30%。
2. **全局前摇下限仍淘汰。**S5 指出对普通玩家无影响；但设计应在熟练对局中成立，熟手下近战失效（62→25%）足以淘汰。若 X1 显示真人整体接近“普通”档，这一条可以重开。
3. **“先接近者吃亏”的处理不在本批。**它是真信号，但在对局里由目标、缩圈和第三方打破，属于 B03/B04 的对局结构问题。这里只记录，不另立方案。
