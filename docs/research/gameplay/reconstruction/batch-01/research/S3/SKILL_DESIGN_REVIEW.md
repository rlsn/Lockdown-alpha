**读表结论**

1. **大部分技能的“实际类型”是 T1，这本身不是问题。** S02、S09、N1 名义上是“方向技能”，实际不需要预判；PO 已批准 Threat Grammar 允许稳定命中的 T1。问题只出在 T1 的**收益过高**或**射程过远**（S10、S02 2B、S13 2B），以及**改类型没继承合同**的分支（S08 2B、S03 2A、S17 2B）。
2. **真正缺的是 T3 与 T4 的入口**，不是更多 T2。现状没有合格的 T4（高收益且有反制入口），S18 这个唯一的 T3 主力被“落点出手后才显示”削掉了 0.25 s。
3. **把基础版 S02 改成真 T2 不划算（L2，§2.3）。** 这推翻了 S3 原 D01-B 的“② 类收窄”建议的一半：类型诊断仍然成立，但改动应落在长射程分支，而不是基础版。
   【原生 X1 第二轮·前提不成立，结论保留】对横向折返走位的目标，线性预判没有价值，命中取决于目标是否在移动。所以“T2 离不开预判”不成立；但“基础版改成真 T2 会让控制流打不中移动目标”这个方向仍然成立，只是原因从“不会预判”变成“移动就能躲”。
4. 表现层（V3/个人提示/倒计时/视觉宽度）能解决约一半的“看不懂”，且不改玩法——见 `THREAT_GRAMMAR.md` Part B。

## 2. 重点技能设计提案

### 2.1 S08 脚底开锅 · 2B“一锅端”（结构问题：改类型未继承合同）

| 项 | 内容 |
| --- | --- |
| 1 当前行为 | 基础版：650 cm 外放 240 半径火区，0/1/2 s 三跳（首跳即时，后两跳可走出）。2B：移除火区，改为**同点即时**（`ground_impact delay=0`）240 半径爆发 90+0.8 法强 + 3 层灼烧；3B2 中心 80 内 ×1.5；3B1 1 s 后同点再炸 50% |
| 2 问题 | 2B 把 T5 变成“650 cm 外的即时 T1”，伤害却是 T4 量级（比板砖 110 固定伤害更高的法强系数、更大的半径、还没有板砖的 0.55 s 延迟）。r* = 0.25 − 240/240 < 0（任何站位都躲不开）。只有 3B1 的第二炸可躲 |
| 3 推荐设计行为 | 2B 改为 **T3 落点**：前摇开始显示落点（V3），落地延迟约 0.45 s（示意，取板砖同档）；伤害与半径不变。3B2“锅底最烫”保持中心加成（站中心的惩罚变成“读到了却贪站”的惩罚） |
| 4 为什么符合身份 | “一锅端”是**蓄好一锅砸下去**，延迟本身就是“锅从天上掉下来”的表现；与板砖形成“锅大慢、砖小快”的区分 |
| 5 玩家操作变化 | 施法者要预判对手 0.7 s 后的位置（对付被定身、贴墙、读条中的人最有效），从“指哪打哪”变成“配合控制砸” |
| 6 对手反制 | 看到脚下锅圈后走出（中位站位约 0.4 s 内走 120 cm，普通玩家可躲，最坏站位需要冲刺） |
| 7 分支与构筑影响 | 2B 与 S02/N1 3B1/冻住（定身）形成正向连招：控制命中 → 锅落下，**控制构筑获得新的收益点**；3B1 二炸的意义从“补伤害”变成“追第二个位置” |
| 8 本批必要？ | 是 B01 最清晰的结构离群点；建议作为 **B01 隔离原型**（只改一个分支的 delay 与预警），正式改动在 PO 批准后进 B02 卡牌/分支调整 |
| 9 留到 B02 | 数值（延迟毫秒、是否补伤害） |
| 10 证据与假设 | L1（r*、伤害公式）。未验证：0.45 s 是否让 2B 过弱；模型未覆盖分支（`combat_model.py` 只按等级缩放） |

### 2.2 S18 板砖糊脸（结构问题：T3 的可读时间被吃掉）

> 【原生 X1 第二轮·现有窗口对冲刺就绪者已足够】躲避生效后，板砖命中从每 Case 3.9 次降到 0.1 次；反应 450 ms 仍能躲开约 90%（前提：看到预警且冲刺就绪）。前摇显示落点的价值只剩“没注意到 / 没有冲刺、只能走路躲”的玩家，需要 L5。另外，板砖对移动目标几乎打不中，基础强度可能偏弱，列为 B02 数值观察。

| 项 | 内容 |
| --- | --- |
| 1 当前行为 | 前摇 0.25 s 期间只有通用施法手势；出手后地面才出现落点，0.55 s 后砸下（200 半径，中心 80 更痛） |
| 2 问题 | 名义 T3，但最坏站位 r* = −0.28 s（只能冲刺躲），中位站位 0.31 s（只有熟手能躲）。玩家在前摇期间看到的信息不能告诉他“砸哪里” |
| 3 推荐设计行为 | **前摇开始即显示落点（V3）**，延迟保持 0.55 s（总可读 0.80 s）。若 PO 希望板砖流节奏不变慢，0.40 s 延迟（总可读 0.65 s，中位站位 r* 约 0.41 s）可以作为节奏选项，但没有 L2 依据 |
| 4 为什么符合身份 | 板砖是 Lockdown 最典型的“看得见、躲得开、砸中很爽”的 T3；它应当是普通玩家学会“看地面”的第一课 |
| 5 玩家操作变化 | 施法者：更依赖预判与配合控制（同 2.1）；对手：看到落点圈就走 |
| 6 对手反制 | 正常移动（不需冲刺），圆心附近仍需冲刺 |
| 7 分支与构筑影响 | 2A 连环砖的二砖与 2B 精准砖（120 半径 ×1.4、3B1 中心眩晕 0.6）都受益于可读：2B 变成“小圈重砸”的 T3/T4 混合，配控制更强 |
| 8 本批必要？ | 表现层改动 + 一个时间点（预警何时出现）；属 REVIEW（改变可躲性）。建议 B01 原型，与 2.1 共用同一个“前摇期下发落点预警”接口（`THREAT_GRAMMAR.md` VI-2） |
| 9 留到 B02 | 延迟是否缩到 0.40 s；伤害补偿 |
| 10 证据与假设 | L1 r* 表（价值论证以此和原型为准）。**L2（反证后修订）**：涉及 S18 的只有 3 组对局，只加“前摇显示落点”时，重击对远程熟手得分 71.3→76.2%（纯胜率 70.0→75.0%），n=40 下**检测不到差异**；显示更早反而让施法方略强，说明模型中 S18 对胜负贡献很小。L2 不支持“中性”，也不支持“0.40 s 补偿”。未验证：真人是否真的会看地面 |

### 2.3 S02 扒裤子（结论：基础版不改，只改 2B 长射程分支）

> 【原生 X1 第二轮】线性预判对折返走位的目标无效（见读表结论 3）；近战 aim150 对扒裤子影响很小（−10%，不显著）。因此 2B 加长起手的效果是“抓站定 / 读条 / 被控的目标”，不是“奖励会预判的人”（B1 的推荐值不变，理由按此理解）。

| 项 | 内容 |
| --- | --- |
| 1 当前行为 | 0.14 s 前摇、440×65 直线瞬判，定身 1.1 s（目标移动中 +0.3 s）。2B：射程 620，落空时前方减速 25% |
| 2 问题 | 名义 T2，实际 T1（不需提前量）；1.1–1.4 s 硬控在 440 cm 不可反应。但它是近战/控制构筑对付风筝的主要工具，“移动中 +0.3 s”就是反风筝设计 |
| 3 推荐设计行为 | **基础版保持，重新标注为 T1**（中距接触：反制是别站进 440）。**2B 长射程分支改为真 T2**：射程 620 的代价是更长的前摇（示意 0.22 s）并显示 V1 方向提示，让远距离抓人需要预判 |
| 4 为什么符合身份 | 扒裤子是“伸手一抓”；抓得近稳，抓得远要看准——长手臂付出预判代价，符合“构筑改变类型” |
| 5 玩家操作变化 | 基础版不变。2B 玩家：要预判对手走向，抓站着不动的人最稳 |
| 6 对手反制 | 基础版：控距；2B：持续横移或改向 |
| 7 分支与构筑影响 | 2B 的“落空减速”变成真正的安慰奖；3B2 连扒（3 s 内免劲再拽、自由方向）保持 |
| 8 本批必要？ | 否；B02 分支设计 |
| 9 留到 B02 | 2B 前摇与宽度的具体值 |
| 10 证据与假设 | **L2（`S02_type2`：基础版前摇 0.22 s 且半宽 50，两项同时改，效应无法拆分）**：控制对远程，熟手得分 87.5→63.7%（纯胜率 87.5→62.5%），普通 72.5→18.8%（纯胜率 72.5→15.0%）；近战对远程得分 72.5→57.5% / 57.5→37.5%。**模型前提**：“普通操作者”完全不做提前量（`lead=0`），所以“不会预判就玩不了 T2”是前提的推论，量级不可信；只取方向——基础版改成真 T2 会重伤控制流。抖动价值指标与风筝效率混在一起，不引用 |
