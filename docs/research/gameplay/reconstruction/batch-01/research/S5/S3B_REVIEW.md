# S3b 独立反证（精简）

对象：`research\S3\S3_DESIGN_DECISION_ADDENDUM.md` 及 `control_chain_model.py`、`data_control_chains.json`、`data_s3b_skill_variants.json`。方法：复跑模型与敏感度（临时命令，未改 S3 文件）。全部为 L2，只取方向。

## 1. 控制链：“最坏 8 s 中 72% 不能移动、首逃 3.26 s”

- 出处是 `F_gank_haste100_wall`：3 名攻击者**同时在场、技能全部就绪**，每人都带撞墙眩晕分支（S01 2B3B1、S09 2B3B1、`card_third_shove` + 撞墙），急速 100，**反应 0**（完美预判、压着控制等上一段刚结束才落地），受害者从不冲刺。这是人为构造的上界，不是“最坏的常见场景”。
- 敏感度：攻击者反应 0.25 s → 62%（首逃 3.66 s）；0.40 s → 58%（1.60 s）；急速 0 → 48%（1.96 s）。高位稳定，但 72% 依赖“完美协同 + 急速 100”。
- 单人场景都在 14–58%，与 S3b “单人开阔地已健康”的判断一致。
- 判定：**“墙 + 多人 + 急速下可以长时间锁人”成立**；72% / 3.26 s 应写成“完美协同上界”，并注明受害者不冲刺。原生频率未知（需 Clean Baseline 后用控制日志测“首次可逃时刻”分布）。

## 2. 方向 A“急眼了”：“正常连招保留 92–100%”

- 指标 `combo3_retained` = 前三段控制状态的总时长（含击退）÷ 现行规则下的同一数值。只看**前三段**，不看伤害、不看击杀。
- 92% 来自 `D_gank_3v1`；**最坏场景 F 下只保留 71%**（S5 复跑：反应 0.25 s 时 1.28 / 1.80 = 71%）。单人场景 100% 是因为 2 s 阈值在前三段内根本没被触发。
- 判定：应写成“单人 100%、普通围攻 92%、墙边急速围攻 71%”——A 的代价恰好落在它要解决的场景上，这是预期的，但不能只报 92–100%。
- 另需注意：模型里挣脱会**立刻截断正在生效的控制**（`states[:] = …min(e,t)`）。原生实现若改为“下一次控制生效时挣脱”，数字会不同；原型应先定这条。

## 3. 扒裤子改真 T2：控制对远程 72%→19%

- 当前 `data_s3b_skill_variants.json` 为 72% → **15%**（普通）、熟手 88% → 62%；SKILL_DESIGN_REVIEW / 附录写 19% / 64%。文档与数据文件不是同一次运行，请以重跑后的数据为准（S18 的 71→76 与数据 70→75 同样不一致）。
- 变体同时改了**两件事**：前摇 0.14→0.22 **且** 半宽 65→50，效应无法归因。
- 模型中的“普通操作者”定义为**完全不做提前量**（`lead=0`），所以任何需要预判的技能对它都必然失效——“不会预判的人玩不了 T2”在模型里是同义反复，不是发现。
- 抖动价值指标出现反常：S02_T2 下控制打“抖动的远程”得分 0.59，打“不动的远程”只有 0.29（站着不动反而更难打中）。S3 已注明该指标与风筝效率混杂、不作结论，S5 同意；附录不应再引用任何抖动相关数字。
- 判定：方向（把基础扒裤子改成真 T2 会重伤控制流）可信；19%/15% 这个量级不可信。S3b 结论“基础版不改、只改长射程分支”与此一致，可保留。

## 4. S18 前摇显示落点：“平衡中性 ±15%”

- 涉及 S18 的对局只有 3 组（重击对远程、重击对控制、技能循环对近战）。变化：重击对远程熟手 0.70→0.75（0.55 s）→0.80（0.40 s）；重击对控制普通 0.80→0.88。
- 两点问题：① n=40 的 95% 区间约 ±15%，“±15% 以内”等于“检测不到”，不是“证明中性”；② 落点**更早可见**时施法方胜率反而上升，方向与预期相反，说明在这个模型里 S18 对胜负贡献很小，变体主要在抽噪声。
- 判定：L2 不能支持“中性”，也不支持“需要 0.40 s 延迟补偿”（0.40 s 版本反而更强）。S18 改动的价值论证应主要来自 L1（可读时间被吃掉 0.25 s）与原型的真人体验；平衡影响留给 X1 `cycle` 镜像加 S18 变体或原型。

## 5. 结论

| 项 | 方向 | 数字 |
| --- | --- | --- |
| 墙 + 多人 + 急速锁人 | 成立 | 72%/3.26 s 为完美协同上界 |
| 方向 A 保留正常连招 | 成立（单人、普通围攻） | 最坏场景 71%，需一并报告 |
| 扒裤子基础版不改 | 成立 | 72→19（实为 15）是模型同义反复 + 双变量，不可作量级 |
| S18 前摇显示落点 | L1 成立 | L2“中性”不成立（检测不到）；0.40 s 补偿无依据 |
