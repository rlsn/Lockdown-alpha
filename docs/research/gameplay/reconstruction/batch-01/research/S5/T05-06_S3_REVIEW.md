## 2. 其他证据问题

1. **“成型构筑比裸构筑快 2.4–7.7 倍（L3）”混入了属性点预算差**。EXP-02 的样板花完全部属性点，`bare` 对手 54 点全不分配（Adapter v16 报告已标注“预算不对等”）。所以这组倍数同时包含 48 点属性与构筑本身，不能用来支持“构筑强度远大于操作”或“技能永动机没有反制空间”（§0.4、§3.3 Q3）。同资源倍数目前没有原生数据。另外 hedgehog、dash_ghost 两组 subject 0 施法（v16 判 NeverCast），不能当构筑强度证据。
2. **D01-B 没有对应的 L2 运行**。模型里的“threat-grammar”变体 `V4_commit` 对所有方向/地面技能施加 0.25 s 前摇下限、施法承诺 + 0.25 s 收招、身体半径判定、270 移速——这正是 S3 自己说 D01-B 必须避免的“全局加时间”。复算：近战对远程熟手 72% → 33%，普通 57% → 25%。因此“D01-B 能解决根因且与近战兼容”目前是**假设**，没有 L2 支持；需要按“只给 ③④ 类加时间、② 类改宽度”重写变体后再跑，否则不能标“推荐：高”。
3. **重击构筑在承诺类规则下没有失效**（CHARTER §11 例“延长预警让慢速近战失效”）：`V4_commit` 下重击对远程 70% → 75%（熟手）/ 62% → 47%（普通），对控制 70% → 88%。L2 不支持“重击被承诺规则压死”，但普通玩家下对远程转为劣势。
4. **TTK 口径**：S3 原生整局 TTK 中位 5.9 s（44 次击杀，PvP 窗口切片），旧研究为 4.8 s（78 条野外命）。两者切片不同，不矛盾，但 D04-A 的“同资源 1v1 目标 6–10 s”既不是同资源数据（整局含等级差、多人、构筑），也和原生同资源裸构筑镜像（L16 21.4 s）差一个量级。目标值属于 REVIEW，证据基础需写明为空白，等 X1 的同资源原生 TTK。
5. **近战镜像“熟手 42%，无优势”**：n=40 的 95% 区间约 27–57%，只能说“未检出优势”，不能说“操作无价值”。X1 会给原生答案。

## 3. 跨系统二阶副作用（与 S4 合看）

1. **P1“可读对位”叠了四层针对 ④ 类的反制**：D01-B 收招 0.2–0.3 s + D03-C 攻击爆劲追加前摇 + D04-B 破招惩罚（半冷却、扣半劲）+ D02-B 第二格冲刺与 D02-A 闪避返还。单项都合理，叠加后 ④ 类大招（重击、攒个大的）可能被过度惩罚。L2 只覆盖其中前一层；组合需要至少一次把这些规则同时打开的模型或原型运行。

4. **D01-D 双速 与 S4 D02-C 疾冲**：S3 已标二选一，同意。另：双速对喷漆防守者与第三方赶场（S3 L4：240→300 时可被第三方赶上的击杀由 68% 升到 80%）的影响落在 B03，需记入依赖。
