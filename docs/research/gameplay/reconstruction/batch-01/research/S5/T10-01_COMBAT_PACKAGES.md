## 1. 当前基础战斗的真实问题（修订后）

| # | 问题 | 依据 | 级别 | 性质 |
| --- | --- | --- | --- | --- |
| 1 | **大部分攻击看到时已经来不及躲**：直线、扇形、自身圈、锁定技能从“看得出打哪”到伤害结算只有 0.14–0.25 s，短于人的反应时间（约 0.25–0.30 s）。所以走位躲招只对少数弹道、板砖、陷阱有效 | S3 §2.1 | L1 | 实测参数 + 数学 |
| 2 | **提速解决不了问题 1，反而改变近远程平衡**：240→330 不会让任何锁定或瞬判技能变得可躲；但 270 时普通玩家的近战对远程胜率从 57% 降到 30%，第三方能赶上的击杀从 68% 升到 73–80% | S3 §0.1、§3.2；S5 反证 | L1 + L2 + L4 | 数学 + 模拟 + 整局切片 |
| 3 | **大部分技能前摇期间不显示打击范围**（24 个里 3 个显示），8 人混战中看不出“这招打不打我”；命中判定两套口径（弹道算身体，其余只看脚点） | S3 §2.3 | L1 | 源码 |
| 4 | **冲刺被拿去跑图，需要躲的时候在冷却**：真人一局按了 90 次冲刺，72% 不在交战中；第二次威胁时有冲刺的概率约 15–22% | S4 §0.1–0.2；S5 E7 | L5（1 名真人）+ L2 | 实测 + 模拟 |
| 5 | **精准闪避几乎触发不了**：真人 90 次冲刺只有 1 次精准闪避；按反应能触发的技能只有 4 个 | S4 §0.1、§0.3 | L5（1 名真人）+ L1 | 实测 + 数学（AI 侧的低次数是 AI 缺陷，不作依据） |
| 6 | **爆劲机会够，却几乎没人用**：交战中约一半时间劲 ≥60（真人 71%），真人整局只爆 3 次。障碍在输入、身份和价值感知，不在劲不够 | S4 §0.5；S5 E1 | L4 + L5 | 原生心跳实测 |
| 7 | **满劲时的输入问题**：劲 ≥60 时自身类技能（如锅盖挡脸）从“按下即放”变成“松键才放”；松键前右键移动会让这次施放消失（S1 已加取消提示，行为待定 R8） | S4 §0.7；S1 `06174c70` | L1 | 源码 |
| 8 | **技能没有破绽，打断没有收益**：大招放完没有收招，被打断也不扣冷却和劲，所以“留控制去打断”“骗出大招再反打”都没有回报 | S3 §2.2、§3.3 | L1 | 源码 |
| 9 | **近战镜像中操作价值未检出**：普攻锁定必中、直线不需提前量，L2 中“会躲”在近战镜像里不带来胜率。只能说“未检出”，原生答案等 X1 | S3 §0.2 | L2 | 模拟（95% 区间宽） |
| 10 | **构筑 vs 操作的相对强度没有同资源证据**：原有“成型构筑快 2.4–7.7 倍”混入了 48 点属性点差，不能用 | S3 §0.4；S5 T05-02 | L3（已降级） | 证据空白，等 X1 |

已在本批修复、不再是问题的：A12×A09 同帧风暴、F2/F3 每帧清零、Y11、弹道闪避时钟、N6、U05、D10/D11 等（见 TASKS A01/A02）。**击退不计递减是现行规格，不是缺陷**（CONTENT §4.5）。

## 2. 四套 Combat Design Package

共同前提（四套都包含）：移速保持 240；D01-A“看得见再说”（前摇期间显示真实打击范围、板砖从前摇起显示落点）；D04-A“预算护栏”作为 Batch 02 的平衡尺子（不直接改手感）；修好 R8 的输入问题。

### P0 保守修正（参照组）

| 项 | 内容 |
| --- | --- |
| 哲学 | 不改战斗结构，只让现有战斗看得懂、按得准 |
| 移动与操作 | 240 不变；D01-A 可读性；命中口径保留脚点、画面画出有效范围 |
| 冲刺与闪避 | 现行 9 s 单次冲刺；D02-A：精准闪避立即清零冲刺冷却（4 s 内置冷却） |
| 爆劲 | D03-A：防御、位移、自身类技能按下即放，爆劲只能 Alt+键；瞄准攻击技能保留按住 0.35 s；蓄力期间右键移动不再取消蓄力 |
| 攻防反制 | 不变（无收招、无破招） |
| 构筑兼容 | 不需要改牌；`card_slippery`（每次闪避永久 +移速，无上限）需要 B02 加上限 |
| 按键流程 | 右键走位 → 看到板砖红圈，等 0.3 s 再按 D 晚闪 → D 立刻亮起；满劲时点 E 立即开盾，Alt+Q 打爆劲 |
| 战斗情景 | 3 人混战，C 在你脚下放板砖，红圈 0.8 s；你晚闪出圈，触发精准闪避，冲刺回到手里，接着躲开 A 的鞋子 |
| 得到 / 失去 | 得到：混战看得懂；满劲不再手感变差；高手晚闪多一次冲刺。失去：几乎不失去现有玩法；**问题 4、8 基本不解决** |
| 风险与验证 | 风险低。验证：渲染实机 1 次（范围显示是否造成视觉噪音）、X1/X2 原生基线 |

### P1 可读对位（AI 推荐）

| 项 | 内容 |
| --- | --- |
| 哲学 | 每一招属于一个反制类别（快招靠预判、反应招靠走位、大招靠冲刺、锁定招靠站位），每个高回报动作留下可惩罚的破绽 |
| 移动与操作 | 240；D01-B 威胁语法：快招收窄判定（扒裤子半宽 65→35 等），反应招调到“熟手能躲、新手难躲”，大招（掏蛋子、蛮牛顶等）加 0.25 s 收招 |
| 冲刺与闪避 | D02-B：冲刺改 2 格（示意 320 cm、每格约 6.5 s），1 s 内连冲两格落地硬直 0.25 s；精准闪避返还 1 格（D02-A 的变体） |
| 爆劲 | D03-C：Alt+Q/W/E 即时爆劲，普通按键永远是普通施放；攻击型爆劲追加约 0.15 s 可读前摇（带闪光），防御与位移型零追加；**精准闪避资格按原前摇判定**（S4 §7 注①） |
| 攻防反制 | D04-B：在对手前摇中用控制命中 → 破招（建议只让对方进冷却，不扣劲，避免与劲经济叠加）；受控结束后 0.5 s 内免新的硬控 |
| 构筑兼容 | `double_dash` 与双格重叠，需改成“+1 格”；`bump_reset` 改为返还 1 格；控制流在快招收窄后变弱，需要 B02 补偿；打断流、反击流获得新空间 |
| 按键流程 | 贴身时左右小幅走位让对手的扒裤子打空 → 对手蓄重击时看到闪光，交一格冲刺侧闪 → 对手收招 0.25 s 不能动，补三段普攻；满劲时 Alt+W 打爆劲，对手看到闪光可以躲 |
| 战斗情景 | 近战追远程：远程甩鞋，你横移让鞋擦过（预判）；冲一格贴身，远程放扒裤子没提前量打空；远程交 Alt+板砖（爆劲，0.15 s 闪光），你用第二格冲刺躲开并在他收招时连打。冲刺两格都交完的人进入危险期，对手能数得出来 |
| 得到 / 失去 | 得到：被打中时说得出原因；第二次威胁有位移（留格时约 65–79%）；高手的抖动走位价值约翻倍（L2：会抖的远程对控制 14%→28%）；爆劲变成随手可拔的牌。失去：控制流命中率下降；锁定招之外的“稳定输出”变少；**大招叠了收招 + 爆劲前摇 + 破招 + 第二格冲刺四层反制**，重击、攒个大的可能被过度惩罚 |
| 风险与验证 | 风险中。①四层叠加：先用 L2 同时打开全部规则跑一次，必要时减层（建议保留收招和第二格冲刺）；②双格 + 闪避返还 + `bump_reset` + 身手关键石的刷新叠加，需要技术上限测试；③24 个技能逐个归类调参的工作量。验证见 §5 |

### P2 街头快节奏（改动最小的结构方案）

| 项 | 内容 |
| --- | --- |
| 哲学 | 不碰交战几何，专门解决“跑图占冲刺”和“远程风筝”两件事 |
| 移动与操作 | D01-D 双速：最近 2.5 s 没打人、没挨打、没放技能 → 0.5 s 内加速到约 320；一交战立即回到 240 |
| 冲刺与闪避 | 现行单次冲刺 + D02-A 精准闪避清零冲刺；冲刺不再需要用来跑图 |
| 爆劲 | D03-A 修复后的长按（或 D03-C，二者都兼容） |
| 攻防反制 | D04-C 上头追击：被某人直接打中后 2 s 内，朝他移动时 +12% 移速 |
| 构筑兼容 | 几乎不改牌；身手移速牌、空投移速的收益变化；需检查与关键石 +25% 叠加后是否触及移速上限 540 |
| 按键流程 | 不打架时自然跑得快 → 进入交战回到正常速度，冲刺留着 → 被远程的鞋打中后直接朝他冲，比他退得快 |
| 战斗情景 | 远程在 600 cm 甩鞋命中你 → 你“上头”，以约 269 对 240 追近；远程必须再放控制或交冲刺才能保持距离。远程停手 2.5 s 想跑，双方都进入街头跑，谁先停手、谁还有冲刺决定能否脱战 |
| 得到 / 失去 | 得到：跑图时间缩短，野外冲突更频繁；冲刺回到战斗用途；风筝有代价。失去：问题 1、8 不解决；第三方赶到更快、混战更多（B03 关注）；“停手脱战”可能让战斗粘住 |
| 风险与验证 | 风险低–中。D01-D 与 D04-C 都需要隔离原型确认手感（规则是否看得懂、2.5 s 是否合适）。与 P1 的 D02-B 双格组合时，上头追击 + 两格冲刺可能让风筝方无解，需联调 |

### P3 技术动作（隔离原型对照组）

| 项 | 内容 |
| --- | --- |
| 哲学 | 闪避成为频繁、可练习的技术动作，跑图和闪避彻底分开 |
| 移动与操作 | 240；D01-B 威胁语法（同 P1） |
| 冲刺与闪避 | D02-C：D = 闪身（示意 180 cm、约 4 s 一次，闪身瞬间对直接命中和弹道免疫）；新键 F = 疾冲（现行 450 cm、9 s，承担跑图、追击、冲撞，没有闪避判定） |
| 爆劲 | D03-C（同 P1）；或 D03-D 独立爆气（R 键开 3 s，接下来 2 次技能自动爆劲）——**注意 D03-D 等于把爆劲价格减半，是数值增强**，且与 F 键同选会新增两个键，超出“每套最多新增一个键”的预算，所以 P3 默认用 D03-C |
| 攻防反制 | D04-B（同 P1） |
| 构筑兼容 | 13 张冲刺形态的牌要按“接触类挂疾冲、闪避类挂闪身”拆宿主；单体弹道与单位技能构筑会被闪身削弱，范围与地面构筑相对变强（B02 的构筑生态变化） |
| 按键流程 | 赶路按 F → 交战中对手出拳瞬间按 D 闪身免掉这一击，触发精准闪避 → 对手骗你交 D 后再出手 |
| 战斗情景 | 近战用 F 追上远程；远程在近战出拳时 D 闪身，免伤并拿到 +20 劲；近战改用范围招（扯嗓子）逼远程，因为闪身躲不开范围 |
| 得到 / 失去 | 得到：第一次威胁时一定有位移；操作上限最高；跑图与闪避不再抢资源。失去：多一个键，新手负担更重；“短无敌”在 8 人混战中可能变成猜拳；单体弹道构筑变弱 |
| 风险与验证 | 风险中–高。必须先做隔离原型与 P1 的双格对比（S4 Q9），不建议直接进入正式实现 |

S3 提出的“高机动 D01-C”（移速 300+、边走边放、生命 +25%）不单独成包：成本最高、与派对混战可读性冲突，L2 中远程镜像全部超时（S3 §4 D01-C）。保留为知情项。

## 3. D01–D04 机制组合 / 冲突矩阵

**可以自由混搭**（彼此不改同一条规则）：D01-A 与一切；D04-A 与一切；D03-A/C 与 D01、D04 各项；D02-A 与 D02-B/C；D04-B 与 D02-B/C、D03-C。

| 组合 | 关系 | 原因 |
| --- | --- | --- |
| D01-D 双速 × D02-C 疾冲 | **互斥（二选一）** | 都在解决“冲刺被跑图占用”，同选等于两套跑图方案 |
| D01-C 高机动 × D02-B 双格 | **互斥** | 高移速 + 两格冲刺会让远程风筝过强 |
| D01-C 高机动 × D02-C 疾冲 | **互斥** | 疾冲与高移速功能重复 |
| D02-D 劲驱动机动 × D03 任何方案 | **互斥（除非整体重算劲）** | 冲刺、技能、爆劲抢同一份劲，攻速流会获得近乎无限的位移 |
| D02-B 双格 × D03-E 劲爆脱 | **互斥（同键）** | 两者都放在 D 键上，需要另选键 |
| D02-A 闪避返还 × D03-C 爆劲前摇 | 需定规则 | 爆劲追加前摇会让每次攻击爆劲都具备精准闪避资格，熟手躲开就白拿冲刺和 +20 劲。推荐：资格按原前摇判定 |
| D02-B 双格 × D04-C 上头追击 | 需联调 | 追击加速 + 两格冲刺可能让风筝方无解 |
| D01-B 收招 × D03-C 爆劲前摇 × D04-B 破招 × D02-B 第二格 | 需联调（减层） | 对大招叠了四层反制，重击类构筑可能被过度惩罚 |
| D04-B 破招 +劲 × D03-D 爆气 | 需联调 | 两者都提高爆劲频率，叠加后爆发方差上升 |
| D04-B 受控保护 × D03-E 劲爆脱 | 重复 | 都在解决控制链锁死，同选是双重保护 |
| D01-E 可挥空普攻 × 任何方案 | 知情项 | 推翻已确认的“普攻必中”产品决定（2026-11-07） |
| 提速（任何幅度）× 无 D04-C | 不建议 | 提速单独会让普通玩家近战对远程从 57% 降到约 30% |

键位预算：一套 Package 最多新增一个动作键（候选：Alt 修饰、F 疾冲、R 爆气）。Alt 目前也用于展开技能说明，选 D03-C 时需要改键。
