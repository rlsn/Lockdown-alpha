# 对手 AI

本页记录本局填充至 6 席的权威对手 AI 决策、构筑策略、战斗施法与公平性边界（`LDOpponentDirector`、`LDOpponentPolicy`、`LDOpponentGateway`、`LDCombatMonsters`）。

## 公平信息边界与网关约束

- **零全知特权**：每个 AI 席位只通过 `LDOpponentGateway` 读取两类合法输入——本人授权投影（自身 HP/劲/位置、冷却轨道、成长账本、待选候选）与该席位独立的 `FLDWorldView` 观察帧加 `PublicMatch` 公开信息。
- **严禁越权读取**：AI 不得读取隐藏敌人的坐标/血量/构筑、未揭示空投落点、隐藏营地的实时剩余血量或刷新倒计时（未目击营地仅能按目录基准值与当前公开野外进度阶数估算满血代价，并用 `AI.ExploreRevisitIntervalSec = 20 s` 记录自身探访冷却）。
- **同一执行入口**：AI 发出的移动、追击、攻击移动、技能释放、冲刺、成长构筑、休息室服务、PK 报名/押注/投掷、复活选点命令，全部经过与真人完全一致的导航、战斗、成长与阶段准入校验，不享受额外数值、减伤、免控或跳过前摇特权。

## 决策节拍与行为状态机（`LDOpponentPolicy`）

常规思考节拍为 `AI.DecisionIntervalSec = 0.25 s`（死亡、硬控禁动或目标失视野在事件当拍立即终止非法追击，不等下一拍）；可重试路径/服务拒绝采用指数退避（最多 `3` 次，`0.25 s -> 0.50 s`），单目标最长持续投入 `AI.EngagementBudgetSec = 40 s`。

| 阶段 / 情境 | 优先级与行动选择 |
| --- | --- |
| **死亡等待** | 立即处理未决主动/构筑牌/技能升级与加点；在复活候选窗内从 `3` 个候选出生点中选择落点 |
| **休息室（R0–R3）** | 先清空待选主动、构筑牌与 R3 终局改装，执行技能分支升级、图纸替换/学习、休息商店采购（技能点/契合词汇牌/缺槽技能）与属性加点；若当前已分配了被判定为非契合的五维点则先 `Respec` 重配；R1/R2 报名窗按血量与构筑完整度参与 PK 报名、押注与观众投掷 |
| **终局决战（FinalField）** | 围绕解锁后的主旗杆（或自身 `final_private_pole`）、安全圈收缩边界、阻断敌方喷漆/守点及收割残血目标决策；低血时优先寻找圈内掩体拉扯而非跑野外躺平角 |
| **定时野外（F1–F3）** | 1. **保命撤退**：`HP < AI.RetreatHPRatio`（25%）时脱离交战前往最近躺平角或拾取可见清营回复球，回至 `45%` 以上再返场。<br>2. **主旗杆/野外目标拦截**：根据公开喷漆/守护进度与路程预算（含 `AI.CaptureReactionBudgetSec = 2 s`）赶往打断；`HP >= 60%` 且距离 `<= 2500 cm` 时争夺开放或预告中的空投、小迷你旗、中心擂台、外卖柜与标记营地。<br>3. **遭遇战与热搜狩猎**：视野内出现可战胜敌方参赛者或等级差 `<= 2` 的热搜目标时发起连招追击。<br>4. **打野发育**：按自身当前属性与保守站桩模型评估小野（余血 `>= 15%`）与中野/大野/远古（入场 `>= 80%`、预计余血 `>= 35%`）路线清营。 |

## 构筑、分支与施法覆盖

- **26 主动与 7 种目标模式全覆盖**：`LDOpponentPolicy` 按 `ELDDemoTargetMode`（`Self`、`Unit`、`Direction`、`GroundPoint`、`Cone`、`Line` 及通用 `Dash`）与技能角色（控制、护盾/解控、突进、爆发、持续区、召唤/墙体）生成瞄准点、施法时机与满 60 劲的爆劲（Overdrive）释放决策。
- **构筑牌、元素勋章与终局改装**：优先选择与已学技能宿主形态/词汇匹配的构筑牌并自动装满容量格，拾得元素勋章后装入空元素槽；R3 从候选终局改装中选定一项。
- **当前五维加点启发式（`RelevantStats`，以代码为准）**：
  - 始终将 `stat_physique`（体格）与 `stat_thick_skin`（脸皮）纳入相关属性；再扫描已学主动 1 级基础效果中的 `ADRatioBp` 与 `APRatioBp` 决定是否纳入 `stat_strength`（力道）与 `stat_brains`（脑力），先把最高权重属性点满 18 点激活首个关键石，再均分其余相关属性。
  - **已知代码局限**：`RelevantStats` 当前硬编码排除了 `stat_agility`（身手，AI 永不加身手且洗点会洗掉身手），且仅读取 1 级静态 `ADRatioBp/APRatioBp`（未计 `AdaptiveRatioBp` 与 2/3 级分支加成）。
