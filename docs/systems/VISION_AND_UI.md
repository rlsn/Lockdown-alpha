# 视野过滤与 UI 状态

战争迷雾首先是服务器的读取权限，不是给已经收到的敌人信息盖一层黑色材质。
本文说明当前观测与表现组件；产品显示内容以 [App Spec](../APP_SPEC.md) 为准。

## 权威观测链

| 入口 | 责任 |
| --- | --- |
| `Vision\LDVisionDirector` | 来源、地形/遮挡、观察者、合法句柄与权限重查 |
| `Vision\LDViewTypes` | 有界、无权威 Actor 指针的观测记录和序列化 |
| `Vision\LDWorldViewRelay` | 每个拥有连接的观测传输、接受游标、过期与隐藏 |
| `ALDObservedEntityProxy` | 客户端非复制表现，不参与权威战斗或资源所有权 |
| `World\LDEnvironmentDirector` 与 `ALDB91Controller` | 完整地图的稀疏身体/门/物件/地表观测 |

当前代码同时保留小地图网格和完整地图稀疏协议。它们是不同格式边界，
不要只扩大一个数组或坐标字段就假定另一个世界能够安全接入。

## 谁可以看到什么

`CanObserve`、`CanSee`、`Ray` 与相应完整地图接口决定当前授权。
来源有其位置、范围及层高语义，实际相机位置不授予额外视野。
静态地形和公开地标可以随地图提供，隐藏身体、动态物件状态与私有内容不能进入全局客户端注册表。

当前系统还存在身体以外的来源。是否在 Demo 中启用某类来源由产品规格决定，
不能因为组件支持 ward 或 public sensor 就自动把对应玩法加入 Demo。

观察句柄仅对当前连接与观察状态有效。`ResolveObserved`/完整地图 `Resolve`
在命令到达时重新判断对象是否仍可观察；历史快照或远处镜头不授予远程伤害/交互。
自己身体的原生预测复制和其他实体的观察代理要区分，避免双重显示与私有状态泄露。

## 全量快照、隐藏与恢复

`ALDWorldViewRelay::ClientFullView` 发送拥有者定向的非可靠全量视图；
`ClientConceal` 提供可靠隐藏通知。两条路径都带 generation/revision，
`ApplyFullView`、`ApplyConceal` 通过接受游标拒绝过期消息。

- 新的全量快照替换可见集合，丢包后可由下一份全量状态恢复。
- 隐藏通知不能被晚到旧快照撤销；旧隐藏也不能擦掉更新的合法重现。
- 接收超时后代理隐藏并标记 stale，而不是无限外推敌人的当前位置。
- 代理销毁时同步清理附着特效、标签、声音或其他可能泄露位置的表现。
- 世界重开或连接/生命变化需要丢弃旧句柄，不能重连到同 ID 的其他实体。

具体超时和发布节奏在当前代码中维护，不在这里给新 Demo 设定平衡值。

## UI 只读模型

| 信息 | 允许来源 |
| --- | --- |
| 自身血蓝、资源、构筑、cooldown | Controller 的自身状态与私有回执 |
| 被选中其他单位 | 当前合法观察记录；未知字段保持未知 |
| 小地图 | 静态地图、自己的探索/可见范围、当前可见动态记录 |
| 商店 | 当前合法报价、自己的金币与库存 |
| 全局占领/结果 | 明确定义的公共状态 |
| 命中、失败与进度 | 经裁剪的自身反馈，而非完整服务器日志 |

`LDHUDModel`、`LDHUD`、`LDMinimap`、`LDUIRoot` 及各 Panel 是主要 UMG/Slate 入口。
完整地图还使用 `ALDB91HUD`/`ALDB92HUD` 的原生绘制与命中框，不能把两者当作完全相同的布局实现。

受控角色、检查对象、准备中的动作、指针捕获、镜头模式和打开面板分别管理。
选中另一角色并不改变技能/装备按钮的所有者；禁用按钮只是反馈，不能代替服务器检查。
Widgets 不得遍历所有 Pawn/PlayerState 来补全 Tooltip 或小地图。

## UI 交互与错误

输入捕获、焦点、Esc、菜单与镜头的共同约束见 [移动与输入](MOVEMENT_INPUT_AND_CAMERA.md)。
界面使用当前映射注册表显示按键，不能写另一份易失效的按键表。
等待、成功、失败、失去权限和过期状态需区别显示，不以本地超时虚构成功。

数据更新应围绕已有快照/回执和局部变化，不为每个 Widget 新增一次全世界扫描。
增加 HUD 字段时同时检查服务器是否授权它、离开视野如何清理、life 改变如何失效，
以及对应提示、特效和辅助显示是否绕过了同一限制。

## 检查入口

`RunViewNetworkCheck.ps1`、`RunHUDCheck.ps1`、`RunInputCheck.ps1`
及 `LDViewTests`、`LDHUDRulesTests` 覆盖协议、可见集合与表现规则。
完整地图用相应环境网络场景检查它自己的观测格式。
必须观察真正的限制客户端及其可访问记录，不能仅看服务器全知视图或一张截图。
