# Frozen v0.3 foundation references

These four files are byte-for-byte snapshots of the predecessor specification, included for offline handoff. They describe intended foundations, not proof of completed Unreal implementation.

- [Scope and migration](01_SCOPE_AND_MIGRATION.md)
- [Multiplayer and vision](05_MULTIPLAYER_AND_VISION.md)
- [Port slice and build plan](06_PORT_SLICE_AND_BUILD_PLAN.md)
- [Acceptance and delivery](07_ACCEPTANCE_AND_DELIVERY.md)

Read v0.4 scope first. Its class starts, attributes, ranks, shared slots, keybindings, XP, death formula, earned Seal and integration timer replace the predecessor defaults where explicitly stated. Preserve unchanged authority, movement, geometry, private observation, transaction and asset requirements. Old fixture flags demonstrate only a fixture; they cannot satisfy v0.4 normal progression.

Historical links inside these verbatim snapshots may refer to the complete v0.3 package. Use its separately retained original if that additional context is needed. The snapshots are not rewritten to appear current.
