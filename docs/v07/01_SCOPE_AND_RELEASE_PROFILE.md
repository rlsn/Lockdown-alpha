# Scope and release profile

## Intended behavior

A prepared low-level contender can stop a claim through vision, a cheap counter-item and displacement. A stronger fighter retains a meaningful advantage in an exposed duel. An economic character can earn access without kills, then defend or time a real contest. Every tactic has a visible weakness. Utility remains useful independent of damage scaling.

All ordinary offensive input uses existing MOBA unit/point/area targeting and right-click native navigation; no aim-heavy shooter migration. Solo utility includes disengagement, scouting, traps, decoys and interruption, not only teammate buffs.

## Required release slices

| Slice | Required behavior |
| --- | --- |
| Core fight | Physical/magical damage, real MP, attack pacing, control vocabulary, dispels, spell block, barriers, forced movement, clear combat feedback |
| Build | Six attributes, natural prerequisites, learning vs training vs equipment, five actives/one capstone, three item references, gear caps/quality, persistent cooldowns |
| Content | All 28 new abilities and 40 item definitions, legacy utilities retained, affordable counter supply, books/trainers/ruins/boss sources |
| Acquisition | Deterministic branching assembly, specialist work orders, quality upgrades, peer transfer and lineage |
| World | Three camps, three ruins, advanced forge/HeartForge, one boss, shrines, two approaches to Heart, three guardian towers and meaningful sight loss |
| Outcome | Siege global opening; registered Charter public warning/window; personal three-key and Heartbreaker leases; one ten-second claim and winner |
| Integration | Economy/bank/market budgets, unified items/reservations, privacy, life/death, native UI/build/remote clients, affected v0.6 regressions |

All are required for release; milestone boundaries allow review before catalog expansion. Do not ship placeholder effects that only log a string or animate without server consequences.

## Profiles and reductions

Normal `v07_integration`: 2100-second deadline, 1–4 locked contenders, level cap 15, 24 item instances, five common active slots, three quick references. N includes every eligible starting contender, human or optional AI; normal default preserves existing roster policy and does not add NPC contenders silently. Eight resident purses/other starting supplies are retained only if actually delivered. Institutional budgets remain fixed from N, not recalculated on withdrawal.

The map stays the small City/West/East region plus authored wilderness pockets. Four outer cities are future scale, not a port requirement. Existing bounded economy schedules still end at t=1440 even though this integration session is longer; no automatic extra supply/reward ticks. Label the event600–780 as retained prototype tuning. No inference of long-run balance.

Level cap 15 tests investment/prerequisites, but normal 35-minute play need not reach it. Existing economy-only examples still give 300 XP → level four under the selected table. Camp/boss/tower XP broadens progression; finite budgets prevent infinite farming. Level-8-vs-14 setups may use labelled fixtures for isolated combat, never as proof of normal character progression or route completion.

Full design: 60–90 minutes and multiple connected cities with nonviolent activity density. No shipping long-session configuration is claimed by this package.

## Definition of done

Real source and native assets on the audited baseline, synchronized versioned data, reproducible build/launch commands, all release features with evidence, accounting/authority/privacy checks, completed ledger/report, four normal route demonstrations without grants, and a recorded lower-level interruption scenario. Human usability and balance are reported separately; missing participants are Not run, not fabricated passes. Specifications/model checks alone do not satisfy game acceptance.
