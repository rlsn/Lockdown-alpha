## Scope control

B71–B73 is the first tactical review build; it is not labelled full v0.7. Do not expand items until core targeting/cost/visibility and death pass. B74 establishes economy integration before all fancy effects. B76 cannot be replaced by developer grants or a fake status label: complete each route through normal legal actions in at least one run. Individual boundary tests may use explicit fixtures with separate logs.

Do not silently defer difficult capstones or personal-route semantics while declaring release complete. If platform limitations arise, implement feasible work, record the exact failing feature/check, and deliver an honest partial milestone. Changes to source numbers or rules require a synchronized decision entry, catalogs/config, real assets and affected tests. Exact engine/API design is chosen from the actual source, not from assumed GAS/engine versions in older notes.

## Delivery contents from the coding agent

Source commit and native assets, versioned real imported data with checksum matching this contract or documented deviations, bootstrap/build/cook/package and launch steps, feature ledger, acceptance matrix, combat/action/route/accounting receipts, performance/privacy captures, normal-route demos, and human observations or explicit pending list. Production deployment/accounts and full 90-minute pacing are not part of this build.
